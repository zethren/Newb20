# Freedom of Movement

*4th-level Abjuration*

| Spell detail | Rule |
| --- | --- |
| **Level** | 4 |
| **School** | Abjuration |
| **Class** | Cleric |
| **Spell Lists** | Cleric 4th, Paladin 4th |
| **Casting Time** | Standard Action |
| **Range** | Touch |
| **Components** | V, S |
| **Duration** | 10 minutes |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

For 10 minutes, the touched creature cannot become Grappled or Entangled, and magic cannot reduce its movement speed; physical barriers still restrain it.
