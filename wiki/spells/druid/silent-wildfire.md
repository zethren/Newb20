# Silent Wildfire

| Spell detail | Value |
| --- | --- |
| Level | 7 |
| School | Illusion |
| Class | Druid |
| Casting time | Standard Action |
| Range | 120 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 10 minutes |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Make a 40-foot-radius area appear to burn and fill with smoke for 10 minutes; the image has no heat, damage, or sound.
