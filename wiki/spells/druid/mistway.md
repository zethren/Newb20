# Mistway

| Spell detail | Value |
| --- | --- |
| Level | 4 |
| School | Conjuration |
| Class | Druid |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | Instantaneous |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Teleport up to four willing creatures within 10 feet of you to a place you have visited within 1 mile; the destination must be unoccupied and outdoors.
