# Shield of Faith

*1st-level Abjuration*

| Spell detail | Rule |
| --- | --- |
| **Level** | 1 |
| **School** | Abjuration |
| **Class** | Cleric |
| **Spell Lists** | Cleric 1st, Paladin 1st |
| **Casting Time** | Standard Action |
| **Range** | Touch |
| **Components** | V, S |
| **Duration** | 1 minute/CL |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

A translucent sigil grants one willing creature a +2 Deflection bonus to Deflection AC against all attacks for 1 minute/CL.
