# Mirror Image

*2nd-level Illusion*

| Spell detail | Rule |
| --- | --- |
| **Level** | 2 |
| **School** | Illusion |
| **Class** | Cleric |
| **Spell Lists** | Cleric 2nd, Wizard 2nd |
| **Casting Time** | Standard Action |
| **Range** | Self |
| **Components** | V, S |
| **Duration** | 1 minute |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

Three duplicates orbit you for 1 minute; the first three attacks that would hit have a 50% chance to strike and destroy one duplicate instead.
