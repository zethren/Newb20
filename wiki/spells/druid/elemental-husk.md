# Elemental Husk

| Spell detail | Value |
| --- | --- |
| Level | 3 |
| School | Abjuration |
| Class | Druid |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 10 minutes/CL |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect
