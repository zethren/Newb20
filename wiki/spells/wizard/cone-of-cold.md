# Cone of Cold

| Spell detail | Rule |
| --- | --- |
| Level | 5 (Wizard) |
| School | Evocation |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | Self (60-foot cone) |
| Components | V, S |
| Duration | Instantaneous |
| Attack | None |
| Saving Throw | Reflex half |
| Spell Resistance | Yes |

**Effect.** Creatures in a 60-foot cone take 1d6 cold damage per caster level, Reflex half. Unattended liquid in the area freezes into a thin surface layer.
