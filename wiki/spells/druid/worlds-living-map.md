# World's Living Map

| Spell detail | Value |
| --- | --- |
| Level | 9 |
| School | Divination |
| Class | Druid |
| Casting time | Standard Action |
| Range | 300 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | Instantaneous |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Learn the layout of natural terrain within 1 mile, including creatures larger than Tiny and sources of water; this reveals no identity or thoughts.
