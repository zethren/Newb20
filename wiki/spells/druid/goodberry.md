# Goodberry

*1st-level Transmutation*

| Spell detail | Value |
| --- | --- |
| Level | 1 |
| School | Transmutation |
| Class | Druid |
| Casting time | Standard Action |
| Range | Touch |
| Components | V, S, M (a sprig of mistletoe) |
| Duration | 24 hours |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Create up to ten magical berries in your hand. A creature can use a Standard Action to eat one berry; it provides enough nourishment for one day and restores 1 hit point. Uneaten berries lose their magic when the spell ends.
