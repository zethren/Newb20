# Hallucinatory Terrain

*4th-level Illusion*

| Spell detail | Rule |
| --- | --- |
| **Level** | 4 |
| **School** | Illusion |
| **Class** | Cleric |
| **Spell Lists** | Cleric 4th, Wizard 4th |
| **Casting Time** | Standard Action |
| **Range** | 300 feet |
| **Components** | V, S |
| **Duration** | 1 day |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

Change the apparent appearance, sound, and smell of natural terrain in a 100-foot cube for 1 day; physical interaction reveals the real terrain.
