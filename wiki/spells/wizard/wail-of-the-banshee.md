# Wail of the Banshee

| Spell detail | Rule |
| --- | --- |
| Level | 9 (Wizard) |
| School | Necromancy |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | Instantaneous |
| Attack | None |
| Saving Throw | Fortitude half |
| Spell Resistance | Yes |

**Effect.** Up to six creatures make Fortitude saves or take 1d6 corrupt damage per caster level; success halves damage. A target reduced to 0 HP by this spell dies.
