# Flesh to Stone

| Spell detail | Rule |
| --- | --- |
| Level | 8 (Wizard) |
| School | Transmutation |
| Class | Wizard |
| Spell Lists | Cleric 6th, Wizard 8th |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | 1 minute/CL |
| Attack | None |
| Saving Throw | Fortitude negates; repeat each turn |
| Spell Resistance | Yes |

**Effect.** One creature makes a Fortitude save or turns to stone and becomes Paralyzed for 1 minute/CL. It gains a +8 Natural Armor bonus to Natural Armor AC, cannot move or speak, and repeats the save each turn.
