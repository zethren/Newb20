# Beast Shape II

| Spell detail | Value |
| --- | --- |
| Level | 4 |
| School | Transmutation (Polymorph) |
| Class | Druid |
| Casting time | Standard Action |
| Range | Self |
| Components | V, S, M (a sample or tuft from the chosen animal) |
| Duration | 1 minute/CL |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

This spell functions as [Beast Shape I](beast-shape-i.md), and also allows Tiny or Large animal forms.

| Form size | Physical ability adjustment | Natural Armor bonus to Natural Armor AC |
| --- | --- | ---: |
| Tiny | +4 Size bonus to Dexterity, -2 Size penalty to Strength | +1 |
| Large | +4 Size bonus to Strength, -2 Size penalty to Dexterity | +4 |

The form may grant climb 60 feet, fly 60 feet (good maneuverability), swim 60 feet, darkvision 60 feet, low-light vision, or scent if the chosen animal has that ability. It may also grant grab, pounce, or trip when present in the chosen animal profile.
