# Hallow

*5th-level Necromancy*

| Spell detail | Rule |
| --- | --- |
| **Level** | 5 |
| **School** | Necromancy |
| **Class** | Cleric |
| **Casting Time** | Standard Action |
| **Range** | Touch |
| **Components** | V, S |
| **Duration** | 24 hours |
| **Attack** | None |
| **Saving Throw** | Will negates entry |
| **Spell Resistance** | Yes |

## Effect

Consecrate a 20-foot-radius area for 24 hours; undead must pass a Will save to enter, and creatures resting inside gain +2 on saves against fear.
