# Moment of Prescience

| Spell detail | Rule |
| --- | --- |
| Level | 8 (Wizard) |
| School | Divination |
| Class | Wizard |
| Spell Lists | Cleric 8th, Wizard 8th |
| Casting Time | Standard Action |
| Range | Self |
| Components | V, S |
| Duration | 1 hour |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** For 1 hour, add +20 to one attack roll, save, ability check, or skill check after seeing your d20 result. The spell then ends.
