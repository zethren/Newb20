# Dreaming Orchard

| Spell detail | Value |
| --- | --- |
| Level | 5 |
| School | Illusion |
| Class | Druid |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 10 minutes |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Up to six willing creatures see a vivid, harmless shared dreamscape for 10 minutes while remaining aware of their surroundings.
