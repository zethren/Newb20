# Create Water

*1st-level Conjuration*

| Spell detail | Rule |
| --- | --- |
| **Level** | 1 |
| **School** | Conjuration |
| **Class** | Cleric |
| **Casting Time** | Standard Action |
| **Range** | 30 feet |
| **Components** | V, S |
| **Duration** | Instantaneous |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

Create up to 10 gallons of clean water in open containers or across an unoccupied space; it is ordinary water and remains after casting.
