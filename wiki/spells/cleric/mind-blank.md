# Mind Blank

*8th-level Abjuration*

| Spell detail | Rule |
| --- | --- |
| **Level** | 8 |
| **School** | Abjuration |
| **Class** | Cleric |
| **Spell Lists** | Cleric 8th, Wizard 8th |
| **Casting Time** | Standard Action |
| **Range** | Touch |
| **Components** | V, S |
| **Duration** | 24 hours |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

The touched creature is immune to magical detection of its thoughts, alignment, or location and to enchantment spells for 24 hours.
