# Lesser Restoration

*2nd-level Conjuration*

| Spell detail | Rule |
| --- | --- |
| **Level** | 2 |
| **School** | Conjuration |
| **Class** | Cleric |
| **Spell Lists** | Cleric 2nd, Druid 2nd, Paladin 2nd |
| **Casting Time** | Standard Action |
| **Range** | Touch |
| **Components** | V, S |
| **Duration** | Instantaneous |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

Touch a creature to end one of these conditions: Blinded, Deafened, Fatigued, or Sickened. You can also restore temporary ability damage equal to a roll of 1d4 from one ability score. This spell does not restore permanent ability damage.
