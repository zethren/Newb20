# Wither Touch

| Spell detail | Value |
| --- | --- |
| Level | 1 |
| School | Necromancy |
| Class | Druid |
| Casting time | Standard Action |
| Range | Touch |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | Instantaneous |
| Spell attack | Melee spell attack (use your spell attack bonus) |
| Saving throw | None |
| Spell resistance | Yes |

## Effect

Make a melee spell attack against one creature; on a hit it takes 2d6 corrupt damage plus 1d6 per 3 caster levels, and you gain temporary hit points equal to half the damage dealt.
