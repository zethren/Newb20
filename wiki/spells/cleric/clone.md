# Clone

*8th-level Necromancy*

| Spell detail | Rule |
| --- | --- |
| **Level** | 8 |
| **School** | Necromancy |
| **Class** | Cleric |
| **Spell Lists** | Cleric 8th, Wizard 8th |
| **Casting Time** | Standard Action |
| **Range** | Touch |
| **Components** | V, S |
| **Duration** | 1 year |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

Create a dormant duplicate from a willing creature’s blood or hair; if that creature dies within a year, its willing soul can awaken in the clone after 24 hours.
