# Lantern Courier

*1st-level Conjuration*

| Spell detail | Rule |
| --- | --- |
| **Level** | 1 |
| **School** | Conjuration |
| **Class** | Cleric |
| **Casting Time** | Standard Action |
| **Range** | 1 mile |
| **Components** | V, S |
| **Duration** | 1 hour |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

Summon a Tiny luminous ghost (an undead spirit) and speak a message of up to 25 words to it. The ghost travels toward one creature you know within range, delivers the message if it can reach that creature, then vanishes. It cannot interact with objects or be used to scout.
