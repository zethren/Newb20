# Antimagic Field

*9th-level Abjuration*

| Spell detail | Rule |
| --- | --- |
| **Level** | 9 |
| **School** | Abjuration |
| **Class** | Cleric |
| **Casting Time** | Standard Action |
| **Range** | Self |
| **Components** | V, S |
| **Duration** | 1 minute |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

A 10-foot-radius field follows you for 1 minute; spells of 4th level or lower are suppressed inside and cannot cross its boundary, including your own spells.
