# Cloak of Needles

| Spell detail | Rule |
| --- | --- |
| Level | 2nd |
| School | Abjuration |
| Class | Ranger |
| Casting Time | Standard Action |
| Range | Self |
| Components | V, S |
| Duration | 1 round/CL |
| Attack | None |
| Save | Dexterity, half damage |
| Spell Resistance | Yes |

## Effect

A close-fitting veil of spectral thorns surrounds you. The first time a creature within 5 feet hits you with a melee attack before the spell ends, it takes **2d6 piercing damage plus 1d6 per 4 caster levels** (Dexterity save for half). The spell then ends.
