# Cause Fear

| Spell detail | Rule |
| --- | --- |
| Level | 1 (Wizard) |
| School | Necromancy |
| Class | Wizard |
| Spell Lists | Cleric 1st, Wizard 1st |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | 1 minute |
| Attack | None |
| Saving Throw | Will negates |
| Spell Resistance | Yes |

**Effect.** One creature makes a Will save or becomes Shaken for 1 minute. A creature with more Hit Dice than your caster level is unaffected.
