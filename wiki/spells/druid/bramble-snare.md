# Bramble Snare

| Spell detail | Value |
| --- | --- |
| Level | 1 |
| School | Conjuration |
| Class | Druid |
| Casting time | Standard Action |
| Range | Self |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | Instantaneous |
| Spell attack | None |
| Saving throw | Strength negates |
| Spell resistance | Yes |

## Effect

Plants seize one Large or smaller creature; it must succeed on a Strength save or have its speed reduced to 0 until the start of your next turn.
