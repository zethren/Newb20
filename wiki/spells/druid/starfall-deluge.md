# Starfall Deluge

| Spell detail | Value |
| --- | --- |
| Level | 9 |
| School | Evocation |
| Class | Druid |
| Casting time | Standard Action |
| Range | 300 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | Instantaneous |
| Spell attack | None |
| Saving throw | Dexterity half |
| Spell resistance | Yes |

## Effect

Choose a point within range; creatures in a 30-foot-radius area take 1d8 fire or holy damage per caster level (choose one), with Dexterity saves for half.
