# Armor Class Components

Armor Class (AC) is made up of separate components. Each modifier identifies both the component it changes and its bonus type. The component determines whether it is removed by a condition; the bonus type determines how it stacks.

| AC component | Examples |
| --- | --- |
| Dexterity AC | The character's Dexterity modifier to AC. |
| Dodge AC | Acrobatics, the Dodge feat, or an item that improves the character's ability to evade attacks. |
| Armor AC | Worn armor. |
| Shield AC | A wielded shield or a feature that improves shield protection. |
| Natural Armor AC | The creature's natural armor. |
| Deflection AC | Deflection effects. |
| Size AC | The current Size adjustment to AC in the [Combat Scaling](combat-scaling.md#size-modifiers) table. |

### Stacking AC Modifiers

Add the contributions of the separate AC components to determine total AC. Components remain separate when applying conditions. Modifiers assigned to different components both contribute to total AC, even if they have the same bonus type.

Within the same component, apply the general bonus-type rules in [Attributes](../attributes.md#bonus-types-and-stacking). For example:

- An Enhancement bonus from magical boots to Dodge AC stacks with a Circumstance bonus to Dodge AC from Acrobatics.
- Multiple Enhancement bonuses to Dodge AC do not stack; use the highest.
- Circumstance bonuses from distinct effects stack within Dodge AC. Thus Acrobatics' rank-based bonus can stack with the Dodge feat's separate Circumstance bonus to Dodge AC.
- A Circumstance bonus to Shield AC applies to a different component from a Circumstance bonus to Dodge AC, so both contribute to total AC.

### Losing Dodge AC

When a condition makes a character Flat-Footed or says they lose their Dexterity and Dodge bonuses, remove the entire **Dexterity AC** and **Dodge AC** components, regardless of their bonus types. Retain Armor AC, Shield AC, Natural Armor AC, Deflection AC, and Size AC unless a specific effect says otherwise.
