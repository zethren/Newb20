# Project Image

| Spell detail | Rule |
| --- | --- |
| Level | 7 (Wizard) |
| School | Illusion |
| Class | Wizard |
| Spell Lists | Cleric 7th, Wizard 7th |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | 1 minute/CL |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |
