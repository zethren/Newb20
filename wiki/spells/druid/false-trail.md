# False Trail

| Spell detail | Value |
| --- | --- |
| Level | 2 |
| School | Illusion |
| Class | Druid |
| Casting time | Standard Action |
| Range | Touch |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 1 hour |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Create convincing tracks leading from a point you touch for up to 1 mile; they remain visible for 1 hour.
