# Protection from Energy

| Spell detail | Rule |
| --- | --- |
| Level | 3 (Wizard) |
| School | Abjuration |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | Touch |
| Components | V, S |
| Duration | Up to 1 hour/CL |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** Choose acid, cold, electric, fire, or force. The touched creature ignores the first 30 damage of that type; the spell ends after preventing 30 damage or 1 hour/CL.
