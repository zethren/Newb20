# Scintillating Pattern

*8th-level Illusion*

| Spell detail | Rule |
| --- | --- |
| **Level** | 8 |
| **School** | Illusion |
| **Class** | Cleric |
| **Spell Lists** | Cleric 8th, Wizard 8th |
| **Casting Time** | Standard Action |
| **Range** | 120 feet |
| **Components** | V, S |
| **Duration** | 1 round |
| **Attack** | None |
| **Saving Throw** | Will negates |
| **Spell Resistance** | Yes |

## Effect

Colorful lights fill a 20-foot-radius area for 1 round; creatures that fail a Will save become Dazed for 1 round, and successful targets are immune to this casting.
