# Hallucinatory Terrain

| Spell detail | Rule |
| --- | --- |
| Level | 4 (Wizard) |
| School | Illusion |
| Class | Wizard |
| Spell Lists | Cleric 4th, Wizard 4th |
| Casting Time | Standard Action |
| Range | 300 feet |
| Components | V, S |
| Duration | 1 day |
| Attack | None |
| Saving Throw | Will disbelief |
| Spell Resistance | No |

**Effect.** Alter the apparent look, sound, and smell of natural terrain in a 100-foot-radius area for 1 day. Physical objects remain unchanged; interaction permits a Will save to see through it.
