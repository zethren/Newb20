# Sunspore

| Spell detail | Value |
| --- | --- |
| Level | 5 |
| School | Evocation |
| Class | Druid |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | Instantaneous |
| Spell attack | None |
| Saving throw | Constitution half |
| Spell resistance | Yes |

## Effect

Creatures in a 20-foot-radius area take 1d6 holy damage per caster level, with a Constitution save for half.
