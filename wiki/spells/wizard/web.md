# Web

| Spell detail | Rule |
| --- | --- |
| Level | 2 (Wizard) |
| School | Conjuration |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | 10 minutes/CL |
| Attack | None |
| Saving Throw | Reflex negates Entangled |
| Spell Resistance | No |

**Effect.** Fill a 20-foot cube with strands for 10 minutes/CL. Creatures inside make Reflex saves or become Entangled; a trapped creature can escape with a Standard Action and Strength check against your spell DC.
