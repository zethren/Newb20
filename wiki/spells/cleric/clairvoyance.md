# Clairvoyance

*4th-level Divination*

| Spell detail | Rule |
| --- | --- |
| **Level** | 4 |
| **School** | Divination |
| **Class** | Cleric |
| **Casting Time** | Standard Action |
| **Range** | 1 mile |
| **Components** | V, S |
| **Duration** | 10 minutes |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

Place an invisible, stationary sensor at a location you know within 1 mile; for 10 minutes, see and hear from its space as though standing there.
