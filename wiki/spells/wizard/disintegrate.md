# Disintegrate

| Spell detail | Rule |
| --- | --- |
| Level | 6 (Wizard) |
| School | Transmutation |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | Instantaneous |
| Attack | Ranged spell attack (spell attack bonus) |
| Saving Throw | None |
| Spell Resistance | Yes |

**Effect.** A ranged spell attack hit deals 2d6 magic damage per caster level to one creature or object. An object reduced to 0 HP crumbles into dust.
