# Disguise Self

| Spell detail | Rule |
| --- | --- |
| Level | 1 (Wizard) |
| School | Illusion |
| Class | Wizard |
| Spell Lists | Cleric 1st, Wizard 1st |
| Casting Time | Standard Action |
| Range | Self |
| Components | V, S |
| Duration | 1 hour/CL |
| Attack | None |
| Saving Throw | Will disbelief |
| Spell Resistance | Yes |

**Effect.** For 1 hour/CL, alter your apparent clothing and features without changing your size. Touch reveals your unchanged body; close inspection permits a Will save to see through it.
