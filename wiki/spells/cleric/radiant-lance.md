# Radiant Lance

*9th-level Evocation*

| Spell detail | Rule |
| --- | --- |
| **Level** | 9 |
| **School** | Evocation |
| **Class** | Cleric |
| **Casting Time** | Standard Action |
| **Range** | 300 feet |
| **Components** | V, S |
| **Duration** | Instantaneous |
| **Attack** | Ranged spell attack |
| **Saving Throw** | None |
| **Spell Resistance** | Yes |

## Effect

Make a ranged spell attack against one creature; on a hit it takes 2d6 holy damage per caster level, and if reduced to 0 HP by this spell it is stable rather than Dying.
