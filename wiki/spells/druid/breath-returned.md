# Breath Returned

| Spell detail | Value |
| --- | --- |
| Level | 8 |
| School | Necromancy |
| Class | Druid |
| Casting time | Standard Action |
| Range | 300 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | Instantaneous |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Restore one creature dead for no more than 100 years to life with half its hit points; it must have an intact body and cannot have died of old age.
