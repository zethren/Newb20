# Telekinesis

| Spell detail | Rule |
| --- | --- |
| Level | 5 (Wizard) |
| School | Transmutation |
| Class | Wizard |
| Spell Lists | Cleric 7th, Wizard 5th |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | 1 minute/CL |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** Move one unattended object weighing up to 1,000 pounds up to 30 feet each round for 1 minute/CL. It cannot make attacks and stops if it hits a creature.
