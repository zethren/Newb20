# Confusion

*4th-level Enchantment*

| Spell detail | Rule |
| --- | --- |
| **Level** | 4 |
| **School** | Enchantment |
| **Class** | Cleric |
| **Spell Lists** | Cleric 4th, Wizard 4th |
| **Casting Time** | Standard Action |
| **Range** | 90 feet |
| **Components** | V, S |
| **Duration** | 1 round |
| **Attack** | None |
| **Saving Throw** | Will negates; repeat at end of turn |
| **Spell Resistance** | Yes |

## Effect

Up to three creatures in a 20-foot-radius area must pass a Will save or become Berserk for 1 round; they repeat the save at the end of each turn.
