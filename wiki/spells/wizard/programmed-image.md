# Programmed Image

| Spell detail | Rule |
| --- | --- |
| Level | 9 (Wizard) |
| School | Illusion |
| Class | Wizard |
| Spell Lists | Cleric 6th, Wizard 9th |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | Until triggered, then 1 minute |
| Attack | None |
| Saving Throw | Will disbelief |
| Spell Resistance | Yes |

**Effect.** Set a 30-foot-cube visual and audible scene to play when a precise observable trigger occurs. It performs a one-minute sequence, then vanishes; viewers may make Will saves to disbelieve.
