# Life from Loam

| Spell detail | Value |
| --- | --- |
| Level | 6 |
| School | Necromancy |
| Class | Druid |
| Casting time | Standard Action |
| Range | 120 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | Instantaneous |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

One creature that died within the last minute returns to life with 1 hit point; this cannot restore a creature that died of old age.
