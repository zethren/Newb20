# Borrowed Shape

| Spell detail | Value |
| --- | --- |
| Level | 3 |
| School | Illusion |
| Class | Druid |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 1 hour |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

One willing creature appears to be another humanoid of its size for 1 hour; touch reveals the illusion.
