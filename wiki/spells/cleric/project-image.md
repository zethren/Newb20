# Project Image

*7th-level Illusion*

| Spell detail | Rule |
| --- | --- |
| **Level** | 7 |
| **School** | Illusion |
| **Class** | Cleric |
| **Spell Lists** | Cleric 7th, Wizard 7th |
| **Casting Time** | Standard Action |
| **Range** | 1 mile |
| **Components** | V, S |
| **Duration** | 1 minute |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

Create a visible duplicate of yourself within 1 mile for 1 minute; see and speak from its space, but your spells still originate from your real space, and damage to the image ends the spell.
