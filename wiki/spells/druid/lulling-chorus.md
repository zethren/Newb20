# Lulling Chorus

| Spell detail | Value |
| --- | --- |
| Level | 5 |
| School | Enchantment |
| Class | Druid |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 1 minute |
| Spell attack | None |
| Saving throw | Wisdom negates |
| Spell resistance | Yes |

## Effect

Creatures of your choice in a 15-foot-radius area must succeed on Wisdom saves or fall asleep for 1 minute; damage or an adjacent ally's action wakes them.
