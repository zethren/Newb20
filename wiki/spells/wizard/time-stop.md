# Time Stop

| Spell detail | Rule |
| --- | --- |
| Level | 9 (Wizard) |
| School | Transmutation |
| Class | Wizard |
| Spell Lists | Cleric 9th, Wizard 9th |
| Casting Time | Standard Action |
| Range | Self |
| Components | V, S |
| Duration | Two extra turns |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** Immediately after this turn, you take two extra turns. Other creatures and unattended objects cannot move or be affected by your spells during them; you cannot harm another creature before time resumes.
