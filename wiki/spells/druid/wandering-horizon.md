# Wandering Horizon

| Spell detail | Value |
| --- | --- |
| Level | 6 |
| School | Illusion |
| Class | Druid |
| Casting time | Standard Action |
| Range | 120 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 1 hour |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Make a 30-foot-radius area appear to be a different natural setting for 1 hour; physical interaction reveals its true features.
