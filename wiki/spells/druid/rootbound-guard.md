# Rootbound Guard

| Spell detail | Value |
| --- | --- |
| Level | 1 |
| School | Abjuration |
| Class | Druid |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 1 hour/CL |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

A creature gains +2 on saves against forced movement and cannot be knocked prone by ordinary terrain until the duration ends.
