# Murkglass Veil

| Spell detail | Value |
| --- | --- |
| Level | 4 |
| School | Illusion |
| Class | Druid |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 1 minute |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Create a 15-foot-radius visual haze for 1 minute; creatures inside are lightly obscured to creatures outside, but not to one another.
