# Lightning Bolt

*3rd-level Evocation*

| Spell detail | Rule |
| --- | --- |
| **Level** | 3 |
| **School** | Evocation |
| **Class** | Cleric |
| **Spell Lists** | Cleric 3rd, Wizard 3rd |
| **Casting Time** | Standard Action |
| **Range** | Self (60-foot line) |
| **Components** | V, S |
| **Duration** | Instantaneous |
| **Attack** | None |
| **Saving Throw** | Reflex half |
| **Spell Resistance** | Yes |

## Effect

A 60-foot-long, 5-foot-wide line deals 1d6 electric damage per caster level to creatures in it, or half on a successful Reflex save.
