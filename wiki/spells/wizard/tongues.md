# Tongues

| Spell detail | Rule |
| --- | --- |
| Level | 3 (Wizard) |
| School | Divination |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | Touch |
| Components | V, S |
| Duration | 1 hour/CL |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** For 1 hour/CL, understand spoken languages and be understood when speaking. This grants no ability to read writing.
