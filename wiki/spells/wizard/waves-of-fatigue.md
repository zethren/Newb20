# Waves of Fatigue

| Spell detail | Rule |
| --- | --- |
| Level | 5 (Wizard) |
| School | Necromancy |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | Self (30-foot cone) |
| Components | V, S |
| Duration | 10 minutes |
| Attack | None |
| Saving Throw | Fortitude negates |
| Spell Resistance | Yes |

**Effect.** Creatures in a 30-foot cone become Fatigued for 10 minutes; Fortitude saves negate. A creature already Fatigued becomes Exhausted on failure.
