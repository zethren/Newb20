# Calm Emotions

*2nd-level Enchantment*

| Spell detail | Rule |
| --- | --- |
| **Level** | 2 |
| **School** | Enchantment |
| **Class** | Cleric |
| **Casting Time** | Standard Action |
| **Range** | 60 feet |
| **Components** | V, S |
| **Duration** | 1 minute |
| **Attack** | None |
| **Saving Throw** | Will negates |
| **Spell Resistance** | Yes |

## Effect

Creatures in a 15-foot-radius area must pass a Will save or have Berserk and Shaken suppressed for 1 minute; the spell does not change attitudes or prevent self-defense.
