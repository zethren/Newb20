# Mass Heal

*9th-level Necromancy*

| Spell detail | Rule |
| --- | --- |
| **Level** | 9 |
| **School** | Necromancy |
| **Class** | Cleric |
| **Casting Time** | Standard Action |
| **Range** | 60 feet |
| **Components** | V, S |
| **Duration** | Instantaneous |
| **Attack** | None |
| **Saving Throw** | Will half against undead |
| **Spell Resistance** | Yes against undead |

## Effect

Choose up to ten creatures within range. Positive energy restores 10d8 + 1d8 per 4 caster levels + your Wisdom modifier hit points to each living target, up to its maximum. Each undead target instead takes that amount as positive-energy damage and can make a Will save to take half damage.
