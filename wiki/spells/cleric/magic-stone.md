# Magic Stone

*1st-level Transmutation*

| Spell detail | Rule |
| --- | --- |
| **Level** | 1 |
| **School** | Transmutation |
| **Class** | Cleric |
| **Casting Time** | Standard Action |
| **Range** | Touch |
| **Components** | V, S |
| **Duration** | 10 minutes/CL |
| **Attack** | Ranged spell attack when thrown |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

Touch up to three pebbles; for 10 minutes/CL, each can be thrown as a ranged spell attack (60 feet), dealing 1d6 + Wisdom modifier blunt damage on a hit.
