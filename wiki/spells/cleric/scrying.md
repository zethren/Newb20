# Scrying

*5th-level Divination*

| Spell detail | Rule |
| --- | --- |
| **Level** | 5 |
| **School** | Divination |
| **Class** | Cleric |
| **Spell Lists** | Cleric 5th, Wizard 5th |
| **Casting Time** | Standard Action |
| **Range** | Same plane |
| **Components** | V, S |
| **Duration** | 1 minute |
| **Attack** | None |
| **Saving Throw** | Will negates |
| **Spell Resistance** | Yes |

## Effect

Observe a named or familiar creature on the same plane for 1 minute; it can resist with a Will save, and the sensor cannot see through solid barriers.
