# Dominate Person

*5th-level Enchantment*

| Spell detail | Rule |
| --- | --- |
| **Level** | 5 |
| **School** | Enchantment |
| **Class** | Cleric |
| **Spell Lists** | Cleric 5th, Wizard 5th |
| **Casting Time** | Standard Action |
| **Range** | 60 feet |
| **Components** | V, S |
| **Duration** | 1 minute/CL |
| **Attack** | None |
| **Saving Throw** | Will negates; repeat for dangerous commands |
| **Spell Resistance** | Yes |

## Effect

One humanoid that fails a Will save follows your spoken commands for 1 minute/CL; it may save again when ordered to attack an ally or take an obviously suicidal action.
