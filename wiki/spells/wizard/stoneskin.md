# Stoneskin

| Spell detail | Rule |
| --- | --- |
| Level | 4 (Wizard) |
| School | Transmutation |
| Class | Wizard |
| Spell Lists | Cleric 4th, Wizard 4th |
| Casting Time | Standard Action |
| Range | Touch |
| Components | V, S |
| Duration | Up to 10 minutes/CL |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** One willing creature touched reduces physical damage from each weapon hit by 5. The spell lasts 10 minutes/CL or until it prevents 50 total damage.
