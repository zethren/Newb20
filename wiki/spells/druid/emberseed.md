# Emberseed

| Spell detail | Value |
| --- | --- |
| Level | 1 |
| School | Evocation |
| Class | Druid |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | Instantaneous |
| Spell attack | Ranged spell attack (use your spell attack bonus) |
| Saving throw | None |
| Spell resistance | Yes |

## Effect

Make a ranged spell attack against one creature; on a hit it takes 2d6 fire damage plus 1d6 per 3 caster levels.
