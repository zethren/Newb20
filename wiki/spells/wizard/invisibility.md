# Invisibility

| Spell detail | Rule |
| --- | --- |
| Level | 2 (Wizard) |
| School | Illusion |
| Class | Wizard |
| Spell Lists | Cleric 2nd, Wizard 2nd |
| Casting Time | Standard Action |
| Range | Touch |
| Components | V, S |
| Duration | 1 minute/CL |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** You or one willing creature touched becomes visually undetectable for 1 minute/CL. The spell ends for that creature when it attacks or casts a spell.
