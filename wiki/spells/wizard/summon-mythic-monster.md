# Summon Mythic Monster

| Spell detail | Rule |
| --- | --- |
| Level | 9 |
| School | Conjuration |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a carved token representing the creature) |
| Duration | 1 minute |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

## Effect

Summon one Huge monster from another plane in an unoccupied space within range. Choose its appearance; it uses the statistics here and gains no other abilities. It has AC 19 and 150 hit points, moves up to 40 feet on its turn, and can make two melee attacks (+12 to hit, 2d10+6 blunt damage each). It acts immediately after you and vanishes when the spell ends or it is reduced to 0 hit points.
