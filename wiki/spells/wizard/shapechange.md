# Shapechange

| Spell detail | Rule |
| --- | --- |
| Level | 9 (Wizard) |
| School | Transmutation |
| Class | Wizard |
| Spell Lists | Cleric 9th, Wizard 9th |
| Casting Time | Standard Action |
| Range | Self |
| Components | V, S |
| Duration | 1 hour/CL |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** For 1 hour/CL, assume the appearance and movement modes of a beast you have seen, retaining your HP, ability scores, and speech. Apply its listed racial traits and the Polymorph item rules. If the new form cannot fit, use the shared [space and confinement rule](../../game-mechanics/transformations.md#space-and-confines-during-polymorph).
