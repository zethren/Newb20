# Call Lightning Storm

| Spell detail | Value |
| --- | --- |
| Level | 5 |
| School | Evocation |
| Class | Druid |
| Casting time | Standard Action |
| Range | 120 feet |
| Components | V, S |
| Duration | 1 minute/CL |
| Spell attack | None |
| Saving throw | Reflex half |
| Spell resistance | No |

## Effect

Call a bolt into a 10-foot-radius burst centered on a point in range. The initial bolt strikes when the spell is cast; on later turns, you can spend a Standard Action to call one additional bolt. Each creature in the burst takes `2d6 + (1d6 per 2 caster levels, round up)` Electric damage, with no maximum caster-level cap. A successful Reflex save halves the damage.
