# Riverform

| Spell detail | Value |
| --- | --- |
| Level | 4 |
| School | Transmutation |
| Class | Druid |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 1 minute |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

One willing creature becomes fluid enough to pass through gaps as narrow as 1 inch for 1 minute; it cannot attack while compressed.
