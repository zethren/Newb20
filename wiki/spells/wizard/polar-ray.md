# Polar Ray

| Spell detail | Rule |
| --- | --- |
| Level | 8 (Wizard) |
| School | Evocation |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | 1 round |
| Attack | Ranged spell attack (spell attack bonus) |
| Saving Throw | None |
| Spell Resistance | Yes |
