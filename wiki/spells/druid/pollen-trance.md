# Pollen Trance

| Spell detail | Value |
| --- | --- |
| Level | 1 |
| School | Enchantment |
| Class | Druid |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | Instantaneous |
| Spell attack | None |
| Saving throw | Wisdom negates |
| Spell resistance | Yes |

## Effect

One creature must succeed on a Wisdom save or be dazed until the end of its next turn, unable to take Reactions.
