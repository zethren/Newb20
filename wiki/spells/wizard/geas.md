# Geas

| Spell detail | Rule |
| --- | --- |
| Level | 6 (Wizard) |
| School | Enchantment |
| Class | Wizard |
| Spell Lists | Cleric 6th, Wizard 6th |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | 1 day |
| Attack | None |
| Saving Throw | Will negates |
| Spell Resistance | Yes |

**Effect.** Give one creature a task that takes at most 1 day. A failed Will save compels it to pursue the task; it becomes Sickened whenever it deliberately abandons it.
