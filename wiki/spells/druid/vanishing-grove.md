# Vanishing Grove

| Spell detail | Value |
| --- | --- |
| Level | 9 |
| School | Illusion |
| Class | Druid |
| Casting time | Standard Action |
| Range | 300 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 1 minute/CL |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Up to ten willing creatures and their worn gear become invisible for 1 minute/CL; the effect ends for a creature when it attacks or casts a spell.
