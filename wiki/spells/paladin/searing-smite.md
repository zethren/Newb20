# Searing Smite

*1st-level Evocation*

| Spell detail | Rule |
| --- | --- |
| **Level** | 1 |
| **School** | Evocation |
| **Class** | Paladin |
| **Spell Lists** | Paladin 1st |
| **Casting Time** | Standard Action |
| **Range** | Self |
| **Components** | V, S |
| **Duration** | 1 minute or until discharged |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

You imbue one melee weapon you are holding with fire. The next time you hit with a melee weapon attack before the spell ends, the attack deals an extra **1d6 fire damage**, plus **1d6 for every 4 caster levels after 1st** (round down). The spell then ends. Damage Reduction applies normally to this damage.
