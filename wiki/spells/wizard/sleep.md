# Sleep

| Spell detail | Rule |
| --- | --- |
| Level | 1 (Wizard) |
| School | Enchantment |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | 1 minute |
| Attack | None |
| Saving Throw | Will negates |
| Spell Resistance | Yes |

**Effect.** One creature makes a Will save or falls Unconscious for 1 minute. Any damage wakes it; an adjacent creature can wake it with a Standard Action.
