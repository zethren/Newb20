# Arcane Lock

| Spell detail | Rule |
| --- | --- |
| Level | 2 (Wizard) |
| School | Abjuration |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | Touch |
| Components | V, S |
| Duration | 1 day/CL |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** Seal one nonmagical door or lid you touch for 1 day/CL. A pre-existing key still opens it; forcing it requires a Strength check against DC 20 + your caster level.
