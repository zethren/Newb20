# Gate

| Spell detail | Rule |
| --- | --- |
| Level | 9 (Wizard) |
| School | Conjuration |
| Class | Wizard |
| Spell Lists | Cleric 9th, Wizard 9th |
| Casting Time | Standard Action |
| Range | 30 feet |
| Components | V, S |
| Duration | 1 minute/CL |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** Open a two-way, 10-foot-wide portal to a place on another plane you name. It lasts 1 minute/CL, permits passage in either direction, and closes if dismissed.
