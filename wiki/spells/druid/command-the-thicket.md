# Command the Thicket

| Spell detail | Value |
| --- | --- |
| Level | 6 |
| School | Enchantment |
| Class | Druid |
| Casting time | Standard Action |
| Range | 120 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | Instantaneous |
| Spell attack | None |
| Saving throw | Wisdom negates |
| Spell resistance | Yes |

## Effect

One creature must succeed on a Wisdom save or use its next Standard Action to move up to its speed toward a space you indicate; it will not enter obvious danger.
