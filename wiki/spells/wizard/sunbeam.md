# Sunbeam

| Spell detail | Rule |
| --- | --- |
| Level | 7 (Wizard) |
| School | Evocation |
| Class | Wizard |
| Spell Lists | Cleric 6th, Wizard 7th |
| Casting Time | Standard Action |
| Range | Self (60-foot line) |
| Components | V, S |
| Duration | 1 round/CL |
