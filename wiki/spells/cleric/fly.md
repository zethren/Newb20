# Fly

*4th-level Transmutation*

| Spell detail | Rule |
| --- | --- |
| **Level** | 4 |
| **School** | Transmutation |
| **Class** | Cleric |
| **Spell Lists** | Cleric 4th, Wizard 3rd |
| **Casting Time** | Standard Action |
| **Range** | Touch |
| **Components** | V, S |
| **Duration** | 10 minutes |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

One willing creature gains a flying speed equal to its base movement speed for 10 minutes; it must land before the spell ends or fall. See the [flight rules](../../game-mechanics/flight.md).
