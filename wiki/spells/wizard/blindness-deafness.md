# Blindness/Deafness

| Spell detail | Rule |
| --- | --- |
| Level | 2 (Wizard) |
| School | Necromancy |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | Instantaneous |
| Attack | None |
| Saving Throw | Fortitude negates |
| Spell Resistance | Yes |

**Effect.** One creature makes a Fortitude save or becomes Blinded or Deafened (your choice) until cured by magic. Success grants immunity to this casting for 24 hours.
