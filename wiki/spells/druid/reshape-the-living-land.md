# Reshape the Living Land

| Spell detail | Value |
| --- | --- |
| Level | 9 |
| School | Transmutation |
| Class | Druid |
| Casting time | Standard Action |
| Range | 300 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | Instantaneous |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Alter up to ten 20-foot cubes of natural earth, stone, or vegetation into a stable terrain feature; the change is permanent and cannot crush a creature.
