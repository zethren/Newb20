# Misty Step

*2nd-level Conjuration*

| Spell detail | Rule |
| --- | --- |
| **Level** | 2 |
| **School** | Conjuration |
| **Class** | Cleric |
| **Spell Lists** | Cleric 2nd, Wizard 2nd |
| **Casting Time** | Standard Action |
| **Range** | Self |
| **Components** | V, S |
| **Duration** | Instantaneous |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

Teleport yourself to an unoccupied space you can see within 30 feet; this movement does not provoke an Attack of Opportunity or pass through a solid barrier.
