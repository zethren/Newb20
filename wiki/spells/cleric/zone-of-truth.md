# Zone of Truth

*3rd-level Enchantment*

| Spell detail | Rule |
| --- | --- |
| **Level** | 3 |
| **School** | Enchantment |
| **Class** | Cleric |
| **Casting Time** | Standard Action |
| **Range** | 60 feet |
| **Components** | V, S |
| **Duration** | 10 minutes |
| **Attack** | None |
| **Saving Throw** | Will negates |
| **Spell Resistance** | Yes |

## Effect

For 10 minutes, a creature in a 15-foot-radius zone that fails a Will save cannot knowingly speak a lie there, though it may remain silent.
