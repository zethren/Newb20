# Wall of Force

| Spell detail | Rule |
| --- | --- |
| Level | 5 (Wizard) |
| School | Abjuration |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | 1 minute/CL |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** Create a transparent 20-foot-long, 10-foot-high barrier with 100 HP for 1 minute/CL. It blocks creatures and spells requiring a clear path; Disintegrate destroys it.
