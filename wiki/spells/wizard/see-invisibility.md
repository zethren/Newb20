# See Invisibility

| Spell detail | Rule |
| --- | --- |
| Level | 2 (Wizard) |
| School | Divination |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | Self |
| Components | V, S |
| Duration | 10 minutes/CL |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** For 10 minutes/CL, see invisible creatures and objects within 60 feet as faint outlines; solid barriers still block sight.
