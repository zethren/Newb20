# Wall of Fire

*4th-level Evocation*

| Spell detail | Rule |
| --- | --- |
| **Level** | 4 |
| **School** | Evocation |
| **Class** | Cleric |
| **Spell Lists** | Cleric 4th, Wizard 4th |
| **Casting Time** | Standard Action |
| **Range** | 120 feet |
| **Components** | V, S |
| **Duration** | 1 minute |
| **Attack** | None |
| **Saving Throw** | Reflex half |
| **Spell Resistance** | Yes |

## Effect

Create a 30-foot-long, 10-foot-high flame wall for 1 minute; a creature crossing it takes 2d6 fire damage plus 1d6 per 3 caster levels, while a creature ending its turn adjacent takes 1d6 plus 1d6 per 4 caster levels (Reflex half).
