# Circle of Trust

| Spell detail | Value |
| --- | --- |
| Level | 5 |
| School | Enchantment |
| Class | Druid |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 1 hour |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Up to six willing creatures gain advantage on saves against fear and charm for 1 hour.
