# Persistent Image

| Spell detail | Rule |
| --- | --- |
| Level | 5 (Wizard) |
| School | Illusion |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | Until dispelled |
| Attack | None |
| Saving Throw | Will disbelief |
| Spell Resistance | Yes |

**Effect.** Create a moving visual and audible scene in a 30-foot cube that follows a simple sequence you set. It lasts until dispelled; interaction permits a Will save to disbelieve.
