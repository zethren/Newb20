# Phantom Thicket

| Spell detail | Value |
| --- | --- |
| Level | 6 |
| School | Illusion |
| Class | Druid |
| Casting time | Standard Action |
| Range | 120 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 10 minutes |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Create illusory barriers across up to four 10-foot squares for 10 minutes; creatures that investigate can recognize them as unreal.
