# Contagion

| Spell detail | Rule |
| --- | --- |
| Level | 5 (Wizard) |
| School | Necromancy |
| Class | Wizard |
| Spell Lists | Cleric 5th, Wizard 5th |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | 1 hour/CL |
| Attack | None |
| Saving Throw | Fortitude negates |
| Spell Resistance | Yes |

**Effect.** One creature makes a Fortitude save or becomes Sickened for 1 hour/CL and cannot regain HP during that time. This magical illness does not spread.
