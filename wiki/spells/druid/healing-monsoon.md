# Healing Monsoon

| Spell detail | Value |
| --- | --- |
| Level | 7 |
| School | Evocation |
| Class | Druid |
| Casting time | Standard Action |
| Range | 120 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | Instantaneous |
| Spell attack | None |
| Saving throw | Constitution negates |
| Spell resistance | Yes |

## Effect

Creatures of your choice in a 30-foot-radius area regain 1d8 per 3 caster levels (round up) + your Wisdom modifier hit points; undead make Constitution saves or take that amount as holy damage.
