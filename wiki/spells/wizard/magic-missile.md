# Magic Missile

| Spell detail | Rule |
| --- | --- |
| Level | 1 (Wizard) |
| School | Evocation |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | Instantaneous |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | Yes |

**Effect.** Fire three force darts, plus one additional dart for every 2 caster levels after 1st, at visible creatures within range. Each automatically hits and deals 1d4 + 1 magic damage; divide the darts among targets as you choose.
