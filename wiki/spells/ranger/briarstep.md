# Briarstep

| Spell detail | Rule |
| --- | --- |
| Level | 1st |
| School | Transmutation |
| Class | Ranger |
| Casting Time | Bonus Action |
| Range | Self |
| Components | V, S |
| Duration | 1 hour/CL |
| Attack | None |
| Save | None |
| Spell Resistance | No |

## Effect

For the duration, nonmagical natural undergrowth does not reduce your movement. Your movement through such growth makes no more noise than movement across open ground, though this does not hide you from sight, scent, or other senses.
