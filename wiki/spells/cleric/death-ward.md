# Death Ward

*4th-level Abjuration*

| Spell detail | Rule |
| --- | --- |
| **Level** | 4 |
| **School** | Abjuration |
| **Class** | Cleric |
| **Spell Lists** | Cleric 4th, Paladin 4th |
| **Casting Time** | Standard Action |
| **Range** | Touch |
| **Components** | V, S |
| **Duration** | 10 minutes |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

The touched creature ignores the next negative-energy damage or effect that would reduce its maximum hit points; it lasts up to 10 minutes.
