# Restorative Rain

| Spell detail | Value |
| --- | --- |
| Level | 5 |
| School | Evocation |
| Class | Druid |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | Instantaneous |
| Spell attack | None |
| Saving throw | Constitution negates |
| Spell resistance | Yes |

## Effect

Up to six creatures in a 20-foot-radius area each regain 1d8 per 4 caster levels (round up) + your Wisdom modifier hit points; undead instead make Constitution saves or take that amount as holy damage.
