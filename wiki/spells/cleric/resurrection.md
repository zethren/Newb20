# Resurrection

*7th-level Necromancy*

| Spell detail | Rule |
| --- | --- |
| **Level** | 7 |
| **School** | Necromancy |
| **Class** | Cleric |
| **Casting Time** | Standard Action |
| **Range** | Touch |
| **Components** | V, S |
| **Duration** | Instantaneous |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

Touch the remains of a creature dead no longer than one week; if its soul is willing and its head and heart remain, it returns at 1 HP and wakes after receiving further healing or a Short Rest.
