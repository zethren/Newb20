# Mass Cure Moderate Wounds

*6th-level Necromancy*

| Spell detail | Rule |
| --- | --- |
| **Level** | 6 |
| **School** | Necromancy |
| **Class** | Cleric |
| **Casting Time** | Standard Action |
| **Range** | 60 feet |
| **Components** | V, S |
| **Duration** | Instantaneous |
| **Attack** | None |
| **Saving Throw** | Will half against undead |
| **Spell Resistance** | Yes against undead |

## Effect

Choose up to six creatures within range. Positive energy restores 2d8 + 1d8 per 4 caster levels hit points to each living target. Each undead target instead takes that amount as positive-energy damage and can make a Will save to take half damage.
