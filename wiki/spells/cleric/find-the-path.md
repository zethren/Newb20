# Find the Path

*6th-level Divination*

| Spell detail | Rule |
| --- | --- |
| **Level** | 6 |
| **School** | Divination |
| **Class** | Cleric |
| **Spell Lists** | Cleric 6th, Wizard 6th |
| **Casting Time** | Standard Action |
| **Range** | Self |
| **Components** | V, S |
| **Duration** | 1 hour |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

Name a destination you have visited on this plane; for 1 hour, know the shortest walkable route and sense whenever you move farther from it.
