# Weird

*9th-level Illusion*

| Spell detail | Rule |
| --- | --- |
| **Level** | 9 |
| **School** | Illusion |
| **Class** | Cleric |
| **Spell Lists** | Cleric 9th, Wizard 9th |
| **Casting Time** | Standard Action |
| **Range** | 120 feet |
| **Components** | V, S |
| **Duration** | Instantaneous |
| **Attack** | None |
| **Saving Throw** | Will half damage and negates Shaken |
| **Spell Resistance** | Yes |

## Effect

Up to six creatures that fail a Will save take 1d6 psychic damage per caster level and become Shaken for 1 minute; success halves damage and prevents the condition.
