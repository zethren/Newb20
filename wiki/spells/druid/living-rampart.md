# Living Rampart

| Spell detail | Value |
| --- | --- |
| Level | 7 |
| School | Abjuration |
| Class | Druid |
| Casting time | Standard Action |
| Range | 120 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 1 hour |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Raise a 30-foot-long, 10-foot-high barrier of interwoven trunks with AC 15 and 60 hit points; it lasts until destroyed or the duration ends.
