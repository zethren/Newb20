# Ray of Enfeeblement

| Spell detail | Rule |
| --- | --- |
| Level | 2 (Wizard) |
| School | Necromancy |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | 1 minute/CL |
| Attack | Ranged spell attack (spell attack bonus) |
| Saving Throw | None |
| Spell Resistance | Yes |

**Effect.** A ranged spell attack hit gives one creature -4 Strength for 1 minute/CL. Repeated castings do not stack.
