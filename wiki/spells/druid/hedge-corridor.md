# Hedge Corridor

| Spell detail | Value |
| --- | --- |
| Level | 3 |
| School | Conjuration |
| Class | Druid |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 1 hour |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Grow a 30-foot-long, 5-foot-wide passage through nonmagical vegetation; it remains open for the duration and closes when the spell ends.
