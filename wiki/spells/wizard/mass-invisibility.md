# Mass Invisibility

| Spell detail | Rule |
| --- | --- |
| Level | 7 (Wizard) |
| School | Illusion |
| Class | Wizard |
| Spell Lists | Cleric 9th, Wizard 7th |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | 1 minute/CL |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** Up to eight willing creatures become Invisible for 1 minute/CL. The effect ends for each creature immediately after it attacks or casts a spell.
