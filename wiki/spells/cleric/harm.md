# Harm

*6th-level Necromancy*

| Spell detail | Rule |
| --- | --- |
| **Level** | 6 |
| **School** | Necromancy |
| **Class** | Cleric |
| **Casting Time** | Standard Action |
| **Range** | Touch |
| **Components** | V, S |
| **Duration** | Instantaneous |
| **Attack** | None |
| **Saving Throw** | Fortitude half |
| **Spell Resistance** | Yes |

## Effect

One living creature you touch takes 1d8 damage per caster level (Fortitude half), but this cannot reduce it below 1 HP and has no effect on undead.
