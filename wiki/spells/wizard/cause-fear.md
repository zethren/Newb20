| Spell detail | Rule |
| --- | --- |
| Level | 1 (Wizard) |
| School | Necromancy |
| Class | Wizard |
| Spell Lists | Cleric 1st, Wizard 1st |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | 1 minute |
| Attack | None |
