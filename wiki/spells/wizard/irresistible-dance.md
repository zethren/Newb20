# Irresistible Dance

| Spell detail | Rule |
| --- | --- |
| Level | 8 (Wizard) |
| School | Enchantment |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | 1 round |
| Attack | None |
| Saving Throw | Will negates |
| Spell Resistance | Yes |

**Effect.** One creature makes a Will save or dances for 1 round: it cannot move, attack, or cast spells, and attacks against it gain +2. Damage ends the effect.
