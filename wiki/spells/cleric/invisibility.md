# Invisibility

*2nd-level Illusion*

| Spell detail | Rule |
| --- | --- |
| **Level** | 2 |
| **School** | Illusion |
| **Class** | Cleric |
| **Spell Lists** | Cleric 2nd, Wizard 2nd |
| **Casting Time** | Standard Action |
| **Range** | Touch |
| **Components** | V, S |
| **Duration** | 10 minutes |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

A willing creature becomes visually undetectable for 10 minutes and gains Total Concealment; attacking or casting a spell makes it visible immediately.
