# Screen

| Spell detail | Rule |
| --- | --- |
| Level | 8 (Wizard) |
| School | Illusion |
| Class | Wizard |
| Spell Lists | Cleric 8th, Wizard 8th |
| Casting Time | Standard Action |
| Range | 120 feet |
| Components | V, S |
| Duration | 24 hours |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** Hide a 30-foot-radius area from Divination for 24 hours and choose what creatures outside see and hear. A creature physically entering perceives the real area.
