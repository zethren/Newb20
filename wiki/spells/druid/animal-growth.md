# Animal Growth

| Spell detail | Value |
| --- | --- |
| Level | 5 |
| School | Transmutation (Polymorph) |
| Class | Druid |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | 1 minute/CL |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Enlarge up to one animal per caster level; each gains a +1 Enhancement bonus to its Size category, increasing its actual size by one category, up to Colossal. The spell has no effect on an animal already Colossal. Enhancement bonuses to the same value do not stack. Apply all relevant modifiers, space, reach, and natural-attack damage from the new Size in [Combat Scaling](../../game-mechanics/combat-scaling.md#size-modifiers); the spell grants no separate ability-score or AC adjustments. Each affected animal also gains Damage Reduction 10 against nonmagical physical damage; magical weapons and effects bypass it. Worn and carried equipment enlarges with the animal and returns to normal size when separated from it or when the spell ends. Use the shared [space and confinement rule](../../game-mechanics/transformations.md#space-and-confines-during-polymorph). This spell does not command or otherwise influence the affected animals.
