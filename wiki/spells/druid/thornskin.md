# Thornskin

| Spell detail | Value |
| --- | --- |
| Level | 3 |
| School | Transmutation |
| Class | Druid |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 1 minute/CL |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

A willing creature gains a +1 Natural Armor bonus to Natural Armor AC and its unarmed strikes deal 1d6 piercing damage for 1 minute/CL.
