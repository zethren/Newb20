# Dimension Door

| Spell detail | Rule |
| --- | --- |
| Level | 4 (Wizard) |
| School | Conjuration |
| Class | Wizard |
| Spell Lists | Cleric 4th, Wizard 4th |
| Casting Time | Standard Action |
| Range | Self |
| Components | V, S |
| Duration | Instantaneous |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** Teleport yourself and up to three willing creatures within 5 feet to a location you name within 500 feet. If the destination is occupied or enclosed, no one moves.
