# Phantom Stag

| Spell detail | Value |
| --- | --- |
| Level | 4 |
| School | Illusion |
| Class | Druid |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 1 hour |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Create an illusory beast that runs along a route you indicate for up to 1 mile; creatures can recognize it as unreal by touching it.
