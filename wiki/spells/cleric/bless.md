# Bless

*1st-level Enchantment*

| Spell detail | Rule |
| --- | --- |
| **Level** | 1 |
| **School** | Enchantment |
| **Class** | Cleric |
| **Spell Lists** | Cleric 1st, Paladin 1st |
| **Casting Time** | Standard Action |
| **Range** | 30 feet |
| **Components** | V, S |
| **Duration** | 1 minute/CL |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

Choose up to three willing creatures within range; for 1 minute/CL, each gains +1 on attack rolls and saving throws.
