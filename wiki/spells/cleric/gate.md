# Gate

*9th-level Conjuration*

| Spell detail | Rule |
| --- | --- |
| **Level** | 9 |
| **School** | Conjuration |
| **Class** | Cleric |
| **Spell Lists** | Cleric 9th, Wizard 9th |
| **Casting Time** | Standard Action |
| **Range** | 60 feet |
| **Components** | V, S |
| **Duration** | 1 minute/CL |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

Open a 20-foot portal to a place on another plane you have visited; it lasts 1 minute/CL, allows passage in either direction, and summons or compels no one.
