# Horrid Wilting

*8th-level Necromancy*

| Spell detail | Rule |
| --- | --- |
| **Level** | 8 |
| **School** | Necromancy |
| **Class** | Cleric |
| **Spell Lists** | Cleric 8th, Wizard 8th |
| **Casting Time** | Standard Action |
| **Range** | 120 feet |
| **Components** | V, S |
| **Duration** | Instantaneous |
| **Attack** | None |
| **Saving Throw** | Fortitude half |
| **Spell Resistance** | Yes |

## Effect

Up to six living creatures take 1d6 corrupt damage per caster level (Fortitude half); plants and water-based creatures take 1d6 additional damage per 4 caster levels.
