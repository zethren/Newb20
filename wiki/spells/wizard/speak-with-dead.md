# Speak with Dead

| Spell detail | Rule |
| --- | --- |
| Level | 3 (Wizard) |
| School | Necromancy |
| Class | Wizard |
| Spell Lists | Cleric 3rd, Wizard 3rd |
| Casting Time | Standard Action |
| Range | Touch |
| Components | V, S |
| Duration | 3 questions |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** Touch a corpse that died within 7 days and ask three questions. It answers from its own memories and cannot know events after its death.
