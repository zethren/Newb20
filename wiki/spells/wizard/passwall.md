# Passwall

| Spell detail | Rule |
| --- | --- |
| Level | 5 (Wizard) |
| School | Transmutation |
| Class | Wizard |
| Spell Lists | Cleric 5th, Wizard 5th |
| Casting Time | Standard Action |
| Range | Touch |
| Components | V, S |

**Effect.** Open a 5-foot-wide, 8-foot-high passage through up to 10 feet of nonmagical wood, plaster, or stone. It lasts 1 hour, then closes if the space is clear.
