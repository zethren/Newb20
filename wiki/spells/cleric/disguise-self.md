# Disguise Self

*1st-level Illusion*

| Spell detail | Rule |
| --- | --- |
| **Level** | 1 |
| **School** | Illusion |
| **Class** | Cleric |
| **Spell Lists** | Cleric 1st, Wizard 1st |
| **Casting Time** | Standard Action |
| **Range** | Self |
| **Components** | V, S |
| **Duration** | 1 hour |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

Alter your clothing, armor, and features for 1 hour; you cannot change body, voice, or size, and a creature examining you may use an Investigation check against your spell DC to see through it.
