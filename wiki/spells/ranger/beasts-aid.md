# Beast's Aid

| Spell detail | Rule |
| --- | --- |
| Level | 2nd |
| School | Transmutation |
| Class | Ranger |
| Casting Time | Standard Action |
| Range | Touch |
| Components | V, S |
| Duration | 1 hour/CL |
| Attack | None |
| Save | None (willing beast only) |
| Spell Resistance | No |

## Effect

Touch a willing beast. It gains 10 temporary hit points and advantage on the next Strength or Dexterity check it makes before the spell ends. Temporary hit points from this spell do not stack with themselves; retain the larger remaining amount.
