# Teleport

| Spell detail | Rule |
| --- | --- |
| Level | 5 (Wizard) |
| School | Conjuration |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | Self |
| Components | V, S |
| Duration | Instantaneous |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** Transport yourself and up to six willing creatures touching you to a visited place on the same plane, arriving in a safe unoccupied space within 100 feet of it.
