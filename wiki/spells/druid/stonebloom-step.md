# Stonebloom Step

| Spell detail | Value |
| --- | --- |
| Level | 5 |
| School | Conjuration |
| Class | Druid |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 10 minutes |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Open a 5-foot-wide tunnel through natural earth up to 30 feet long; creatures can pass through before it seals after 10 minutes.
