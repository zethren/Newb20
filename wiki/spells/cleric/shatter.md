# Shatter

*5th-level Evocation*

| Spell detail | Rule |
| --- | --- |
| **Level** | 5 |
| **School** | Evocation |
| **Class** | Cleric |
| **Spell Lists** | Cleric 5th, Wizard 2nd |
| **Casting Time** | Standard Action |
| **Range** | 60 feet |
| **Components** | V, S |
| **Duration** | Instantaneous |
| **Attack** | None |
| **Saving Throw** | Fortitude half |
| **Spell Resistance** | Yes |

## Effect

A 10-foot-radius pulse deals 1d6 sonic damage per caster level to creatures and unattended objects (Fortitude half); fragile nonmagical objects that take damage break.
