# Haste

| Spell detail | Rule |
| --- | --- |
| Level | 3 (Wizard) |
| School | Transmutation |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | 1 minute/CL |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** Up to three willing creatures gain +10 feet to all movement speeds for 1 minute/CL and one additional Standard Action on their first turn only.
