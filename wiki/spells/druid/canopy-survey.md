# Canopy Survey

| Spell detail | Value |
| --- | --- |
| Level | 3 |
| School | Divination |
| Class | Druid |
| Casting time | Standard Action |
| Range | Self |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 10 minutes |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

For 10 minutes, you can see through the senses of a tiny plant within 60 feet, though you remain aware of your own surroundings.
