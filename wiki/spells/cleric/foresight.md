# Foresight

*7th-level Divination*

| Spell detail | Rule |
| --- | --- |
| **Level** | 7 |
| **School** | Divination |
| **Class** | Cleric |
| **Spell Lists** | Cleric 7th, Wizard 9th |
| **Casting Time** | Standard Action |
| **Range** | Touch |
| **Components** | V, S |
| **Duration** | 1 hour |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

One willing creature you touch cannot be surprised for 1 hour and gains +2 on Reflex saves and initiative checks.
