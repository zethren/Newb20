# Divine Favor

*1st-level Evocation*

| Spell detail | Rule |
| --- | --- |
| **Level** | 1 |
| **School** | Evocation |
| **Class** | Paladin |
| **Spell Lists** | Paladin 1st |
| **Casting Time** | Standard Action |
| **Range** | Self |
| **Components** | V, S |
| **Duration** | 1 minute |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

For the duration, you gain a +1 Luck bonus on weapon attack rolls and weapon damage rolls. The bonus increases to +2 at caster level 5 and +3 at caster level 9. This bonus does not stack with other Luck bonuses to the same rolls.
