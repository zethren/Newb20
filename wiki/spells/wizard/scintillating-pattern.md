# Scintillating Pattern

| Spell detail | Rule |
| --- | --- |
| Level | 8 (Wizard) |
| School | Illusion |
| Class | Wizard |
| Spell Lists | Cleric 8th, Wizard 8th |
| Casting Time | Standard Action |
| Range | 120 feet |
| Components | V, S |
| Duration | 1 round |
| Attack | None |
| Saving Throw | Will negates |
| Spell Resistance | Yes |

**Effect.** A 20-foot-radius color pattern lasts 1 round. Creatures that see it make Will saves or become Dazed for 1 round; a successful save grants immunity to this casting.
