# Secure Shelter

| Spell detail | Rule |
| --- | --- |
| Level | 4 (Wizard) |
| School | Conjuration |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | 30 feet |
| Components | V, S |
| Duration | 12 hours |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** Conjure a locked cottage for up to eight creatures on a level, unoccupied surface. It contains eight beds, a table, and a fireplace; it lasts 12 hours and disappears when empty.
