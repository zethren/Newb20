# Seasoned Tracker

| Spell detail | Rule |
| --- | --- |
| Level | 4th |
| School | Divination |
| Class | Ranger |
| Casting Time | 1 minute |
| Range | Self |
| Components | V, S |
| Duration | 1 hour |
| Attack | None |
| Save | Wisdom, negates |
| Spell Resistance | Yes |

## Effect

Name or vividly recall one creature whose tracks, scent, or other trail you have examined. If it is within 5 miles and on the same plane, you learn its direction and whether it is moving, hiding, or stationary. The creature may make a Wisdom saving throw; on a success, the spell yields no information about it. This spell does not reveal an exact location or cross a planar boundary.
