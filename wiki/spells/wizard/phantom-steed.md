# Phantom Steed

| Spell detail | Rule |
| --- | --- |
| Level | 3 (Wizard) |
| School | Conjuration |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | 10 feet |
| Components | V, S |
| Duration | 1 hour/CL |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** Conjure a horse-sized mount for yourself for 1 hour/CL. It carries you at twice your normal speed and crosses gaps up to 10 feet; it vanishes if you dismount or it takes damage.
