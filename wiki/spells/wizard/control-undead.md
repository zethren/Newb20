# Control Undead

| Spell detail | Rule |
| --- | --- |
| Level | 7 (Wizard) |
| School | Necromancy |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | 1 hour |
| Attack | None |
| Saving Throw | Will negates; repeat when damaged |
| Spell Resistance | Yes |

**Effect.** One undead creature makes a Will save or follows your spoken commands for 1 hour. It repeats the save whenever damaged, ending the spell on success.
