# Flame Strike

| Spell detail | Rule |
| --- | --- |
| Level | 5 (Wizard) |
| School | Evocation |
| Class | Wizard |
| Spell Lists | Cleric 5th, Wizard 5th |
| Casting Time | Standard Action |
| Range | 120 feet |
| Components | V, S |
| Duration | Instantaneous |
| Attack | None |
| Saving Throw | Reflex half |
| Spell Resistance | Yes |

**Effect.** A 10-foot-wide, 40-foot-high column deals 1d6 damage per caster level, half fire and half force. Creatures in it make Reflex saves to halve the total.
