# Shapechange

*9th-level Transmutation*

| Spell detail | Rule |
| --- | --- |
| **Level** | 9 |
| **School** | Transmutation |
| **Class** | Cleric |
| **Spell Lists** | Cleric 9th, Wizard 9th |
| **Casting Time** | Standard Action |
| **Range** | Self |
| **Components** | V, S |
| **Duration** | 1 hour |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

For 1 hour, take the form of a beast or humanoid you have seen, within one size category of your own; retain ability scores and HP but gain that form’s movement modes and natural attacks. If the new form cannot fit, use the shared [space and confinement rule](../../game-mechanics/transformations.md#space-and-confines-during-polymorph).
