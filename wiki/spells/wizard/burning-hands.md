# Burning Hands

| Spell detail | Rule |
| --- | --- |
| Level | 1 (Wizard) |
| School | Evocation |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | Self (15-foot cone) |
| Components | V, S |
| Duration | Instantaneous |
| Attack | None |
| Saving Throw | Reflex half |
| Spell Resistance | Yes |

**Effect.** Creatures in a 15-foot cone take 1d4 fire damage per caster level, Reflex half. Unattended paper and tinder in the cone ignite.
