# Commune

*5th-level Divination*

| Spell detail | Rule |
| --- | --- |
| **Level** | 5 |
| **School** | Divination |
| **Class** | Cleric |
| **Casting Time** | Standard Action |
| **Range** | Self |
| **Components** | V, S |
| **Duration** | Instantaneous |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

Ask up to three yes-or-no questions about events within one day; the GM answers truthfully yes, no, or uncertain, without explanation.
