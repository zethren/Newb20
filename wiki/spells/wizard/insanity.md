# Insanity

| Spell detail | Rule |
| --- | --- |
| Level | 7 (Wizard) |
| School | Enchantment |
| Class | Wizard |
| Spell Lists | Cleric 7th, Wizard 7th |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | 1 minute/CL |
| Attack | None |
| Saving Throw | Will negates; repeat each turn |
| Spell Resistance | Yes |

**Effect.** One creature makes a Will save or becomes Confused for 1 minute/CL. It repeats the save at the end of each turn.
