# Heal

*6th-level Necromancy*

| Spell detail | Rule |
| --- | --- |
| **Level** | 6 |
| **School** | Necromancy |
| **Class** | Cleric |
| **Casting Time** | Standard Action |
| **Range** | Touch |
| **Components** | V, S |
| **Duration** | Instantaneous |
| **Attack** | None |
| **Saving Throw** | Will half against undead |
| **Spell Resistance** | Yes against undead |

## Effect

Positive energy restores 6d8 + 1d8 per 3 caster levels + your Wisdom modifier hit points to one living creature you touch, up to its maximum. An undead creature instead takes that amount as positive-energy damage and can make a Will save to take half damage.
