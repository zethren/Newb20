# Nullseed Ward

| Spell detail | Value |
| --- | --- |
| Level | 6 |
| School | Abjuration |
| Class | Druid |
| Casting time | Standard Action |
| Range | 120 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 1 hour |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Choose one creature; the next spell of 6th level or lower that targets it is negated, ending this ward.
