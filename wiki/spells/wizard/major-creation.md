# Major Creation

| Spell detail | Rule |
| --- | --- |
| Level | 5 (Wizard) |
| School | Conjuration |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | 1 hour/CL |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** Create one nonmagical, nonprecious object no larger than a 5-foot cube. It lasts 1 hour/CL and cannot be food, a weapon, or a working mechanism.
