# Weatherproof Mantle

| Spell detail | Value |
| --- | --- |
| Level | 5 |
| School | Abjuration |
| Class | Druid |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 1 hour |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Up to four creatures gain resistance to one chosen energy type (acid, cold, fire, or lightning) for the duration.
