# Stillwater Shelter

| Spell detail | Value |
| --- | --- |
| Level | 2 |
| School | Abjuration |
| Class | Druid |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 1 hour/CL |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

A creature gains resistance to cold damage and advantage on checks to resist being moved by water or wind for the duration.
