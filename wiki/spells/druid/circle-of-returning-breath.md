# Circle of Returning Breath

| Spell detail | Value |
| --- | --- |
| Level | 5 |
| School | Necromancy |
| Class | Druid |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 1 hour |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Up to six creatures gain 3d8 temporary hit points for 1 hour; an affected creature that drops to 0 hit points can instead drop to 1 once, ending this spell for it.
