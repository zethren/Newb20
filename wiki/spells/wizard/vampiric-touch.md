# Vampiric Touch

| Spell detail | Rule |
| --- | --- |
| Level | 3 (Wizard) |
| School | Necromancy |
| Class | Wizard |
| Spell Lists | Cleric 3rd, Wizard 3rd |
| Casting Time | Standard Action |
| Range | Touch |
| Components | V, S |
| Duration | Instantaneous |
| Attack | Melee spell attack (spell attack bonus) |
| Saving Throw | None |
| Spell Resistance | Yes |

**Effect.** A melee spell attack hit deals 1d6 corrupt damage per caster level; regain HP equal to half the damage dealt, rounded down.
