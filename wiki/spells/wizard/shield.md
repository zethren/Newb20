# Shield

| Spell detail | Rule |
| --- | --- |
| Level | 1 (Wizard) |
| School | Abjuration |
| Class | Wizard |
| Casting Time | Reaction |
| Range | Self |
| Components | V, S |
| Duration | 1 round |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** As a Reaction when an attack roll against you is declared, gain a +4 Shield bonus to Shield AC until your next turn. This does not stack with the Shield bonus from a wielded shield. Magic Missile spells cannot hit you during that time.
