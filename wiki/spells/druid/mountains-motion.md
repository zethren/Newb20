# Mountain's Motion

| Spell detail | Value |
| --- | --- |
| Level | 7 |
| School | Transmutation |
| Class | Druid |
| Casting time | Standard Action |
| Range | 120 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | Instantaneous |
| Spell attack | None |
| Saving throw | Dexterity negates |
| Spell resistance | Yes |

## Effect

Move one 20-foot cube of natural earth up to 30 feet along the ground; creatures on it move with it unless they succeed on a Dexterity save.
