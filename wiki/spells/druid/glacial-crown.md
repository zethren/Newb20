# Glacial Crown

| Spell detail | Value |
| --- | --- |
| Level | 6 |
| School | Evocation |
| Class | Druid |
| Casting time | Standard Action |
| Range | 120 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | Instantaneous |
| Spell attack | None |
| Saving throw | Dexterity half |
| Spell resistance | Yes |

## Effect

Creatures in a 20-foot-radius area take 1d6 cold damage per caster level, with a Dexterity save for half; failed saves also reduce speed to 0 until your next turn.
