# Spell Turning

*7th-level Abjuration*

| Spell detail | Rule |
| --- | --- |
| **Level** | 7 |
| **School** | Abjuration |
| **Class** | Cleric |
| **Spell Lists** | Cleric 7th, Wizard 9th |
| **Casting Time** | Standard Action |
| **Range** | Self |
| **Components** | V, S |
| **Duration** | 1 minute/CL |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

For 1 minute/CL, reflect the first spell of 5th level or lower that targets only you back at its caster; it cannot reflect area or multi-target spells.
