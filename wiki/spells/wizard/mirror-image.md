# Mirror Image

| Spell detail | Rule |
| --- | --- |
| Level | 2 (Wizard) |
| School | Illusion |
| Class | Wizard |
| Spell Lists | Cleric 2nd, Wizard 2nd |
| Casting Time | Standard Action |
| Range | Self |
| Components | V, S |
| Duration | 1 minute/CL |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** Three duplicates mimic your movements for 1 minute/CL. When an attack hits your AC, roll d4: 1-3 destroys a duplicate instead; 4 hits you.
