# Programmed Image

*6th-level Illusion*

| Spell detail | Rule |
| --- | --- |
| **Level** | 6 |
| **School** | Illusion |
| **Class** | Cleric |
| **Spell Lists** | Cleric 6th, Wizard 9th |
| **Casting Time** | Standard Action |
| **Range** | 120 feet |
| **Components** | V, S |
| **Duration** | 1 day or until triggered |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

Set a visual and audible illusion within a 20-foot cube; it waits up to a day for a creature you specify to enter, then plays for no more than 10 minutes.
