# Delayed Blast Fireball

| Spell detail | Rule |
| --- | --- |
| Level | 7 (Wizard) |
| School | Evocation |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | 150 feet |
| Components | V, S |
| Duration | Up to 1 minute |
| Attack | None |
| Saving Throw | Reflex half |
| Spell Resistance | Yes |

**Effect.** Set a glowing bead at a point within range. As a Standard Action within 1 minute you may detonate it in a 30-foot radius for 1d6 fire damage per caster level, Reflex half; otherwise it bursts when time expires.
