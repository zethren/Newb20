# Crownfire Arc

| Spell detail | Value |
| --- | --- |
| Level | 7 |
| School | Evocation |
| Class | Druid |
| Casting time | Standard Action |
| Range | 120 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | Instantaneous |
| Spell attack | None |
| Saving throw | Dexterity half |
| Spell resistance | Yes |

## Effect

Choose up to three creatures within 60 feet; each takes 1d8 fire damage per 2 caster levels (round up), with a Dexterity save for half.
