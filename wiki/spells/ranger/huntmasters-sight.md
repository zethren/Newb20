# Huntmaster's Sight

| Spell detail | Rule |
| --- | --- |
| Level | 3rd |
| School | Divination |
| Class | Ranger |
| Casting Time | Standard Action |
| Range | Self |
| Components | V, S |
| Duration | 10 minutes |
| Attack | None |
| Save | None |
| Spell Resistance | No |

## Effect

You perceive subtle traces of recent passage within 60 feet: disturbed leaves, bent grass, warmth, and similar signs. You can tell how many creatures passed, their approximate size, and whether they moved quickly or slowly during the last hour. The spell does not reveal their identity, exact path, or present location, and cannot detect passage through a sealed barrier.
