# Control Weather

*8th-level Transmutation*

| Spell detail | Rule |
| --- | --- |
| **Level** | 8 |
| **School** | Transmutation |
| **Class** | Cleric |
| **Casting Time** | Standard Action |
| **Range** | Self (1-mile radius) |
| **Components** | V, S |
| **Duration** | 1 hour |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

Gradually change natural weather in a 1-mile radius to clear, cloud, rain, snow, or wind over 10 minutes; the chosen weather lasts 1 hour and cannot create a storm.
