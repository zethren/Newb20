# Plane Shift

| Spell detail | Rule |
| --- | --- |
| Level | 7 (Wizard) |
| School | Conjuration |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | Touch |
| Components | V, S |
| Duration | Instantaneous |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** You and up to six willing creatures touching you travel to a plane you name, arriving at a safe location there. Unwilling creatures cannot travel with you.
