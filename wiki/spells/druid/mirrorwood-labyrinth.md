# Mirrorwood Labyrinth

| Spell detail | Value |
| --- | --- |
| Level | 8 |
| School | Illusion |
| Class | Druid |
| Casting time | Standard Action |
| Range | 300 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 1 hour |
| Spell attack | None |
| Saving throw | Wisdom negates |
| Spell resistance | Yes |

## Effect

Make a 60-foot-radius natural area appear to contain shifting paths for 1 hour; a creature that fails a Wisdom save treats the area as difficult terrain and cannot willingly leave it.
