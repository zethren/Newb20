# Insanity

*7th-level Enchantment*

| Spell detail | Rule |
| --- | --- |
| **Level** | 7 |
| **School** | Enchantment |
| **Class** | Cleric |
| **Spell Lists** | Cleric 7th, Wizard 7th |
| **Casting Time** | Standard Action |
| **Range** | 60 feet |
| **Components** | V, S |
| **Duration** | 1 minute |
| **Attack** | None |
| **Saving Throw** | Will negates; repeat at end of turn |
| **Spell Resistance** | Yes |

## Effect

A creature that fails a Will save is Staggered and cannot take Reactions for 1 minute; it repeats the save at the end of each turn to end the spell.
