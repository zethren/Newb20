# Discern Location

| Spell detail | Rule |
| --- | --- |
| Level | 8 (Wizard) |
| School | Divination |
| Class | Wizard |
| Spell Lists | Cleric 8th, Wizard 8th |
| Casting Time | Standard Action |
| Range | Self |
| Components | V, S |
| Duration | Instantaneous |
| Attack | None |
| Saving Throw | None |
