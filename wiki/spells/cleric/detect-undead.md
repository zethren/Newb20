# Detect Undead

*1st-level Divination*

| Spell detail | Rule |
| --- | --- |
| **Level** | 1 |
| **School** | Divination |
| **Class** | Cleric |
| **Casting Time** | Standard Action |
| **Range** | Self |
| **Components** | V, S |
| **Duration** | 10 minutes |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

For 10 minutes, sense undead within 60 feet and their direction; a thin layer of stone blocks the sense, which does not reveal identity or exact location.
