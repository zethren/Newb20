# Augury

*3rd-level Divination*

| Spell detail | Rule |
| --- | --- |
| **Level** | 3 |
| **School** | Divination |
| **Class** | Cleric |
| **Casting Time** | Standard Action |
| **Range** | Self |
| **Components** | V, S |
| **Duration** | Instantaneous |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

Ask whether one specific action you plan within 30 minutes will bring good, bad, both, or neither; the GM gives an honest omen but does not explain its reasoning.
