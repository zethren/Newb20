# Greater Teleport

*7th-level Conjuration*

| Spell detail | Rule |
| --- | --- |
| **Level** | 7 |
| **School** | Conjuration |
| **Class** | Cleric |
| **Spell Lists** | Cleric 7th, Wizard 7th |
| **Casting Time** | Standard Action |
| **Range** | Touch |
| **Components** | V, S |
| **Duration** | Instantaneous |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

Teleport yourself and up to six willing creatures within 5 feet to a place you have visited anywhere on this plane; each arrives in a space you designate or the nearest safe space.
