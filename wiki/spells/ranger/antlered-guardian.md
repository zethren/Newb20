# Antlered Guardian

| Spell detail | Rule |
| --- | --- |
| Level | 3rd |
| School | Conjuration |
| Class | Ranger |
| Casting Time | Standard Action |
| Range | 30 feet |
| Components | V, S, a twig |
| Duration | 1 minute |
| Attack | None |
| Save | None |
| Spell Resistance | No |

## Effect

An antlered spirit appears in an unoccupied space you can see within range and guards one creature you choose within 10 feet of it. When a hostile creature enters the guarded creature's reach, the spirit can use its Reaction to impose disadvantage on that creature's next attack before the start of its next turn. The spirit occupies its space but cannot attack, move, or take other actions. It vanishes if reduced to 0 hit points (AC 13, 20 hit points) or when the spell ends.
