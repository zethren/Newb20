# Borrowed Vitality

| Spell detail | Value |
| --- | --- |
| Level | 3 |
| School | Necromancy |
| Class | Druid |
| Casting time | Standard Action |
| Range | Self |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 1 hour |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

You or one willing creature gains 2d8 temporary hit points for 1 hour; they vanish when the duration ends.
