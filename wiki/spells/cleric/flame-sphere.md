# Flame Sphere

*2nd-level Evocation*

| Spell detail | Rule |
| --- | --- |
| **Level** | 2 |
| **School** | Evocation |
| **Class** | Cleric |
| **Casting Time** | Standard Action |
| **Range** | 60 feet |
| **Components** | V, S |
| **Duration** | 1 minute |
| **Attack** | None |
| **Saving Throw** | Reflex negates damage |
| **Spell Resistance** | Yes |

## Effect

A 5-foot fire sphere lasts 1 minute; as a Move Action, roll it up to 20 feet, dealing 2d6 fire damage to each creature it passes through, no more than once per turn (Reflex negates).
