# Inflict Wounds

*1st-level Necromancy*

| Spell detail | Rule |
| --- | --- |
| **Level** | 1 |
| **School** | Necromancy |
| **Class** | Cleric |
| **Casting Time** | Standard Action |
| **Range** | Touch |
| **Components** | V, S |
| **Duration** | Instantaneous |
| **Attack** | Melee spell attack |
| **Saving Throw** | None |
| **Spell Resistance** | Yes |

## Effect

Make a melee spell attack against a creature you touch; on a hit, a living target takes 2d8 negative-energy damage plus 1d8 per 3 caster levels, while an undead target regains that many hit points.
