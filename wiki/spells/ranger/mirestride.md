# Mirestride

| Spell detail | Rule |
| --- | --- |
| Level | 2nd |
| School | Transmutation |
| Class | Ranger |
| Casting Time | Bonus Action |
| Range | Self |
| Components | V, S |
| Duration | 10 minutes |
| Attack | None |
| Save | None |
| Spell Resistance | No |

## Effect

For the duration, mud, shallow water, loose scree, and similar unstable natural surfaces do not count as difficult terrain for you. You can move across liquid surfaces, but must end each turn on a surface that can support you or fall through.
