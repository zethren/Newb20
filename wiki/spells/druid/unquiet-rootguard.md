# Unquiet Rootguard

| Spell detail | Value |
| --- | --- |
| Level | 7 |
| School | Necromancy |
| Class | Druid |
| Casting time | Standard Action |
| Range | 120 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 1 minute |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Animate one Large dead tree as a guardian (AC 15, 70 hit points) for 1 minute; it obeys commands and attacks once each round (+7 to hit, 3d8+4 blunt).
