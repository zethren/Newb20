# Detect Magic

| Spell detail | Rule |
| --- | --- |
| Level | 1 (Wizard) |
| School | Divination |
| Class | Wizard |
| Spell Lists | Cleric 1st, Wizard 1st |
| Casting Time | Standard Action |
| Range | Self |
| Components | V, S |
| Duration | 10 minutes/CL |
| Attack | None |
| Saving Throw | None |
