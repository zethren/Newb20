# Elderwood Refuge

| Spell detail | Value |
| --- | --- |
| Level | 8 |
| School | Abjuration |
| Class | Druid |
| Casting time | Standard Action |
| Range | 300 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 1 hour |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Form a sealed, 20-foot-radius refuge for up to ten creatures; it has AC 18 and 120 hit points, and its occupants have total cover from outside.
