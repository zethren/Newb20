# Screen

*8th-level Illusion*

| Spell detail | Rule |
| --- | --- |
| **Level** | 8 |
| **School** | Illusion |
| **Class** | Cleric |
| **Spell Lists** | Cleric 8th, Wizard 8th |
| **Casting Time** | Standard Action |
| **Range** | Touch |
| **Components** | V, S |
| **Duration** | 24 hours |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

For 24 hours, conceal a 30-foot cube from divination and remote viewing; choose what it appears and sounds like from outside, while creatures inside see the true area.
