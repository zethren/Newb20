# Renewal of the First Rain

| Spell detail | Value |
| --- | --- |
| Level | 9 |
| School | Evocation |
| Class | Druid |
| Casting time | Standard Action |
| Range | 300 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | Instantaneous |
| Spell attack | None |
| Saving throw | Constitution negates |
| Spell resistance | Yes |

## Effect

Up to ten creatures in a 40-foot-radius area regain 1d8 per 2 caster levels (round up) + your Wisdom modifier hit points and end one poison or disease affecting each; undead make Constitution saves or take the healing amount as holy damage.
