# Grove Bastion

| Spell detail | Value |
| --- | --- |
| Level | 4 |
| School | Abjuration |
| Class | Druid |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | Concentration, up to 1 minute |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Create a 15-foot-radius ward centered on you; allies inside gain a +2 Circumstance bonus to Shield AC against attacks from outside the ward for the duration.
