# Charm Person

| Spell detail | Rule |
| --- | --- |
| Level | 1 (Wizard) |
| School | Enchantment |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | 1 hour/CL |
| Attack | None |
| Saving Throw | Will negates |
| Spell Resistance | Yes |

**Effect.** One humanoid makes a Will save or regards you as a trusted acquaintance for 1 hour/CL. Your allies’ attack ends the spell.
