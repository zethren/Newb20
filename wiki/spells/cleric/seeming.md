# Seeming

*5th-level Illusion*

| Spell detail | Rule |
| --- | --- |
| **Level** | 5 |
| **School** | Illusion |
| **Class** | Cleric |
| **Casting Time** | Standard Action |
| **Range** | 30 feet |
| **Components** | V, S |
| **Duration** | 12 hours |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

Up to eight willing creatures appear as different humanoids of similar size for 12 hours; touch reveals the true form, and the illusion cannot change anyone’s voice.
