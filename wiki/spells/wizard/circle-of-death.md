# Circle of Death

| Spell detail | Rule |
| --- | --- |
| Level | 6 (Wizard) |
| School | Necromancy |
| Class | Wizard |
| Spell Lists | Cleric 6th, Wizard 6th |
| Casting Time | Standard Action |
| Range | 150 feet |
| Components | V, S |
| Duration | Instantaneous |
| Attack | None |
| Saving Throw | Fortitude half |
| Spell Resistance | Yes |

**Effect.** Creatures in a 20-foot-radius burst make Fortitude saves or take 1d6 corrupt damage per caster level. A creature reduced to 0 HP by this spell dies; success halves damage.
