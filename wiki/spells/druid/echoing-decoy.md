# Echoing Decoy

| Spell detail | Value |
| --- | --- |
| Level | 5 |
| School | Illusion |
| Class | Druid |
| Casting time | Standard Action |
| Range | Self |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 1 minute |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Create three illusory copies of a creature you can see; attacks against it have a 25% chance to hit a copy and miss, for 1 minute.
