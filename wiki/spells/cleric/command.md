# Command

*1st-level Enchantment*

| Spell detail | Rule |
| --- | --- |
| **Level** | 1 |
| **School** | Enchantment |
| **Class** | Cleric |
| **Spell Lists** | Cleric 1st, Paladin 1st |
| **Casting Time** | Standard Action |
| **Range** | 30 feet |
| **Components** | V, S |
| **Duration** | 1 round |
| **Attack** | None |
| **Saving Throw** | Will negates |
| **Spell Resistance** | Yes |

## Effect

Speak a short order to a creature that understands you; on a failed Will save, it spends its next turn obeying if possible and not directly endangering itself.
