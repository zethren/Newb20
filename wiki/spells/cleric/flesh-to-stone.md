# Flesh to Stone

*6th-level Transmutation*

| Spell detail | Rule |
| --- | --- |
| **Level** | 6 |
| **School** | Transmutation |
| **Class** | Cleric |
| **Spell Lists** | Cleric 6th, Wizard 8th |
| **Casting Time** | Standard Action |
| **Range** | 60 feet |
| **Components** | V, S |
| **Duration** | 1 minute |
| **Attack** | None |
| **Saving Throw** | Fortitude negates; repeat at end of turn |
| **Spell Resistance** | Yes |

## Effect

One creature that fails a Fortitude save becomes rigid and Paralyzed for 1 minute, though still alive; it repeats the save at each turn’s end to end the spell.
