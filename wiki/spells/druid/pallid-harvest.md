# Pallid Harvest

| Spell detail | Value |
| --- | --- |
| Level | 4 |
| School | Necromancy |
| Class | Druid |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | Instantaneous |
| Spell attack | None |
| Saving throw | Constitution half |
| Spell resistance | Yes |

## Effect

Creatures in a 15-foot-radius area make Constitution saves, taking 1d6 corrupt damage per caster level on a failure or half on a success; you regain hit points equal to half total damage dealt.
