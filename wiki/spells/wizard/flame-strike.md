| Spell detail | Rule |
| --- | --- |
| Level | 5 (Wizard) |
| School | Evocation |
| Class | Wizard |
| Spell Lists | Cleric 5th, Wizard 5th |
| Casting Time | Standard Action |
| Range | 120 feet |
| Components | V, S |
| Duration | Instantaneous |
| Attack | None |
