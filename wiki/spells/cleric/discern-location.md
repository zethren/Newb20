# Discern Location

*8th-level Divination*

| Spell detail | Rule |
| --- | --- |
| **Level** | 8 |
| **School** | Divination |
| **Class** | Cleric |
| **Spell Lists** | Cleric 8th, Wizard 8th |
| **Casting Time** | Standard Action |
| **Range** | Unlimited |
| **Components** | V, S |

| **Saving Throw** | None |

## Effect

Name a known creature or object to learn its exact location, plane, and distance despite barriers or lesser divination wards; artifacts and deities may elude this spell.
