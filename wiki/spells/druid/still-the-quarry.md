# Still the Quarry

| Spell detail | Value |
| --- | --- |
| Level | 4 |
| School | Enchantment |
| Class | Druid |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 1 minute |
| Spell attack | None |
| Saving throw | Wisdom negates |
| Spell resistance | Yes |

## Effect

One creature must succeed on a Wisdom save or have disadvantage on attacks against creatures other than you for 1 minute.
