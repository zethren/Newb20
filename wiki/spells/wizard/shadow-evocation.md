# Shadow Evocation

| Spell detail | Rule |
| --- | --- |
| Level | 5 (Wizard) |
| School | Illusion |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | Instantaneous |
| Attack | None |
| Saving Throw | Will disbelief; original save also applies |
| Spell Resistance | Yes |

**Effect.** Reproduce one Evocation spell of 4th level or lower that you know, using its range and save. It deals half normal damage; a successful Will save to disbelieve negates damage.
