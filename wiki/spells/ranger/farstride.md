# Farstride

| Spell detail | Rule |
| --- | --- |
| Level | 3rd |
| School | Transmutation |
| Class | Ranger |
| Casting Time | 1 minute |
| Range | 30 feet |
| Components | V, S |
| Duration | 8 hours |
| Attack | None |
| Save | None (willing creatures only) |
| Spell Resistance | No |

## Effect

Choose up to six willing creatures within range. For the duration, their overland travel speed increases by 1 mile per hour, and they have advantage on Constitution checks made to resist exhaustion from forced marches. The spell does not prevent exhaustion or aid travel by magic, vehicle, or flight.
