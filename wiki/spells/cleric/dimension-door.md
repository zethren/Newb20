# Dimension Door

*4th-level Conjuration*

| Spell detail | Rule |
| --- | --- |
| **Level** | 4 |
| **School** | Conjuration |
| **Class** | Cleric |
| **Spell Lists** | Cleric 4th, Wizard 4th |
| **Casting Time** | Standard Action |
| **Range** | Touch |
| **Components** | V, S |
| **Duration** | Instantaneous |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

You and up to three willing creatures touching you teleport to a place you have seen within 500 feet; if any arrival space is occupied, nobody moves.
