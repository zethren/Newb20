# Charm Monster

*4th-level Enchantment*

| Spell detail | Rule |
| --- | --- |
| **Level** | 4 |
| **School** | Enchantment |
| **Class** | Cleric |
| **Spell Lists** | Cleric 4th, Wizard 4th |
| **Casting Time** | Standard Action |
| **Range** | 30 feet |
| **Components** | V, S |
| **Duration** | 1 hour |
| **Attack** | None |
| **Saving Throw** | Will negates |
| **Spell Resistance** | Yes |

## Effect

One creature that fails a Will save regards you as a trusted acquaintance for 1 hour, but will not attack you unless you or your allies harm it; it retains its choices.
