# Suggestion

*3rd-level Enchantment*

| Spell detail | Rule |
| --- | --- |
| **Level** | 3 |
| **School** | Enchantment |
| **Class** | Cleric |
| **Spell Lists** | Cleric 3rd, Wizard 3rd |
| **Casting Time** | Standard Action |
| **Range** | 30 feet |
| **Components** | V, S |
| **Duration** | Up to 8 hours |
| **Attack** | None |
| **Saving Throw** | Will negates |
| **Spell Resistance** | Yes |

## Effect

Give one creature that understands you a reasonable task completable within 8 hours; on a failed Will save it follows the instruction but will not knowingly harm itself or an ally.
