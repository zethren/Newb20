# Prismatic Ward

*9th-level Abjuration*

| Spell detail | Rule |
| --- | --- |
| **Level** | 9 |
| **School** | Abjuration |
| **Class** | Cleric |
| **Casting Time** | Standard Action |
| **Range** | 60 feet |
| **Components** | V, S |
| **Duration** | 1 minute |
| **Attack** | None |
| **Saving Throw** | Reflex half |
| **Spell Resistance** | Yes |

## Effect

A 20-foot wall of layered light blocks movement for 1 minute; the first creature touching it each round takes 6d6 damage, split evenly among fire, cold, and electric (Reflex half).
