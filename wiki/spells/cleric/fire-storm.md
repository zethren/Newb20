# Fire Storm

*7th-level Evocation*

| Spell detail | Rule |
| --- | --- |
| **Level** | 7 |
| **School** | Evocation |
| **Class** | Cleric |
| **Casting Time** | Standard Action |
| **Range** | 150 feet |
| **Components** | V, S |
| **Duration** | Instantaneous |
| **Attack** | None |
| **Saving Throw** | Reflex half |
| **Spell Resistance** | Yes |

## Effect

Choose up to four 10-foot cubes; creatures in each take 1d6 fire damage per caster level (Reflex half), and you may leave safe gaps between the cubes.
