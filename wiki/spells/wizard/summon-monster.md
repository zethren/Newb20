# Summon Monster

| Spell detail | Rule |
| --- | --- |
| Level | 3 |
| School | Conjuration |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a small token representing the creature) |
| Duration | 1 minute |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

## Effect

Summon one Medium monster from another plane in an unoccupied space within range. Choose its appearance; it uses the statistics here and gains no other abilities. It has AC 15 and 40 hit points, moves up to 30 feet on its turn, and can make one melee attack (+6 to hit, 1d10+3 blunt damage). It acts immediately after you and vanishes when the spell ends or it is reduced to 0 hit points.
