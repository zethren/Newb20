# Break Enchantment

*5th-level Abjuration*

| Spell detail | Rule |
| --- | --- |
| **Level** | 5 |
| **School** | Abjuration |
| **Class** | Cleric |
| **Spell Lists** | Cleric 5th, Wizard 6th |
| **Casting Time** | Standard Action |
| **Range** | Touch |
| **Components** | V, S |
| **Duration** | Instantaneous |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

Touch a creature to end one magical Charmed, Shaken, Sickened, Staggered, or Paralyzed condition; against a 5th-level-or-higher source, pass a caster-level check (DC 11 + source level).
