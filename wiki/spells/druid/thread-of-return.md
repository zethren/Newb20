# Thread of Return

| Spell detail | Value |
| --- | --- |
| Level | 7 |
| School | Divination |
| Class | Druid |
| Casting time | Standard Action |
| Range | Touch |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 8 hours |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

For 8 hours, you know the direction and distance to a creature you touched when casting, while it remains on the same plane.
