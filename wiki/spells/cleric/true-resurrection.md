# True Resurrection

*9th-level Necromancy*

| Spell detail | Rule |
| --- | --- |
| **Level** | 9 |
| **School** | Necromancy |
| **Class** | Cleric |
| **Casting Time** | Standard Action |
| **Range** | Touch |
| **Components** | V, S |
| **Duration** | Instantaneous |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

Touch remains or speak the name of a creature dead within a year; if its soul is willing, it returns at full HP in an unoccupied space, forming a new body if needed.
