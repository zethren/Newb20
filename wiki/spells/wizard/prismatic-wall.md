# Prismatic Wall

| Spell detail | Rule |
| --- | --- |
| Level | 9 (Wizard) |
| School | Abjuration |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | 120 feet |
| Components | V, S |
| Duration | 10 minutes/CL |
| Attack | None |
| Saving Throw | Fortitude negates Blinded |
| Spell Resistance | Yes |

**Effect.** Create a 30-foot-long, 20-foot-high wall of layered light for 10 minutes/CL. Crossing creatures take 10d6 magic damage and make a Fortitude save or become Blinded for 1 round.
