# Stonebloom Shape

| Spell detail | Value |
| --- | --- |
| Level | 5 |
| School | Transmutation |
| Class | Druid |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | Instantaneous |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Turn a 10-foot cube of natural stone or earth into a rough doorway or close an existing doorway in it.
