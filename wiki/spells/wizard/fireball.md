# Fireball

| Spell detail | Rule |
| --- | --- |
| Level | 3 (Wizard) |
| School | Evocation |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | 150 feet |
| Components | V, S |
| Duration | Instantaneous |
| Attack | None |
| Saving Throw | Reflex half |
| Spell Resistance | Yes |

**Effect.** A bead erupts at a point within range. Creatures in its 20-foot-radius sphere take 1d6 fire damage per caster level, Reflex half.
