# Stonewave

| Spell detail | Value |
| --- | --- |
| Level | 4 |
| School | Evocation |
| Class | Druid |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | Instantaneous |
| Spell attack | None |
| Saving throw | Strength half |
| Spell resistance | Yes |

## Effect

Creatures in a 20-foot cone take 1d6 blunt damage per caster level and are pushed 10 feet on a failed Strength save; success halves damage and prevents the push.
