# Tracks Beneath Leaves

| Spell detail | Value |
| --- | --- |
| Level | 2 |
| School | Divination |
| Class | Druid |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | Instantaneous |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Inspect a 30-foot area to learn the number and creature sizes of tracks made there in the last day.
