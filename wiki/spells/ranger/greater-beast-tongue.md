# Greater Beast Tongue

| Spell detail | Rule |
| --- | --- |
| Level | 4th |
| School | Enchantment |
| Class | Ranger |
| Casting Time | Standard Action |
| Range | 30 feet |
| Components | V, S |
| Duration | 1 hour |
| Attack | None |
| Save | Wisdom, negates (unwilling beast) |
| Spell Resistance | Yes |

## Effect

Choose one beast you can see. An unwilling beast can resist with a Wisdom saving throw. For the duration, you and the beast can exchange detailed ideas and sensory impressions, and you can ask it questions about events it witnessed. It answers according to its memory and understanding; the spell neither compels honesty nor changes its attitude.
