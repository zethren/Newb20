# Whispering Grove

| Spell detail | Value |
| --- | --- |
| Level | 2 |
| School | Illusion |
| Class | Druid |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 1 minute |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Create a sound at a point within range, no louder than a conversation, that lasts up to 1 minute and can be heard from 60 feet away.
