# Analyze Dweomer

| Spell detail | Rule |
| --- | --- |
| Level | 6 (Wizard) |
| School | Divination |
| Class | Wizard |
| Spell Lists | Cleric 7th, Wizard 6th |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | 1 minute |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** Study one creature or object within 30 feet for 1 minute. Learn every spell affecting it and each magical property it possesses, but not a creature’s thoughts or history.
