# Read Magic

*2nd-level Divination*

| Spell detail | Rule |
| --- | --- |
| **Level** | 2 |
| **School** | Divination |
| **Class** | Cleric |
| **Casting Time** | Standard Action |
| **Range** | Self |
| **Components** | V, S |
| **Duration** | 1 hour |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

For 1 hour, understand the literal meaning of magical writing you can see, including scripts and symbols; hidden messages and magical traps remain concealed.
