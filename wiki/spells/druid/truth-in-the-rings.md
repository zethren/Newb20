# Truth in the Rings

| Spell detail | Value |
| --- | --- |
| Level | 8 |
| School | Divination |
| Class | Druid |
| Casting time | Standard Action |
| Range | 300 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | Instantaneous |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Touch a tree and learn the broad events that occurred within 30 feet of it during one day in the past year.
