# Dominate Person

| Spell detail | Rule |
| --- | --- |
| Level | 5 (Wizard) |
| School | Enchantment |
| Class | Wizard |
| Spell Lists | Cleric 5th, Wizard 5th |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | 1 minute/CL |
| Attack | None |
| Saving Throw | Will negates; repeat for harmful order |
| Spell Resistance | Yes |

**Effect.** One humanoid makes a Will save or follows your spoken commands for 1 minute/CL. It repeats the save if ordered to directly harm itself or an ally.
