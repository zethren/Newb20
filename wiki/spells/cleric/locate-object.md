# Locate Object

*3rd-level Divination*

| Spell detail | Rule |
| --- | --- |
| **Level** | 3 |
| **School** | Divination |
| **Class** | Cleric |
| **Spell Lists** | Cleric 3rd, Wizard 2nd |
| **Casting Time** | Standard Action |
| **Range** | Self |
| **Components** | V, S |
| **Duration** | 10 minutes |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

Name an object familiar to you; for 10 minutes, know its direction while it is within 1 mile, unless lead blocks the sense.
