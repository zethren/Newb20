# Mass Invisibility

*9th-level Illusion*

| Spell detail | Rule |
| --- | --- |
| **Level** | 9 |
| **School** | Illusion |
| **Class** | Cleric |
| **Spell Lists** | Cleric 9th, Wizard 7th |
| **Casting Time** | Standard Action |
| **Range** | 60 feet |
| **Components** | V, S |
| **Duration** | 10 minutes |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

Up to ten willing creatures gain Total Concealment against sight for 10 minutes; each becomes visible immediately after attacking or casting a spell.
