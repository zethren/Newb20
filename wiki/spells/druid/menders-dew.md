# Mender's Dew

| Spell detail | Value |
| --- | --- |
| Level | 1 |
| School | Evocation |
| Class | Druid |
| Casting time | Standard Action |
| Range | Touch |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 3 rounds |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

One living creature you touch regains 1d4 hit points at the start of each of its next three turns. This spell has no effect on undead.
