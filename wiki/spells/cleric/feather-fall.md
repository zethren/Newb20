# Feather Fall

*1st-level Transmutation*

| Spell detail | Rule |
| --- | --- |
| **Level** | 1 |
| **School** | Transmutation |
| **Class** | Cleric |
| **Spell Lists** | Cleric 1st, Wizard 1st |
| **Casting Time** | Standard Action |
| **Range** | 60 feet |
| **Components** | V, S |
| **Duration** | 1 minute |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

Choose up to five falling creatures; for 1 minute their fall slows to 60 feet per round and they take no damage on landing.
