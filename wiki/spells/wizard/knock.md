# Knock

| Spell detail | Rule |
| --- | --- |
| Level | 2 (Wizard) |
| School | Transmutation |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | Touch |
| Components | V, S |
| Duration | Instantaneous |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** Touch one nonmagical lock, barred door, or stuck lid and open it. A magical lock requires a caster-level check against DC 11 + its caster level.
