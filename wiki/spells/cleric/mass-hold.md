# Mass Hold

*9th-level Enchantment*

| Spell detail | Rule |
| --- | --- |
| **Level** | 9 |
| **School** | Enchantment |
| **Class** | Cleric |
| **Casting Time** | Standard Action |
| **Range** | 60 feet |
| **Components** | V, S |
| **Duration** | 1 minute |
| **Attack** | None |
| **Saving Throw** | Will negates; repeat at end of turn |
| **Spell Resistance** | Yes |

## Effect

Choose up to six creatures; each that fails a Will save becomes Staggered for 1 minute and repeats the save at the end of each turn to end the effect.
