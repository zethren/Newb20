# Cure Moderate Wounds

*2nd-level Necromancy*

| Spell detail | Rule |
| --- | --- |
| **Level** | 2 |
| **School** | Necromancy |
| **Class** | Cleric |
| **Spell Lists** | Cleric 2nd, Paladin 2nd |
| **Casting Time** | Standard Action |
| **Range** | Touch |
| **Components** | V, S |
| **Duration** | Instantaneous |
| **Attack** | None |
| **Saving Throw** | Will half against undead |
| **Spell Resistance** | Yes against undead |

## Effect

Positive energy restores 2d8 + 1d8 per 3 caster levels hit points to one living creature you touch. An undead creature instead takes that amount as positive-energy damage and can make a Will save to take half damage.
