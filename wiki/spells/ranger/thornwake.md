# Thornwake

| Spell detail | Rule |
| --- | --- |
| Level | 4th |
| School | Transmutation |
| Class | Ranger |
| Casting Time | Standard Action |
| Range | 120 feet |
| Components | V, S |
| Duration | Concentration, up to 1 minute |
| Attack | None |
| Save | Dexterity, half damage |
| Spell Resistance | Yes |

## Effect

Thorns erupt across a 20-foot-radius area of ground you can see. A creature that enters the area for the first time on a turn or starts its turn there takes **4d6 piercing damage** (Dexterity save for half). The area is difficult terrain. The thorns do not harm you or creatures you designate when casting the spell.
