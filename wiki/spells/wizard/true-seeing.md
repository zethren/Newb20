# True Seeing

| Spell detail | Rule |
| --- | --- |
| Level | 5 (Wizard) |
| School | Divination |
| Class | Wizard |
| Spell Lists | Cleric 6th, Wizard 5th |
| Casting Time | Standard Action |
| Range | Self |
| Components | V, S |
| Duration | 10 minutes/CL |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** For 10 minutes/CL, see invisible creatures, visual illusions, and true forms through magical disguises within 60 feet. This does not see through solid objects or ordinary disguises.
