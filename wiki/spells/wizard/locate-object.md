# Locate Object

| Spell detail | Rule |
| --- | --- |
| Level | 2 (Wizard) |
| School | Divination |
| Class | Wizard |
| Spell Lists | Cleric 3rd, Wizard 2nd |
| Casting Time | Standard Action |
| Range | Self |
| Components | V, S |
| Duration | 10 minutes/CL |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** Name or picture a nonliving object you have seen. For 10 minutes/CL, know its direction while within 1,000 feet; lead blocks the reading.
