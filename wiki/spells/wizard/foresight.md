# Foresight

| Spell detail | Rule |
| --- | --- |
| Level | 9 (Wizard) |
| School | Divination |
| Class | Wizard |
| Spell Lists | Cleric 7th, Wizard 9th |
| Casting Time | Standard Action |
| Range | Touch |
| Components | V, S |
| Duration | 8 hours |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** You or one willing creature touched cannot be Surprised for 8 hours and receives a one-round warning before an immediate danger first threatens it.
