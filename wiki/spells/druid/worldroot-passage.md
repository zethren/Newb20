# Worldroot Passage

| Spell detail | Value |
| --- | --- |
| Level | 9 |
| School | Conjuration |
| Class | Druid |
| Casting time | Standard Action |
| Range | 300 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | Instantaneous |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Transport up to eight willing creatures to a natural place you have visited on the same plane, provided it is familiar to you; arrival is precise and unoccupied.
