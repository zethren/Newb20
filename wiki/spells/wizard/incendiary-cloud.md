# Incendiary Cloud

| Spell detail | Rule |
| --- | --- |
| Level | 8 (Wizard) |
| School | Evocation |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | 120 feet |
| Components | V, S |
| Duration | 1 round/CL |
| Attack | None |
| Saving Throw | Reflex half |
