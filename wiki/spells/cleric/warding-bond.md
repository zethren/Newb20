# Warding Bond

*2nd-level Abjuration*

| Spell detail | Rule |
| --- | --- |
| **Level** | 2 |
| **School** | Abjuration |
| **Class** | Cleric |
| **Spell Lists** | Cleric 2nd, Paladin 2nd |
| **Casting Time** | Standard Action |
| **Range** | 30 feet |
| **Components** | V, S |
| **Duration** | 10 minutes |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

Link yourself to one willing creature for 10 minutes: it gains a +1 Deflection bonus to Deflection AC and a +1 bonus on saves, while you take half the damage it receives; the link ends beyond 60 feet.
