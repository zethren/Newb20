# Tidegate

| Spell detail | Value |
| --- | --- |
| Level | 6 |
| School | Conjuration |
| Class | Druid |
| Casting time | Standard Action |
| Range | 120 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 10 minutes |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Open a 10-foot-wide passage through nonmagical water or loose earth, up to 60 feet long; it remains stable for 10 minutes.
