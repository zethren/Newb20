# Locate Creature

| Spell detail | Rule |
| --- | --- |
| Level | 4 (Wizard) |
| School | Divination |
| Class | Wizard |
| Spell Lists | Cleric 4th, Wizard 4th |
| Casting Time | Standard Action |
| Range | Self |
| Components | V, S |
| Duration | 1 hour/CL |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** Name a creature you know or describe it. For 1 hour/CL, learn its direction while it is within 1 mile on your plane; running water blocks the reading.
