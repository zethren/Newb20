# Shimmering Canopy

| Spell detail | Value |
| --- | --- |
| Level | 3 |
| School | Illusion |
| Class | Druid |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 1 hour |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

A 10-foot-radius area appears as ordinary foliage for 1 hour; a creature that examines it can recognize the illusion with an Investigation check against your save DC.
