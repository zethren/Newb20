| Spell detail | Rule |
| --- | --- |
| Level | 7 (Wizard) |
| School | Necromancy |
| Class | Wizard |
| Spell Lists | Cleric 7th, Wizard 7th |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | Instantaneous |
| Attack | None |
| Saving Throw | Fortitude half |
| Spell Resistance | Yes |

**Effect.** One living creature makes a Fortitude save or takes 1d6 corrupt damage per caster level; success halves damage. If this damage reduces it to 0 HP, it dies.
