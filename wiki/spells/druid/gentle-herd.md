# Gentle Herd

| Spell detail | Value |
| --- | --- |
| Level | 1 |
| School | Enchantment |
| Class | Druid |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 1 minute |
| Spell attack | None |
| Saving throw | Wisdom negates |
| Spell resistance | Yes |

## Effect

One beast must succeed on a Wisdom save or regard you as nonthreatening for 1 minute; hostile actions end the effect.
