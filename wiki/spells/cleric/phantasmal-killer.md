# Phantasmal Killer

*5th-level Illusion*

| Spell detail | Rule |
| --- | --- |
| **Level** | 5 |
| **School** | Illusion |
| **Class** | Cleric |
| **Spell Lists** | Cleric 5th, Wizard 4th |
| **Casting Time** | Standard Action |
| **Range** | 60 feet |
| **Components** | V, S |
| **Duration** | Instantaneous |
| **Attack** | None |
| **Saving Throw** | Will half damage and negates Shaken |
| **Spell Resistance** | Yes |

## Effect

One creature that fails a Will save takes 1d6 psychic damage per caster level and becomes Shaken for 1 round; a success halves the damage and negates Shaken.
