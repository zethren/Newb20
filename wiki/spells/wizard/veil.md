# Veil

| Spell detail | Rule |
| --- | --- |
| Level | 6 (Wizard) |
| School | Illusion |
| Class | Wizard |
| Spell Lists | Cleric 7th, Wizard 6th |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | 1 hour/CL |
| Attack | None |
| Saving Throw | Will disbelief |
| Spell Resistance | Yes |

**Effect.** Up to six willing creatures appear to be members of another humanoid group for 1 hour/CL. Touch or close inspection permits a Will save to see through the disguises.
