# Horrid Wilting

| Spell detail | Rule |
| --- | --- |
| Level | 8 (Wizard) |
| School | Necromancy |
| Class | Wizard |
| Spell Lists | Cleric 8th, Wizard 8th |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | Instantaneous |
| Attack | None |
| Saving Throw | Fortitude half |
| Spell Resistance | Yes |

**Effect.** Up to six creatures make Fortitude saves or take 1d6 corrupt damage per caster level; success halves damage. Constructs and undead are unaffected.
