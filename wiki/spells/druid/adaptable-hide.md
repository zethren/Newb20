# Adaptable Hide

| Spell detail | Value |
| --- | --- |
| Level | 5 |
| School | Transmutation |
| Class | Druid |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 1 hour |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

One willing creature gains resistance to one damage type (acid, cold, fire, or lightning) and can breathe either air or water for 1 hour.
