# Green Echo

| Spell detail | Value |
| --- | --- |
| Level | 2 |
| School | Divination |
| Class | Druid |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | Instantaneous |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect
