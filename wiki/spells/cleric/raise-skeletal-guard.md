# Raise Skeletal Guard

*3rd-level Conjuration*

| Spell detail | Rule |
| --- | --- |
| **Level** | 3 |
| **School** | Conjuration |
| **Class** | Cleric |
| **Casting Time** | Standard Action |
| **Range** | 30 feet |
| **Components** | V, S, M (a bone fragment) |
| **Duration** | 1 minute |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

Summon one Medium skeletal guard (undead) in an unoccupied space within range. It has AC 15 and 30 hit points, moves up to 30 feet on its turn, and can make one melee attack (+5 to hit, 1d8+2 piercing damage). It acts immediately after you and vanishes when the spell ends or it is reduced to 0 hit points.
