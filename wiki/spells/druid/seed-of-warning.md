# Seed of Warning

| Spell detail | Value |
| --- | --- |
| Level | 1 |
| School | Divination |
| Class | Druid |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | Instantaneous |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Choose one creature; it cannot be surprised by a creature it can see before the end of its next turn.
