# Meld with the Oak

| Spell detail | Value |
| --- | --- |
| Level | 4 |
| School | Transmutation |
| Class | Druid |
| Casting time | Standard Action |
| Range | Self |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 1 hour |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

You merge into a tree large enough to contain you for up to 1 hour; you can see outside and leave as a Standard Action.
