# Clone

| Spell detail | Rule |
| --- | --- |
| Level | 8 (Wizard) |
| School | Necromancy |
| Class | Wizard |
| Spell Lists | Cleric 8th, Wizard 8th |
| Casting Time | Standard Action |
| Range | Touch |
| Components | V, S, M (tissue sample and gem worth 1,000 gp) |
| Duration | One year to mature; then until used |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** Grow a dormant duplicate from a living creature’s tissue. If it dies within one year, its soul awakens in the clone at full HP; its original body remains dead.
