# Bestow Curse

*4th-level Necromancy*

| Spell detail | Rule |
| --- | --- |
| **Level** | 4 |
| **School** | Necromancy |
| **Class** | Cleric |
| **Casting Time** | Standard Action |
| **Range** | Touch |
| **Components** | V, S |
| **Duration** | 1 minute |
| **Attack** | Melee spell attack |
| **Saving Throw** | Will negates |
| **Spell Resistance** | Yes |

## Effect

Make a melee spell attack; on a hit, the creature takes -2 on attack rolls and saves for 1 minute unless it succeeds on a Will save.
