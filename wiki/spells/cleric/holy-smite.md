# Holy Smite

*4th-level Evocation*

| Spell detail | Rule |
| --- | --- |
| **Level** | 4 |
| **School** | Evocation |
| **Class** | Cleric |
| **Spell Lists** | Cleric 4th, Paladin 4th |
| **Casting Time** | Standard Action |
| **Range** | 120 feet |
| **Components** | V, S |
| **Duration** | Instantaneous |
| **Attack** | None |
| **Saving Throw** | Reflex half |
| **Spell Resistance** | Yes |

## Effect

Creatures you choose in a 20-foot-radius burst take 1d6 holy damage per caster level (Reflex half); undead instead take 1d8 holy damage per caster level.
