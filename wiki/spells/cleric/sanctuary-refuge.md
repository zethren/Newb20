# Sanctuary Refuge

*9th-level Conjuration*

| Spell detail | Rule |
| --- | --- |
| **Level** | 9 |
| **School** | Conjuration |
| **Class** | Cleric |
| **Casting Time** | Standard Action |
| **Range** | 30 feet |
| **Components** | V, S |
| **Duration** | 8 hours |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

You and up to ten willing creatures within 30 feet vanish to a refuge for up to 8 hours; you can return to your former spaces as a Standard Action, but attacking ends the spell.
