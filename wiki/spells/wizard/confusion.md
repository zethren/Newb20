# Confusion

| Spell detail | Rule |
| --- | --- |
| Level | 4 (Wizard) |
| School | Enchantment |
| Class | Wizard |
| Spell Lists | Cleric 4th, Wizard 4th |
| Casting Time | Standard Action |
| Range | 120 feet |
| Components | V, S |
| Duration | 1 round/CL |
| Attack | None |
| Saving Throw | Will negates |
| Spell Resistance | Yes |

**Effect.** Creatures in a 20-foot-radius burst make Will saves or become Confused for 1 round/CL. Each turn roll d6: 1-2 lose a Standard Action, 3-4 move away from you, 5-6 act normally.
