# Summon Greater Monster

| Spell detail | Rule |
| --- | --- |
| Level | 6 |
| School | Conjuration |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a carved token representing the creature) |
| Duration | 1 minute |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

## Effect

Summon one Large monster from another plane in an unoccupied space within range. Choose its appearance; it uses the statistics here and gains no other abilities. It has AC 17 and 85 hit points, moves up to 30 feet on its turn, and can make one melee attack (+9 to hit, 2d10+5 blunt damage). It acts immediately after you and vanishes when the spell ends or it is reduced to 0 hit points.
