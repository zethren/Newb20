# Major Image

*3rd-level Illusion*

| Spell detail | Rule |
| --- | --- |
| **Level** | 3 |
| **School** | Illusion |
| **Class** | Cleric |
| **Spell Lists** | Cleric 3rd, Wizard 3rd |
| **Casting Time** | Standard Action |
| **Range** | 120 feet |
| **Components** | V, S |
| **Duration** | 10 minutes |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

Create a moving image with sound, smell, and apparent temperature inside a 20-foot cube for 10 minutes; it has no physical substance, and examination can expose it.
