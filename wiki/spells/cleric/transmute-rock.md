# Transmute Rock

*5th-level Transmutation*

| Spell detail | Rule |
| --- | --- |
| **Level** | 5 |
| **School** | Transmutation |
| **Class** | Cleric |
| **Casting Time** | Standard Action |
| **Range** | 120 feet |
| **Components** | V, S |
| **Duration** | 1 minute |
| **Attack** | None |
| **Saving Throw** | Reflex negates Entangled |
| **Spell Resistance** | No |

## Effect

Turn a 20-foot cube of natural stone to mud for 1 minute; a creature that fails a Reflex save becomes Entangled until it leaves, then the stone returns.
