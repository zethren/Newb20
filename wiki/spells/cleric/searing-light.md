# Searing Light

*3rd-level Evocation*

| Spell detail | Rule |
| --- | --- |
| **Level** | 3 |
| **School** | Evocation |
| **Class** | Cleric |
| **Spell Lists** | Cleric 3rd, Paladin 3rd |
| **Casting Time** | Standard Action |
| **Range** | 120 feet |
| **Components** | V, S |
| **Duration** | Instantaneous |
| **Attack** | Ranged spell attack |
| **Saving Throw** | None |
| **Spell Resistance** | Yes |

## Effect

Make a ranged spell attack against one creature; on a hit it takes 1d8 holy damage per 2 caster levels (round up), or 1d6 holy damage per caster level if undead.
