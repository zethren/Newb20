# Wall of Stone

*5th-level Conjuration*

| Spell detail | Rule |
| --- | --- |
| **Level** | 5 |
| **School** | Conjuration |
| **Class** | Cleric |
| **Spell Lists** | Cleric 5th, Wizard 6th |
| **Casting Time** | Standard Action |
| **Range** | 60 feet |
| **Components** | V, S |
| **Duration** | Permanent |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

Raise a nonmagical stone wall up to 20 feet long, 10 feet high, and 1 foot thick on a solid surface; it has no openings and lasts until destroyed.
