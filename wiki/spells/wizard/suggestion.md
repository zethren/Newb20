# Suggestion

| Spell detail | Rule |
| --- | --- |
| Level | 3 (Wizard) |
| School | Enchantment |
| Class | Wizard |
| Spell Lists | Cleric 3rd, Wizard 3rd |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | Up to 1 hour |
| Attack | None |
| Saving Throw | Will negates |
| Spell Resistance | Yes |
