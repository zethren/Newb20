# Ice Storm

| Spell detail | Rule |
| --- | --- |
| Level | 4 (Wizard) |
| School | Evocation |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | 120 feet |
| Components | V, S |
| Duration | 1 round |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | Yes |

**Effect.** Hail fills a 20-foot-radius, 40-foot-high cylinder for 1 round. Creatures take 4d6 blunt damage and move at half speed inside; no save prevents damage.
