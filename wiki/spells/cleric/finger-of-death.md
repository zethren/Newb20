# Finger of Death

*7th-level Necromancy*

| Spell detail | Rule |
| --- | --- |
| **Level** | 7 |
| **School** | Necromancy |
| **Class** | Cleric |
| **Spell Lists** | Cleric 7th, Wizard 7th |
| **Casting Time** | Standard Action |
| **Range** | 60 feet |
| **Components** | V, S |
| **Duration** | Instantaneous |
| **Attack** | Ranged spell attack |
| **Saving Throw** | Fortitude half |
| **Spell Resistance** | Yes |

## Effect

Make a ranged spell attack; on a hit, one living creature takes 1d6 negative-energy damage per caster level (Fortitude half). Reaching 0 HP makes it Unconscious and Dying as normal.
