# Restoration

*4th-level Conjuration*

| Spell detail | Rule |
| --- | --- |
| **Level** | 4 |
| **School** | Conjuration |
| **Class** | Cleric |
| **Spell Lists** | Cleric 4th, Druid 4th, Paladin 4th |
| **Casting Time** | Standard Action |
| **Range** | Touch |
| **Components** | V, S |
| **Duration** | Instantaneous |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

Touch one creature to restore temporary ability damage equal to a roll of 2d4 and 1 point of permanent ability damage. You may distribute the restored points among its ability scores.
