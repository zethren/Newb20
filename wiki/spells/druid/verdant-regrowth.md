# Verdant Regrowth

*4th-level Transmutation*

| Spell detail | Value |
| --- | --- |
| Level | 4 |
| School | Transmutation |
| Class | Druid |
| Casting time | Standard Action |
| Range | Touch |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 3 rounds |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

One living creature you touch regains 2d6 hit points at the start of each of its next three turns. This spell has no effect on undead.
