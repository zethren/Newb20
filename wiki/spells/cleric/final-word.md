# Final Word

*9th-level Enchantment*

| Spell detail | Rule |
| --- | --- |
| **Level** | 9 |
| **School** | Enchantment |
| **Class** | Cleric |
| **Casting Time** | Standard Action |
| **Range** | 60 feet |
| **Components** | V, S |
| **Duration** | 1 minute |
| **Attack** | None |
| **Saving Throw** | Will negates |
| **Spell Resistance** | Yes |

## Effect

A creature that fails a Will save cannot attack or cast harmful spells for 1 minute; the effect ends if you or an ally damages it.
