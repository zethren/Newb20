# Holy Aura

*8th-level Abjuration*

| Spell detail | Rule |
| --- | --- |
| **Level** | 8 |
| **School** | Abjuration |
| **Class** | Cleric |
| **Casting Time** | Standard Action |
| **Range** | Self |
| **Components** | V, S |
| **Duration** | 1 minute/CL |
| **Attack** | None |
| **Saving Throw** | Will negates Shaken |
| **Spell Resistance** | Yes |

## Effect

For 1 minute/CL, you and willing allies within 20 feet gain a +2 Deflection bonus to Deflection AC and a +2 bonus on saves against hostile spells; an enemy entering must pass a Will save or become Shaken for 1 round.
