# Bodyguard

The Bodyguard is a martial protector who designates a willing ally as a Protected Charge and uses shield work and damage interception to keep them safe. At level 8, the Bodyguard can protect a second charge.

## Class Statistics

| Statistic | Value |
| --- | --- |
| Hit Die | d12 |
| Base attack bonus | High progression (+1 per level) |
| Good saves | Fortitude, Will |
| Reflex save | Poor progression |
| Skill ranks per level | 2 + Intelligence modifier (minimum 1) |
| Class skills | [Acrobatics](../../../skills/acrobatics.md), [Athletics](../../../skills/athletics.md), [Heal](../../../skills/heal.md), [Lore (Nobility)](../../../skills/lore-nobility.md), [Perception](../../../skills/perception.md), [Persuasion](../../../skills/persuasion.md), [Ride](../../../skills/ride.md), [Sense Motive](../../../skills/sense-motive.md) |
| Entry requirements | BAB +5; Vanguard Intercept, Raise Shield Other, and Toughness; Perception 5 ranks |

The save values use the common d20 good-save and poor-save progressions implied by the source's Fortitude/Will designation. Prestige classes use a 10-level progression. The Bodyguard gains features at levels 1, 2, 4, 6, 8, and 10; levels 3, 5, 7, and 9 intentionally grant no new class features.
