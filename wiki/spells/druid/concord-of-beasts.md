# Concord of Beasts

| Spell detail | Value |
| --- | --- |
| Level | 6 |
| School | Enchantment |
| Class | Druid |
| Casting time | Standard Action |
| Range | 120 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 1 hour |
| Spell attack | None |
| Saving throw | Wisdom negates |
| Spell resistance | Yes |

## Effect

Up to eight beasts that can hear you regard you and your allies as familiar companions for 1 hour, unless any is harmed.
