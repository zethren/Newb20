# Fly

| Spell detail | Rule |
| --- | --- |
| Level | 3 (Wizard) |
| School | Transmutation |
| Class | Wizard |
| Spell Lists | Cleric 4th, Wizard 3rd |
| Casting Time | Standard Action |
| Range | Touch |
| Components | V, S |
| Duration | 10 minutes/CL |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** One willing creature touched gains a 60-foot flying speed for 10 minutes/CL. If airborne when the spell ends, it descends safely at 60 feet per round.
