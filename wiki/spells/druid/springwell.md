# Springwell

| Spell detail | Value |
| --- | --- |
| Level | 3 |
| School | Conjuration |
| Class | Druid |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 1 hour |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Create up to 20 gallons of clean water in containers or on the ground; uncontained water flows naturally and remains for 1 hour.
