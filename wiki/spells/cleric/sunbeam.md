# Sunbeam

*6th-level Evocation*

| Spell detail | Rule |
| --- | --- |
| **Level** | 6 |
| **School** | Evocation |
| **Class** | Cleric |
| **Spell Lists** | Cleric 6th, Wizard 7th |
| **Casting Time** | Standard Action |
| **Range** | Self (60-foot line) |
| **Components** | V, S |
| **Duration** | 1 minute |
| **Attack** | None |
| **Saving Throw** | Fortitude half and negates Blinded |
| **Spell Resistance** | Yes |

## Effect

For 1 minute, fire a 60-foot line of sunlight as a Standard Action each turn; creatures take 4d6 holy damage and become Blinded for 1 round (Fortitude half and negates Blinded).
