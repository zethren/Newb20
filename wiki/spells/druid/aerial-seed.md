# Aerial Seed

| Spell detail | Value |
| --- | --- |
| Level | 6 |
| School | Transmutation |
| Class | Druid |
| Casting time | Standard Action |
| Range | 120 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 10 minutes |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

One willing creature gains a 40-foot fly speed for 10 minutes; if the spell ends while aloft, it descends safely at 60 feet per round.
