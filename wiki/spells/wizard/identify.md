# Identify

| Spell detail | Rule |
| --- | --- |
| Level | 1 (Wizard) |
| School | Divination |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | Touch |
| Components | V, S |
| Duration | 1 minute |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** Touch one magic item for 1 minute to learn its properties, activation, and remaining charges. This does not reveal curses.
