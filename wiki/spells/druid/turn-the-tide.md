# Turn the Tide

| Spell detail | Value |
| --- | --- |
| Level | 8 |
| School | Transmutation |
| Class | Druid |
| Casting time | Standard Action |
| Range | 300 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 1 hour |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Redirect a nonmagical current or wind in a 100-foot-radius area for 1 hour, changing its direction and doubling or halving its speed.
