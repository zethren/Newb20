# Clairaudience

| Spell detail | Rule |
| --- | --- |
| Level | 3 (Wizard) |
| School | Divination |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | Self |
| Components | V, S |
| Duration | 10 minutes/CL |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** Hear sounds at a familiar location within 1 mile for 10 minutes/CL. You cannot see or cast spells through this remote sense.
