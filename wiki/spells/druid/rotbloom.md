# Rotbloom

| Spell detail | Value |
| --- | --- |
| Level | 3 |
| School | Necromancy |
| Class | Druid |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | Instantaneous |
| Spell attack | None |
| Saving throw | Constitution half |
| Spell resistance | Yes |

## Effect

One creature takes 1d6 corrupt damage per caster level on a failed Constitution save, or half on a success; plants in its space wilt harmlessly.
