# Mass Suggestion

*5th-level Enchantment*

| Spell detail | Rule |
| --- | --- |
| **Level** | 5 |
| **School** | Enchantment |
| **Class** | Cleric |
| **Spell Lists** | Cleric 5th, Wizard 6th |
| **Casting Time** | Standard Action |
| **Range** | 60 feet |
| **Components** | V, S |
| **Duration** | Up to 8 hours |
| **Attack** | None |
| **Saving Throw** | Will negates |
| **Spell Resistance** | Yes |

## Effect

Give the same reasonable instruction to up to six creatures that understand you; each that fails a Will save follows it for up to 8 hours without knowingly harming itself or an ally.
