# Reverse Gravity

| Spell detail | Rule |
| --- | --- |
| Level | 7 (Wizard) |
| School | Transmutation |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | 120 feet |
| Components | V, S |
| Duration | 1 round/CL |
| Attack | None |
| Saving Throw | Reflex negates rising |
| Spell Resistance | Yes |

**Effect.** Gravity reverses in a 30-foot-radius, 100-foot-high cylinder for 1 round/CL. Creatures rise; a Reflex save lets them grab a fixed surface and stay put.
