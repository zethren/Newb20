# Harvest of the Last Leaf

| Spell detail | Value |
| --- | --- |
| Level | 8 |
| School | Necromancy |
| Class | Druid |
| Casting time | Standard Action |
| Range | 300 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | Instantaneous |
| Spell attack | None |
| Saving throw | Constitution half |
| Spell resistance | Yes |

## Effect

Creatures of your choice in a 30-foot-radius area make Constitution saves, taking 1d8 corrupt damage per caster level on a failure or half on a success; you regain hit points equal to half the damage dealt.
