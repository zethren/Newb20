# Storm of Vengeance

| Spell detail | Rule |
| --- | --- |
| Level | 9 (Wizard) |
| School | Evocation |
| Class | Wizard |
| Spell Lists | Cleric 9th, Wizard 9th |
| Casting Time | Standard Action |
| Range | 300 feet |
| Components | V, S |
| Duration | 1 minute |
| Attack | None |
| Saving Throw | Reflex half |
| Spell Resistance | Yes |

**Effect.** A 60-foot-radius storm lasts 1 minute. Creatures inside take 1d6 electric damage per 6 caster levels (round up) each round, Reflex half; the area is heavily obscured and ordinary flames go out.
