# Farroot Passage

| Spell detail | Value |
| --- | --- |
| Level | 7 |
| School | Conjuration |
| Class | Druid |
| Casting time | Standard Action |
| Range | 120 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | Instantaneous |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Teleport up to six willing creatures to a natural landmark you have visited within 10 miles; the destination must be unoccupied.
