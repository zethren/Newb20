# Iron Body

| Spell detail | Rule |
| --- | --- |
| Level | 8 (Wizard) |
| School | Transmutation |
| Class | Wizard |
| Spell Lists | Cleric 8th, Wizard 8th |
| Casting Time | Standard Action |
| Range | Self |
| Components | V, S |
| Duration | 10 minutes/CL |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** Your skin becomes iron for 10 minutes/CL: gain a +6 Enhancement bonus to Natural Armor AC and immunity to poison and critical hits, but halve your speed and lose the ability to swim.
