# Forbiddance

*6th-level Abjuration*

| Spell detail | Rule |
| --- | --- |
| **Level** | 6 |
| **School** | Abjuration |
| **Class** | Cleric |
| **Casting Time** | Standard Action |
| **Range** | Touch |
| **Components** | V, S |
| **Duration** | 24 hours |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

Ward a doorway or 20-foot cube for 24 hours; teleportation across its boundary fails, and only creatures you designated while casting can pass through.
