# Hidden Hollow

| Spell detail | Value |
| --- | --- |
| Level | 6 |
| School | Conjuration |
| Class | Druid |
| Casting time | Standard Action |
| Range | 120 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 8 hours |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Create a 15-foot-radius pocket beneath natural ground for up to six willing creatures; it has an air supply and a concealed entrance for 8 hours.
