# Grease

| Spell detail | Rule |
| --- | --- |
| Level | 1 (Wizard) |
| School | Conjuration |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | 1 minute/CL |
| Attack | None |
| Saving Throw | Reflex negates falling Prone |
| Spell Resistance | No |

**Effect.** Slick a 10-foot square for 1 minute/CL. Creatures there make Reflex saves or fall Prone; anyone entering must save or fall, and the square is difficult terrain.
