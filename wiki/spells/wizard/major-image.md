# Major Image

| Spell detail | Rule |
| --- | --- |
| Level | 3 (Wizard) |
| School | Illusion |
| Class | Wizard |
| Spell Lists | Cleric 3rd, Wizard 3rd |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | 10 minutes/CL |
| Attack | None |
| Saving Throw | Will disbelief |
| Spell Resistance | Yes |

**Effect.** Create a moving visual and audible scene in a 20-foot cube for 10 minutes/CL. It cannot cause touch, smell, or damage; testing it permits a Will save to disbelieve.
