# Sunbeam

| Spell detail | Rule |
| --- | --- |
| Level | 7 (Wizard) |
| School | Evocation |
| Class | Wizard |
| Spell Lists | Cleric 6th, Wizard 7th |
| Casting Time | Standard Action |
| Range | Self (60-foot line) |
| Components | V, S |
| Duration | 1 round/CL |
| Attack | None |
| Saving Throw | Reflex half; Fortitude negates Blinded |
| Spell Resistance | Yes |

**Effect.** For 1 round/CL, project a 60-foot line once each turn. Creatures take 4d6 damage, Reflex half, and on a failed Fortitude save become Blinded for 1 round.
