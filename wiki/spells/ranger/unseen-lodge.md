# Unseen Lodge

| Spell detail | Rule |
| --- | --- |
| Level | 4th |
| School | Conjuration |
| Class | Ranger |
| Casting Time | 1 minute |
| Range | 30 feet |
| Components | V, S, a branch |
| Duration | 8 hours |
| Attack | None |
| Save | None |
| Spell Resistance | No |

## Effect

Create a sheltered lodge in an unoccupied natural space within range. The lodge accommodates up to eight Medium creatures and their ordinary gear, blocks ordinary wind and rain, and remains visually indistinct from outside. The entrance is visible at close range; the lodge does not block sound, prevent entry, or conceal its occupants from a deliberate search. It vanishes if its space is disturbed or the spell ends.
