# Resist Energy

*2nd-level Abjuration*

| Spell detail | Rule |
| --- | --- |
| **Level** | 2 |
| **School** | Abjuration |
| **Class** | Cleric |
| **Spell Lists** | Cleric 2nd, Paladin 2nd |
| **Casting Time** | Standard Action |
| **Range** | Touch |
| **Components** | V, S |
| **Duration** | 10 minutes/CL |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

Choose acid, cold, electric, fire, or sonic damage; the target reduces each instance of that type by 5 for 10 minutes/CL.
