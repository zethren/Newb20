# Phantasmal Killer

| Spell detail | Rule |
| --- | --- |
| Level | 4 (Wizard) |
| School | Illusion |
| Class | Wizard |
| Spell Lists | Cleric 5th, Wizard 4th |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | Instantaneous |
| Attack | None |
| Saving Throw | Will half damage and negates Stunned |
| Spell Resistance | Yes |

**Effect.** One creature makes a Will save or sees a private nightmare, takes 1d6 psychic damage per caster level, and becomes Stunned for 1 round. Success halves damage and prevents Stun.
