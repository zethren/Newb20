# Everchanging Wild

| Spell detail | Value |
| --- | --- |
| Level | 9 |
| School | Illusion |
| Class | Druid |
| Casting time | Standard Action |
| Range | 300 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 8 hours |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Create a 100-foot-radius illusion of terrain, creatures, sound, and scent for 8 hours; an observer that interacts with it can make an Investigation check against your save DC to see through it.
