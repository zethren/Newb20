# Read the Rootways

| Spell detail | Value |
| --- | --- |
| Level | 7 |
| School | Divination |
| Class | Druid |
| Casting time | Standard Action |
| Range | 120 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | Instantaneous |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Learn the location of the nearest passage, shelter, or water source within 10 miles, choosing which kind to seek.
