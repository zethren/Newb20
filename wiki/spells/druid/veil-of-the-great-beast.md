# Veil of the Great Beast

| Spell detail | Value |
| --- | --- |
| Level | 8 |
| School | Illusion |
| Class | Druid |
| Casting time | Standard Action |
| Range | 300 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 1 hour |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Up to eight willing creatures appear as harmless local wildlife to observers for 1 hour; an observer that studies one may make an Investigation check against your save DC.
