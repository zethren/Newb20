# Blindness and Deafness

*2nd-level Necromancy*

| Spell detail | Rule |
| --- | --- |
| **Level** | 2 |
| **School** | Necromancy |
| **Class** | Cleric |
| **Casting Time** | Standard Action |
| **Range** | 30 feet |
| **Components** | V, S |
| **Duration** | 1 minute |
| **Attack** | None |
| **Saving Throw** | Fortitude negates; repeat at end of turn |
| **Spell Resistance** | Yes |

## Effect

One creature that fails a Fortitude save becomes Blinded or Deafened (your choice) for 1 minute and repeats the save at the end of each turn.
