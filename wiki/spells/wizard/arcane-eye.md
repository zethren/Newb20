# Arcane Eye

| Spell detail | Rule |
| --- | --- |
| Level | 4 (Wizard) |
| School | Divination |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | Self |
| Components | V, S |
| Duration | 10 minutes/CL |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** Steer an invisible sensor up to 500 feet away for 10 minutes/CL and see through it. It moves 30 feet per round and cannot pass through solid barriers.
