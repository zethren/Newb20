# Mossward Circle

| Spell detail | Value |
| --- | --- |
| Level | 2 |
| School | Abjuration |
| Class | Druid |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 1 minute/CL |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Choose up to three creatures in a 10-foot-radius area; each gains a +2 Circumstance bonus to Shield AC against ranged attacks for the duration.
