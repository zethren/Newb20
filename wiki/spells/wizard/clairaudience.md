# Clairaudience

| Spell detail | Rule |
| --- | --- |
| Level | 3 (Wizard) |
| School | Divination |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | Self |
| Components | V, S |
| Duration | 10 minutes/CL |
| Attack | None |
| Saving Throw | None |
