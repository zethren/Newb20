# Silent Image

| Spell detail | Rule |
| --- | --- |
| Level | 1 (Wizard) |
| School | Illusion |
| Class | Wizard |
| Spell Lists | Cleric 1st, Wizard 1st |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | 1 minute/CL |
| Attack | None |
| Saving Throw | Will disbelief |
| Spell Resistance | Yes |

**Effect.** Create a stationary visual image no larger than a 15-foot cube for 1 minute/CL. It makes no sound or physical change; a creature testing it may make a Will save to disbelieve.
