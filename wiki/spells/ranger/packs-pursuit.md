# Pack's Pursuit

| Spell detail | Rule |
| --- | --- |
| Level | 3rd |
| School | Divination |
| Class | Ranger |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | 1 minute |
| Attack | None |
| Save | Wisdom, negates |
| Spell Resistance | Yes |

## Effect

Choose one creature you can see within range. It makes a Wisdom saving throw. On a failure, you and up to five willing allies within 30 feet of you can sense the target's direction while it remains within 1 mile and on the same plane. The effect ends early if the target succeeds on a Wisdom saving throw at the end of one of its turns.
