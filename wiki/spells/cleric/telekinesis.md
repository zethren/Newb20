# Telekinesis

*7th-level Transmutation*

| Spell detail | Rule |
| --- | --- |
| **Level** | 7 |
| **School** | Transmutation |
| **Class** | Cleric |
| **Spell Lists** | Cleric 7th, Wizard 5th |
| **Casting Time** | Standard Action |
| **Range** | 120 feet |
| **Components** | V, S |
| **Duration** | 1 minute |
| **Attack** | Ranged spell attack if striking |
| **Saving Throw** | None |
| **Spell Resistance** | Yes |

## Effect

Move an unattended object weighing up to 500 pounds up to 60 feet as a Standard Action for 1 minute; instead, make a ranged spell attack with it for 1d6 blunt damage per caster level, ending the spell.
