# Power Word Blind

| Spell detail | Rule |
| --- | --- |
| Level | 7 (Wizard) |
| School | Enchantment |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | 1 hour |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | Yes |

**Effect.** One creature with 100 HP or fewer becomes Blinded for 1 hour. A creature above that limit is unaffected; no saving throw applies.
