# Dimensional Lock

| Spell detail | Rule |
| --- | --- |
| Level | 8 (Wizard) |
| School | Abjuration |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | 120 feet |
| Components | V, S |
| Duration | 1 day/CL |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** Fix a 30-foot-radius area for 1 day/CL. Teleportation and planar travel into, out of, or within it fail; other movement and spells work normally.
