# Oracle’s Revelation

*9th-level Divination*

| Spell detail | Rule |
| --- | --- |
| **Level** | 9 |
| **School** | Divination |
| **Class** | Cleric |
| **Casting Time** | Standard Action |
| **Range** | Self |
| **Components** | V, S |
| **Duration** | Instantaneous |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

Ask one question about a named person, place, or event; the GM gives a truthful answer of up to three sentences, but cannot disclose unknown information.
