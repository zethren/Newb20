# The Wild's Command

| Spell detail | Value |
| --- | --- |
| Level | 8 |
| School | Enchantment |
| Class | Druid |
| Casting time | Standard Action |
| Range | 300 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | Instantaneous |
| Spell attack | None |
| Saving throw | Wisdom negates |
| Spell resistance | Yes |

## Effect

Up to four creatures must succeed on Wisdom saves or obey one brief, non-self-destructive command on their next turn.
