# Stinking Cloud

| Spell detail | Rule |
| --- | --- |
| Level | 3 (Wizard) |
| School | Conjuration |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | 120 feet |
| Components | V, S |
| Duration | 1 round/CL |
| Attack | None |
| Saving Throw | Fortitude negates Nauseated |
| Spell Resistance | Yes |

**Effect.** Create a 20-foot-radius cloud for 1 round/CL. A creature that starts its turn inside makes a Fortitude save or becomes Nauseated until its next turn; wind disperses the cloud.
