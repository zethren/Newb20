# True Seeing

*6th-level Divination*

| Spell detail | Rule |
| --- | --- |
| **Level** | 6 |
| **School** | Divination |
| **Class** | Cleric |
| **Spell Lists** | Cleric 6th, Wizard 5th |
| **Casting Time** | Standard Action |
| **Range** | Self |
| **Components** | V, S |
| **Duration** | 10 minutes |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

For 10 minutes, see invisible creatures, visual illusions, and shape-changed forms within 60 feet as they truly are; this does not see through solid objects.
