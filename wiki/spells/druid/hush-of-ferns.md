# Hush of Ferns

| Spell detail | Value |
| --- | --- |
| Level | 2 |
| School | Enchantment |
| Class | Druid |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 1 minute |
| Spell attack | None |
| Saving throw | Wisdom negates |
| Spell resistance | Yes |

## Effect

Up to two creatures must succeed on Wisdom saves or be unable to speak above a whisper for 1 minute; this does not prevent spellcasting.
