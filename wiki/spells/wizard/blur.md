# Blur

| Spell detail | Rule |
| --- | --- |
| Level | 3 (Wizard) |
| School | Illusion |
| Class | Wizard |
| Spell Lists | Cleric 3rd, Wizard 3rd |
| Casting Time | Standard Action |
| Range | Self |
| Components | V, S |
| Duration | 1 minute/CL |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** Your outline shifts for 1 minute/CL, granting Total Concealment against attacks. A creature that does not rely on sight ignores the effect.
