# Spirit Guardians

*7th-level Conjuration*

| Spell detail | Rule |
| --- | --- |
| **Level** | 7 |
| **School** | Conjuration |
| **Class** | Cleric |
| **Casting Time** | Standard Action |
| **Range** | Self |
| **Components** | V, S |
| **Duration** | 1 minute |
| **Attack** | None |
| **Saving Throw** | Will negates half damage |
| **Spell Resistance** | Yes |

## Effect

A 15-foot ring follows you for 1 minute; the first time each round an enemy enters or starts there, a failed Will save deals 1d8 holy damage per 3 caster levels (round up) and halves its speed until its next turn.
