# Stonefoot

| Spell detail | Value |
| --- | --- |
| Level | 2 |
| School | Transmutation |
| Class | Druid |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 10 minutes |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

One willing creature gains advantage on checks to resist forced movement and difficult terrain for 10 minutes.
