# Mislead

| Spell detail | Rule |
| --- | --- |
| Level | 6 (Wizard) |
| School | Illusion |
| Class | Wizard |
| Spell Lists | Cleric 6th, Wizard 6th |
| Casting Time | Standard Action |
| Range | Self |
| Components | V, S |
| Duration | 1 minute/CL |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** Become Invisible and leave a visible double at a point within 30 feet. For 1 minute/CL you may move independently; the double cannot attack or speak.
