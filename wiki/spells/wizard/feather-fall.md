# Feather Fall

| Spell detail | Rule |
| --- | --- |
| Level | 1 (Wizard) |
| School | Transmutation |
| Class | Wizard |
| Spell Lists | Cleric 1st, Wizard 1st |
| Casting Time | Reaction |
| Range | 60 feet |
| Components | V, S |
| Duration | 1 minute |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** When you or up to five creatures within range begin falling, cast as a Reaction to slow the fall to 60 feet per round for 1 minute. None takes damage from that descent.
