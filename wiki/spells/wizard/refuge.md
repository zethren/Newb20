# Refuge

| Spell detail | Rule |
| --- | --- |
| Level | 9 (Wizard) |
| School | Conjuration |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | Touch |
| Components | V, S |
| Duration | Until used |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** Touch a willing creature and create a token linked to a safe room you designate on this plane. Breaking it teleports its bearer and up to six adjacent willing allies there.
