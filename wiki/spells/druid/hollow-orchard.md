# Hollow Orchard

| Spell detail | Value |
| --- | --- |
| Level | 6 |
| School | Necromancy |
| Class | Druid |
| Casting time | Standard Action |
| Range | 120 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | Instantaneous |
| Spell attack | None |
| Saving throw | Constitution half |
| Spell resistance | Yes |

## Effect

Creatures in a 20-foot-radius area make Constitution saves, taking 1d6 corrupt damage per caster level on a failure or half on a success; failed saves also prevent healing until your next turn.
