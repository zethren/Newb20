# Foxglove Double

| Spell detail | Value |
| --- | --- |
| Level | 1 |
| School | Illusion |
| Class | Druid |
| Casting time | Standard Action |
| Range | Self |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 1 minute |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Create a silent illusory copy of yourself in a space within 30 feet; it lasts 1 minute and vanishes if touched.
