# Break Enchantment

| Spell detail | Rule |
| --- | --- |
| Level | 6 (Wizard) |
| School | Abjuration |
| Class | Wizard |
| Spell Lists | Cleric 5th, Wizard 6th |
| Casting Time | Standard Action |
| Range | Touch |
| Components | V, S |
| Duration | Instantaneous |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** Touch one creature to end one spell imposing a condition on it. If the spell is 4th level or higher, succeed on a caster-level check against DC 11 + its caster level.
