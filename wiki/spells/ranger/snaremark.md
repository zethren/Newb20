# Snaremark

| Spell detail | Rule |
| --- | --- |
| Level | 1st |
| School | Abjuration |
| Class | Ranger |
| Casting Time | Standard Action |
| Range | Touch |
| Components | V, S |
| Duration | 8 hours |
| Attack | None |
| Save | None |
| Spell Resistance | No |

## Effect

Mark a point on a surface within reach. If a Small or larger creature crosses within 5 feet of that point, you receive a brief mental alert if you are within 1 mile. The mark does not identify the creature or reveal its direction, and the spell ends after the first alert.
