# Beastmind Glimpse

| Spell detail | Value |
| --- | --- |
| Level | 3 |
| School | Divination |
| Class | Druid |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | Instantaneous |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Choose a beast within range; learn its current emotional state and whether it is hungry, frightened, or injured.
