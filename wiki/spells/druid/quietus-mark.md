# Quietus Mark

| Spell detail | Value |
| --- | --- |
| Level | 2 |
| School | Necromancy |
| Class | Druid |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 1 minute |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Mark one creature for 1 minute; the next time it regains hit points, reduce that healing by 1d8.
