# Cause Fear

*1st-level Necromancy*

| Spell detail | Rule |
| --- | --- |
| **Level** | 1 |
| **School** | Necromancy |
| **Class** | Cleric |
| **Spell Lists** | Cleric 1st, Wizard 1st |
| **Casting Time** | Standard Action |
| **Range** | 30 feet |
| **Components** | V, S |
| **Duration** | 1 minute |
| **Attack** | None |
| **Saving Throw** | Will negates; repeat at end of turn |
| **Spell Resistance** | Yes |

## Effect

One living creature that fails a Will save becomes Shaken for 1 minute and may repeat the save at the end of each turn.
