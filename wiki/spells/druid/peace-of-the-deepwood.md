# Peace of the Deepwood

| Spell detail | Value |
| --- | --- |
| Level | 8 |
| School | Enchantment |
| Class | Druid |
| Casting time | Standard Action |
| Range | 300 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | Concentration, up to 1 minute |
| Spell attack | None |
| Saving throw | Wisdom negates |
| Spell resistance | Yes |

## Effect

Creatures of your choice in a 30-foot-radius area must succeed on Wisdom saves or be charmed by you for 1 minute; taking damage ends the effect.
