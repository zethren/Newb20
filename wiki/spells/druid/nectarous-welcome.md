# Nectarous Welcome

| Spell detail | Value |
| --- | --- |
| Level | 3 |
| School | Enchantment |
| Class | Druid |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 10 minutes |
| Spell attack | None |
| Saving throw | Wisdom negates |
| Spell resistance | Yes |

## Effect

One beast must succeed on a Wisdom save or follow you at a walking pace for 10 minutes; it stops if endangered or attacked.
