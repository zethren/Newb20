# Rootbound Snare

| Spell detail | Rule |
| --- | --- |
| Level | 3rd |
| School | Transmutation |
| Class | Ranger |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | Up to 1 minute |
| Attack | None |
| Save | Strength, negates |
| Spell Resistance | Yes |

## Effect

Roots seize one creature you can see on the ground within range. It must succeed on a Strength saving throw or become restrained. The target repeats the save at the end of each of its turns, ending the spell on a success. The roots can also be destroyed: AC 12, 20 hit points; destroying them ends the spell.
