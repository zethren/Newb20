# Seasonal Premonition

| Spell detail | Value |
| --- | --- |
| Level | 6 |
| School | Divination |
| Class | Druid |
| Casting time | Standard Action |
| Range | 120 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | Instantaneous |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Ask about one likely natural hazard in the next 24 hours within 1 mile; receive a clear sign indicating its type and direction.
