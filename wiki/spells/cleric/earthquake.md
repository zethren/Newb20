# Earthquake

*8th-level Evocation*

| Spell detail | Rule |
| --- | --- |
| **Level** | 8 |
| **School** | Evocation |
| **Class** | Cleric |
| **Casting Time** | Standard Action |
| **Range** | 500 feet |
| **Components** | V, S |
| **Duration** | 1 minute |
| **Attack** | None |
| **Saving Throw** | Reflex negates Prone |
| **Spell Resistance** | No |

## Effect

The ground in a 60-foot radius shakes for 1 minute; a failed Reflex save knocks creatures Prone, movement costs twice as much, and structures suffer severe damage at the GM’s discretion.
