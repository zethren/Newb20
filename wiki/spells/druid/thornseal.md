# Thornseal

| Spell detail | Value |
| --- | --- |
| Level | 3 |
| School | Abjuration |
| Class | Druid |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 1 hour |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Seal a door, chest, or 10-foot opening; opening it without your permission requires a Strength check against your spell save DC.
