# Charm Monster

| Spell detail | Rule |
| --- | --- |
| Level | 4 (Wizard) |
| School | Enchantment |
| Class | Wizard |
| Spell Lists | Cleric 4th, Wizard 4th |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | 1 day/CL |
| Attack | None |
| Saving Throw | Will negates |
| Spell Resistance | Yes |

**Effect.** One creature makes a Will save or regards you as a trusted friend for 1 day/CL. It will not follow a request to directly harm itself.
