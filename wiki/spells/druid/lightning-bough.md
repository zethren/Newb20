# Lightning Bough

| Spell detail | Value |
| --- | --- |
| Level | 4 |
| School | Evocation |
| Class | Druid |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | Instantaneous |
| Spell attack | None |
| Saving throw | Dexterity half |
| Spell resistance | Yes |

## Effect

A 60-foot-long, 5-foot-wide lightning line deals 1d6 electric damage per caster level; creatures in it make Dexterity saves for half.
