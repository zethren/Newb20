# Guiding Bolt

*1st-level Evocation*

| Spell detail | Rule |
| --- | --- |
| **Level** | 1 |
| **School** | Evocation |
| **Class** | Cleric |
| **Casting Time** | Standard Action |
| **Range** | 60 feet |
| **Components** | V, S |
| **Duration** | Instantaneous |
| **Attack** | Ranged spell attack |
| **Saving Throw** | None |
| **Spell Resistance** | Yes |

## Effect

Make a ranged spell attack; on a hit, one creature takes 2d6 holy damage plus 1d6 per 3 caster levels and the next attack against it before your next turn gains +2.
