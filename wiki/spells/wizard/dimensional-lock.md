| Spell detail | Rule |
| --- | --- |
| Level | 8 (Wizard) |
| School | Abjuration |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | 120 feet |
| Components | V, S |
| Duration | 1 day/CL |
| Attack | None |
