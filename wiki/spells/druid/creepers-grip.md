# Creeper's Grip

| Spell detail | Value |
| --- | --- |
| Level | 1 |
| School | Transmutation |
| Class | Druid |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | Instantaneous |
| Spell attack | None |
| Saving throw | Strength negates |
| Spell resistance | Yes |

## Effect

Grow grasping vines in a 10-foot square; one creature in it must succeed on a Strength save or have its speed reduced by 10 feet until your next turn.
