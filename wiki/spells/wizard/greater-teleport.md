# Greater Teleport

| Spell detail | Rule |
| --- | --- |
| Level | 7 (Wizard) |
| School | Conjuration |
| Class | Wizard |
| Spell Lists | Cleric 7th, Wizard 7th |
| Casting Time | Standard Action |
| Range | Self |
| Components | V, S |
| Duration | Instantaneous |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** Teleport yourself and up to six willing creatures to any location on the same plane you can identify. If the exact point is blocked, arrive in the nearest safe space.
