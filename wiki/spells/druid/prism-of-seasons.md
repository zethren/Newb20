# Prism of Seasons

| Spell detail | Value |
| --- | --- |
| Level | 6 |
| School | Transmutation |
| Class | Druid |
| Casting time | Standard Action |
| Range | 120 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 1 hour |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Choose up to four willing creatures; each gains resistance to cold, fire, or electric damage (choose separately) for 1 hour.
