# Unseen Servant

| Spell detail | Rule |
| --- | --- |
| Level | 1 (Wizard) |
| School | Conjuration |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | 1 hour/CL |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** Create an invisible helper for 1 hour/CL. It carries up to 20 pounds and performs one simple task each round, but cannot attack, use magic, or move over 100 feet from you.
