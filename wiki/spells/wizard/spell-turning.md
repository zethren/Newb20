# Spell Turning

| Spell detail | Rule |
| --- | --- |
| Level | 9 (Wizard) |
| School | Abjuration |
| Class | Wizard |
| Spell Lists | Cleric 7th, Wizard 9th |
| Casting Time | Standard Action |
| Range | Self |
| Components | V, S |
| Duration | 1 minute/CL |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** For 1 minute/CL, the first single-target spell of 8th level or lower that affects you instead targets its caster. Area spells are unaffected.
