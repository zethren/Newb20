# Moment of Prescience

*8th-level Divination*

| Spell detail | Rule |
| --- | --- |
| **Level** | 8 |
| **School** | Divination |
| **Class** | Cleric |
| **Spell Lists** | Cleric 8th, Wizard 8th |
| **Casting Time** | Standard Action |
| **Range** | Self |
| **Components** | V, S |
| **Duration** | 1 hour or until used |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

Gain a one-use +10 bonus to an attack roll, save, ability check, or initiative check within 1 hour; choose to use it after rolling but before the result is announced.
