# Call Lightning

| Spell detail | Value |
| --- | --- |
| Level | 3 |
| School | Evocation |
| Class | Druid |
| Casting time | Standard Action |
| Range | 120 feet |
| Components | V, S |
| Duration | 1 minute/CL |
| Spell attack | None |
| Saving throw | Reflex half |
| Spell resistance | No |

## Effect

Call a vertical bolt in a 5-foot-wide, 30-foot-long line from a point in range. The initial bolt strikes when the spell is cast; on later turns, you can spend a Standard Action to call one additional bolt. Each creature in the line takes `1d6` Electric damage per 2 caster levels (round up, minimum `3d6`), with no maximum caster-level cap. A successful Reflex save halves the damage. The spell works indoors and underground but not underwater.
