# Enhance Ability

*2nd-level Transmutation*

| Spell detail | Rule |
| --- | --- |
| **Level** | 2 |
| **School** | Transmutation |
| **Class** | Cleric |
| **Spell Lists** | Cleric 2nd, Paladin 2nd |
| **Casting Time** | Standard Action |
| **Range** | Touch |
| **Components** | V, S |
| **Duration** | 10 minutes/CL |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

Touch one willing creature and choose an ability score; it gains a +2 enhancement bonus to that score for 10 minutes/CL.
