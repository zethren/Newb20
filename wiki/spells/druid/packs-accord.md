# Pack's Accord

| Spell detail | Value |
| --- | --- |
| Level | 2 |
| School | Enchantment |
| Class | Druid |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 10 minutes |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Up to three willing creatures gain +2 on checks made to coordinate or assist one another for 10 minutes.
