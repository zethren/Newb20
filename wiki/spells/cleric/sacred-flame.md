# Sacred Flame

*1st-level Evocation*

| Spell detail | Rule |
| --- | --- |
| **Level** | 1 |
| **School** | Evocation |
| **Class** | Cleric |
| **Casting Time** | Standard Action |
| **Range** | 60 feet |
| **Components** | V, S |
| **Duration** | Instantaneous |
| **Attack** | None |
| **Saving Throw** | Reflex half |
| **Spell Resistance** | Yes |

## Effect

One creature takes 1d8 holy damage, plus 1d8 at caster level 5 and every 5 caster levels thereafter, halved by a Reflex save; cover does not protect it from this light.
