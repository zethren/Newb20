# Vampiric Touch

*3rd-level Necromancy*

| Spell detail | Rule |
| --- | --- |
| **Level** | 3 |
| **School** | Necromancy |
| **Class** | Cleric |
| **Spell Lists** | Cleric 3rd, Wizard 3rd |
| **Casting Time** | Standard Action |
| **Range** | Touch |
| **Components** | V, S |
| **Duration** | Instantaneous |
| **Attack** | Melee spell attack |
| **Saving Throw** | None |
| **Spell Resistance** | Yes |

## Effect

Make a melee spell attack; on a hit, a living creature takes 1d6 negative-energy damage per caster level and you regain HP equal to half the damage dealt.
