# Storm of Vengeance

*9th-level Evocation*

| Spell detail | Rule |
| --- | --- |
| **Level** | 9 |
| **School** | Evocation |
| **Class** | Cleric |
| **Spell Lists** | Cleric 9th, Wizard 9th |
| **Casting Time** | Standard Action |
| **Range** | 300 feet |
| **Components** | V, S |
| **Duration** | 1 minute |
| **Attack** | None |
| **Saving Throw** | Reflex half |
| **Spell Resistance** | Yes |

## Effect

A 60-foot-radius storm follows a point for 1 minute; at the start of each of your turns, creatures inside take 1d6 electric damage per 6 caster levels (round up; Reflex half), and the area is heavily obscured and difficult terrain.
