# Barkskin Aegis

| Spell detail | Value |
| --- | --- |
| Level | 1 |
| School | Abjuration |
| Class | Druid |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 10 minutes/CL |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Grant one creature a +2 Enhancement bonus to Natural Armor AC until the duration ends; it also ignores the first 3 damage from each nonmagical hit.
