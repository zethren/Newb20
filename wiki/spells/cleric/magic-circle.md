# Magic Circle

*3rd-level Abjuration*

| Spell detail | Rule |
| --- | --- |
| **Level** | 3 |
| **School** | Abjuration |
| **Class** | Cleric |
| **Spell Lists** | Cleric 3rd, Paladin 3rd |
| **Casting Time** | Standard Action |
| **Range** | 60 feet |
| **Components** | V, S |
| **Duration** | 10 minutes |
| **Attack** | None |
| **Saving Throw** | Will negates entry |
| **Spell Resistance** | Yes |

## Effect

A 10-foot-radius ward lasts 10 minutes; allies inside gain +2 on saves against enchantment, and a summoned creature must pass a Will save to enter.
