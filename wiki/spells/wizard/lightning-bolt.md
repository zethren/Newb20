# Lightning Bolt

| Spell detail | Rule |
| --- | --- |
| Level | 3 (Wizard) |
| School | Evocation |
| Class | Wizard |
| Spell Lists | Cleric 3rd, Wizard 3rd |
| Casting Time | Standard Action |
| Range | Self (100-foot line) |
| Components | V, S |
| Duration | Instantaneous |
| Attack | None |
| Saving Throw | Reflex half |
| Spell Resistance | Yes |

**Effect.** A 100-foot-long, 5-foot-wide line of lightning deals 1d6 electric damage per caster level to each creature in its path, Reflex half.
