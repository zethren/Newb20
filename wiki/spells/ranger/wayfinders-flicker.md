# Wayfinder's Flicker

| Spell detail | Rule |
| --- | --- |
| Level | 1st |
| School | Divination |
| Class | Ranger |
| Casting Time | Standard Action |
| Range | Self |
| Components | V, S |
| Duration | 10 minutes |
| Attack | None |
| Save | None |
| Spell Resistance | No |

## Effect

Name or clearly visualize a destination you have visited or can see. A faint glimmer indicates the direction of the shortest practicable route toward it, but not distance, hazards, or the route beyond your current plane. If no route exists on this plane, the spell gives no direction.
