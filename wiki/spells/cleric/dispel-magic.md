# Dispel Magic

*3rd-level Abjuration*

| Spell detail | Rule |
| --- | --- |
| **Level** | 3 |
| **School** | Abjuration |
| **Class** | Cleric |
| **Spell Lists** | Cleric 3rd, Paladin 3rd, Wizard 3rd |
| **Casting Time** | Standard Action |
| **Range** | 60 feet |
| **Components** | V, S |
| **Duration** | Instantaneous |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

Choose one creature, object, or 10-foot cube. For each spell of 3rd level or lower affecting it, check 1d20 + caster level against DC 11 + spell level; each success ends that spell.
