# Captive Attention

| Spell detail | Value |
| --- | --- |
| Level | 7 |
| School | Enchantment |
| Class | Druid |
| Casting time | Standard Action |
| Range | 120 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | Concentration, up to 1 minute |
| Spell attack | None |
| Saving throw | Wisdom negates |
| Spell resistance | Yes |

## Effect

Creatures in a 20-foot-radius area must make Wisdom saves; on a failure, they cannot willingly move farther from you for 1 minute, repeating the save when damaged.
