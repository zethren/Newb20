# Burrowstep

| Spell detail | Value |
| --- | --- |
| Level | 2 |
| School | Conjuration |
| Class | Druid |
| Casting time | Standard Action |
| Range | Self |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | Instantaneous |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Teleport yourself and one willing adjacent creature to unoccupied spaces you can see within 30 feet; neither space may be behind a sealed barrier.
