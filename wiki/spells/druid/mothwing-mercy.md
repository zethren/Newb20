# Mothwing Mercy

| Spell detail | Value |
| --- | --- |
| Level | 1 |
| School | Necromancy |
| Class | Druid |
| Casting time | Standard Action |
| Range | Touch |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 1 hour |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

One creature you touch gains 1d6 temporary hit points for 1 hour; these do not stack with themselves.
