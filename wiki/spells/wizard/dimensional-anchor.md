# Dimensional Anchor

| Spell detail | Rule |
| --- | --- |
| Level | 4 (Wizard) |
| School | Abjuration |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | 1 minute/CL |
| Attack | Ranged spell attack (spell attack bonus) |
| Saving Throw | None |
| Spell Resistance | Yes |

**Effect.** A ranged spell attack hit prevents one creature from teleporting, changing planes, or becoming incorporeal for 1 minute/CL.
