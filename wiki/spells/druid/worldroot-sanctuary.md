# Worldroot Sanctuary

| Spell detail | Value |
| --- | --- |
| Level | 9 |
| School | Abjuration |
| Class | Druid |
| Casting time | Standard Action |
| Range | 300 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | Concentration, up to 1 minute |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Create a 60-foot-radius sanctuary for 10 creatures; allies inside gain resistance to all damage and cannot be forcibly moved for the duration.
