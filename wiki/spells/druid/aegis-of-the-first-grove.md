# Aegis of the First Grove

| Spell detail | Value |
| --- | --- |
| Level | 9 |
| School | Abjuration |
| Class | Druid |
| Casting time | Standard Action |
| Range | 300 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 1 round/CL |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Up to six creatures gain immunity to one damage type you choose from acid, cold, fire, lightning, or poison for the duration.
