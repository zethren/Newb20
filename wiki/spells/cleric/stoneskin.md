# Stoneskin

*4th-level Conjuration*

| Spell detail | Rule |
| --- | --- |
| **Level** | 4 |
| **School** | Conjuration |
| **Class** | Cleric |
| **Spell Lists** | Cleric 4th, Paladin 4th, Wizard 4th |
| **Casting Time** | Standard Action |
| **Range** | Touch |
| **Components** | V, S |
| **Duration** | 10 minutes |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

One willing creature reduces physical damage from each weapon hit by 5 for 10 minutes; the spell ends after reducing 50 total damage.
