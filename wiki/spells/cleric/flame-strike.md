# Flame Strike

*5th-level Evocation*

| Spell detail | Rule |
| --- | --- |
| **Level** | 5 |
| **School** | Evocation |
| **Class** | Cleric |
| **Spell Lists** | Cleric 5th, Wizard 5th |
| **Casting Time** | Standard Action |
| **Range** | 120 feet |
| **Components** | V, S |
| **Duration** | Instantaneous |
| **Attack** | None |
| **Saving Throw** | Reflex half |
| **Spell Resistance** | Yes |

## Effect

A 10-foot-radius, 40-foot-high column deals 1d6 damage per caster level, half fire and half holy; a successful Reflex save halves the total.
