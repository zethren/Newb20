# Regenerate Limb

*7th-level Transmutation*

| Spell detail | Rule |
| --- | --- |
| **Level** | 7 |
| **School** | Transmutation |
| **Class** | Cleric |
| **Casting Time** | Standard Action |
| **Range** | Touch |
| **Components** | V, S |
| **Duration** | 1 minute |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

Over 1 minute, restore one severed hand, foot, or ear of a living creature you touch; it must remain above 0 HP for the casting, and the spell cannot regrow a head or revive the dead.
