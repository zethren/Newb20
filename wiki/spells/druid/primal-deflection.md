# Primal Deflection

| Spell detail | Value |
| --- | --- |
| Level | 7 |
| School | Abjuration |
| Class | Druid |
| Casting time | Standard Action |
| Range | 120 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 1 minute/CL |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

For the duration, a creature gains a +3 Deflection bonus to Deflection AC and advantage on saves against spells that deal elemental damage.
