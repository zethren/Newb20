# Confluence of Minds

| Spell detail | Value |
| --- | --- |
| Level | 9 |
| School | Enchantment |
| Class | Druid |
| Casting time | Standard Action |
| Range | 300 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 8 hours |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Up to ten willing creatures share thoughts, speech, and willing sensory impressions across any distance on the same plane for 8 hours.
