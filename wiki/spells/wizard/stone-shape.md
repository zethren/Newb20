# Stone Shape

| Spell detail | Rule |
| --- | --- |
| Level | 4 (Wizard) |
| School | Transmutation |
| Class | Wizard |
| Spell Lists | Cleric 3rd, Wizard 4th |
| Casting Time | Standard Action |
| Range | Touch |
| Components | V, S |
| Duration | Permanent |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** Reshape a nonmagical stone object or section up to a 5-foot cube into a solid design. The new form has no moving parts and remains until physically altered.
