# Pathfinder's Instinct

| Spell detail | Value |
| --- | --- |
| Level | 4 |
| School | Divination |
| Class | Druid |
| Casting time | Standard Action |
| Range | Self |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 1 hour |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

For 1 hour, you know the direction of the nearest safe route to a destination you can name within 5 miles.
