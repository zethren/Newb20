# Chain Lightning

| Spell detail | Rule |
| --- | --- |
| Level | 6 (Wizard) |
| School | Evocation |
| Class | Wizard |
| Spell Lists | Cleric 7th, Wizard 6th |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | Instantaneous |
| Attack | Ranged spell attack (spell attack bonus) |
| Saving Throw | Reflex half for secondary targets |
| Spell Resistance | Yes |

**Effect.** A ranged spell attack deals 1d6 electric damage per caster level to one target. It jumps to four creatures within 30 feet of the last target for half damage, Reflex half.
