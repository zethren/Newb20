# Contagion

*5th-level Necromancy*

| Spell detail | Rule |
| --- | --- |
| **Level** | 5 |
| **School** | Necromancy |
| **Class** | Cleric |
| **Spell Lists** | Cleric 5th, Wizard 5th |
| **Casting Time** | Standard Action |
| **Range** | Touch |
| **Components** | V, S |
| **Duration** | 1 minute |
| **Attack** | Melee spell attack |
| **Saving Throw** | Fortitude negates Sickened |
| **Spell Resistance** | Yes |

## Effect

Make a melee spell attack against a living creature; on a hit it takes 1d6 poison damage per 2 caster levels (round up) and becomes Sickened for 1 minute, negated by a Fortitude save.
