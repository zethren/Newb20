# Speak with Dead

*3rd-level Necromancy*

| Spell detail | Rule |
| --- | --- |
| **Level** | 3 |
| **School** | Necromancy |
| **Class** | Cleric |
| **Spell Lists** | Cleric 3rd, Wizard 3rd |
| **Casting Time** | Standard Action |
| **Range** | Touch |
| **Components** | V, S |
| **Duration** | 10 minutes |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

Ask a corpse up to five questions about events it witnessed in life; it answers truthfully from its knowledge but cannot learn new facts.
