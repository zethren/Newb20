# Locate Creature

*4th-level Divination*

| Spell detail | Rule |
| --- | --- |
| **Level** | 4 |
| **School** | Divination |
| **Class** | Cleric |
| **Spell Lists** | Cleric 4th, Wizard 4th |
| **Casting Time** | Standard Action |
| **Range** | Self |
| **Components** | V, S |
| **Duration** | 1 hour |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

Name a creature you know; for 1 hour, sense its direction while it is within 1 mile, unless running water at least 10 feet wide blocks the sense.
