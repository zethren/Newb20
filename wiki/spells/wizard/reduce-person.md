# Reduce Person

| Spell detail | Value |
| --- | --- |
| Level | 1 |
| School | Transmutation (Polymorph) |
| Class | Wizard |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a pinch of powdered iron) |
| Duration | 1 minute/CL |
| Spell attack | None |
| Saving throw | Fortitude negates (harmless) |
| Spell resistance | Yes |

## Effect

One humanoid decreases by one Size category, to a minimum of Diminutive. An unwilling target can make a Fortitude save to resist. Apply all relevant modifiers, space, reach, and weapon damage from the new Size in [Combat Scaling](../../game-mechanics/combat-scaling.md#size-modifiers); the spell grants no separate ability-score or AC adjustments. Worn and carried equipment shrinks with the creature and returns to normal size when separated from it or when the spell ends. This is a Polymorph effect; use the shared [space and confinement rule](../../game-mechanics/transformations.md#space-and-confines-during-polymorph).

This spell counters and is dispelled by [Enlarge Person](enlarge-person.md). Multiple size-changing Polymorph effects do not stack.
