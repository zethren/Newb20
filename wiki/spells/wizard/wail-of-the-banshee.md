| Spell detail | Rule |
| --- | --- |
| Level | 9 (Wizard) |
| School | Necromancy |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | Instantaneous |
| Attack | None |
