# Vision

| Spell detail | Rule |
| --- | --- |
| Level | 9 (Wizard) |
| School | Divination |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | 1 minute |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** Ask one question about a creature, place, or event you encountered. In 1 minute, receive a truthful answer of up to three sentences; the spell cannot predict an unmade choice.
