# Water Breathing

*3rd-level Transmutation*

| Spell detail | Rule |
| --- | --- |
| **Level** | 3 |
| **School** | Transmutation |
| **Class** | Cleric |
| **Casting Time** | Standard Action |
| **Range** | 30 feet |
| **Components** | V, S |
| **Duration** | 1 hour/CL |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

Up to six willing creatures can breathe underwater as easily as air for 1 hour/CL; this grants no swimming speed.
