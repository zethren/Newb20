# Scrying

| Spell detail | Rule |
| --- | --- |
| Level | 5 (Wizard) |
| School | Divination |
| Class | Wizard |
| Spell Lists | Cleric 5th, Wizard 5th |
| Casting Time | Standard Action |
| Range | Self |
| Components | V, S |
| Duration | 1 minute |
| Attack | None |
| Saving Throw | Will negates |
| Spell Resistance | Yes |

**Effect.** One creature you know makes a Will save. On failure, see and hear its surroundings for 1 minute, wherever it is on your plane; on success, it senses the attempt and is immune to your Scrying for a day.
