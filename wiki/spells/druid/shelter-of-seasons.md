# Shelter of Seasons

| Spell detail | Value |
| --- | --- |
| Level | 6 |
| School | Abjuration |
| Class | Druid |
| Casting time | Standard Action |
| Range | 120 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 1 hour |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Create a 20-foot-radius shelter that blocks ordinary wind, rain, and heat; up to eight creatures inside gain +2 on saves against environmental hazards for the duration.
