# Unbroken Bough

| Spell detail | Value |
| --- | --- |
| Level | 4 |
| School | Abjuration |
| Class | Druid |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | Instantaneous |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

A creature that would fall to 0 hit points instead remains at 1 hit point; the spell then ends.
