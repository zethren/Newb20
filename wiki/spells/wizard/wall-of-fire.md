# Wall of Fire

| Spell detail | Rule |
| --- | --- |
| Level | 4 (Wizard) |
| School | Evocation |
| Class | Wizard |
| Spell Lists | Cleric 4th, Wizard 4th |
| Casting Time | Standard Action |
| Range | 120 feet |
| Components | V, S |
| Duration | 1 minute/CL |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | Yes |

**Effect.** Raise a 20-foot-long, 10-foot-high wall of flame for 1 minute/CL. Passing through deals 2d6 fire damage plus 1d6 per 3 caster levels; creatures adjacent when formed take 1d6 plus 1d6 per 4 caster levels (Reflex half).
