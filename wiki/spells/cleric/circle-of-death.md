# Circle of Death

*6th-level Necromancy*

| Spell detail | Rule |
| --- | --- |
| **Level** | 6 |
| **School** | Necromancy |
| **Class** | Cleric |
| **Spell Lists** | Cleric 6th, Wizard 6th |
| **Casting Time** | Standard Action |
| **Range** | 120 feet |
| **Components** | V, S |
| **Duration** | Instantaneous |
| **Attack** | None |
| **Saving Throw** | Fortitude half |
| **Spell Resistance** | Yes |

## Effect

Creatures in a 20-foot-radius burst take 1d6 negative-energy damage per caster level (Fortitude half); undead instead regain HP equal to half the damage rolled.
