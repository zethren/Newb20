# Word of Recall

*6th-level Conjuration*

| Spell detail | Rule |
| --- | --- |
| **Level** | 6 |
| **School** | Conjuration |
| **Class** | Cleric |
| **Casting Time** | Standard Action |
| **Range** | Touch |
| **Components** | V, S |
| **Duration** | 24 hours |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

Choose a consecrated sanctuary you have visited; you and up to five willing creatures touching you can teleport there from the same plane within 24 hours.
