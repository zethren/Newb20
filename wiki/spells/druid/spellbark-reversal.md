# Spellbark Reversal

| Spell detail | Value |
| --- | --- |
| Level | 8 |
| School | Abjuration |
| Class | Druid |
| Casting time | Standard Action |
| Range | Touch |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 1 hour |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

When a spell of 7th level or lower targets one creature you touch, negate it and end this spell; otherwise this ward lasts 1 hour.
