| Spell detail | Value |
| --- | --- |
| Level | 3 |
| School | Conjuration |
| Class | Druid |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a leaf or seed, not consumed) |

| Saving throw | None |

## Effect
