# Major Image

| Spell detail | Rule |
| --- | --- |
| Level | 3 (Wizard) |
| School | Illusion |
| Class | Wizard |
| Spell Lists | Cleric 3rd, Wizard 3rd |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | 10 minutes/CL |
| Attack | None |
