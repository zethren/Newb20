# Heroism

*6th-level Enchantment*

| Spell detail | Rule |
| --- | --- |
| **Level** | 6 |
| **School** | Enchantment |
| **Class** | Cleric |
| **Spell Lists** | Cleric 6th, Paladin 2nd, Wizard 3rd |
| **Casting Time** | Standard Action |
| **Range** | Touch |
| **Components** | V, S |
| **Duration** | 1 hour/CL |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

One willing creature gains a +2 morale bonus on attack rolls, saves, and skill checks for 1 hour/CL; it does not stack with another morale bonus.
