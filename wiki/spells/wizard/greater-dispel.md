# Greater Dispel

| Spell detail | Rule |
| --- | --- |
| Level | 7 (Wizard) |
| School | Abjuration |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | 120 feet |
| Components | V, S |
| Duration | Instantaneous |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** Choose any number of creatures and objects in a 20-foot-radius burst. Roll 1d20 + caster level against DC 11 + each spell effect caster level; end every effect you defeat.
