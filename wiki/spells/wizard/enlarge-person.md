# Enlarge Person

| Spell detail | Value |
| --- | --- |
| Level | 1 |
| School | Transmutation (Polymorph) |
| Class | Wizard |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a pinch of iron filings) |
| Duration | 1 minute/CL |
| Spell attack | None |
| Saving throw | Fortitude negates (harmless) |
| Spell resistance | Yes |

## Effect

One humanoid gains a +1 Enhancement bonus to its Size category, increasing its actual size by one category, up to Colossal. The spell has no effect on a Colossal target. Enhancement bonuses to the same value do not stack. An unwilling target can make a Fortitude save to resist. Apply all relevant modifiers, space, reach, and weapon damage from the new Size in [Combat Scaling](../../game-mechanics/combat-scaling.md#size-modifiers); the spell grants no separate ability-score or AC adjustments. Worn and carried equipment enlarges with the creature and returns to normal size when separated from it or when the spell ends. Use the shared [space and confinement rule](../../game-mechanics/transformations.md#space-and-confines-during-polymorph).

This spell counters and is dispelled by [Reduce Person](reduce-person.md).
