# Lesser Restoration

| Spell detail | Value |
| --- | --- |
| Level | 2 |
| School | Conjuration |
| Class | Druid |
| Spell Lists | Cleric 2nd, Druid 2nd |
| Casting time | Standard Action |
| Range | Touch |
| Components | V, S |
| Duration | Instantaneous |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Touch a creature to end one of these conditions: Blinded, Deafened, Fatigued, or Sickened. You can also restore temporary ability damage equal to a roll of 1d4 from one ability score. This spell does not restore permanent ability damage.
