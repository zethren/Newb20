# Ironwood

| Spell detail | Value |
| --- | --- |
| Level | 6 |
| School | Transmutation |
| Class | Druid |
| Casting time | Standard Action |
| Range | Touch |
| Components | V, S, M (a leaf) |
| Duration | 1 day/CL |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Touch one wooden item or a quantity of worked wood weighing up to 20 pounds/CL. For the duration, the wood has the strength and durability of steel, but retains its original form, weight, and other statistics. The spell does not make the item magical or grant an enhancement bonus. Ironwood remains wood, not metal, and a Druid may wear or use it despite the Nature's Metal Prohibition.
