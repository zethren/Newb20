# Protection from Evil

*1st-level Abjuration*

| Spell detail | Rule |
| --- | --- |
| **Level** | 1 |
| **School** | Abjuration |
| **Class** | Cleric |
| **Spell Lists** | Cleric 1st, Paladin 1st |
| **Casting Time** | Standard Action |
| **Range** | 30 feet |
| **Components** | V, S |
| **Duration** | 1 minute/CL |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

One creature you can see gains a +2 bonus on saves against spells cast by a creature you name and a +2 Deflection bonus to Deflection AC against that creature for 1 minute/CL.
