# Spring Renewal

| Spell detail | Value |
| --- | --- |
| Level | 3 |
| School | Evocation |
| Class | Druid |
| Casting time | Standard Action |
| Range | Touch |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 2 rounds |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Up to three living creatures you touch each regain 1d8 hit points at the start of each of their next two turns. This spell has no effect on undead.
