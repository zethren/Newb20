# Scorching Ray

| Spell detail | Rule |
| --- | --- |
| Level | 2 (Wizard) |
| School | Evocation |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | Instantaneous |
| Attack | Three ranged spell attacks (spell attack bonus) |
| Saving Throw | None |
| Spell Resistance | Yes |

**Effect.** Make three ranged spell attacks, plus one additional ray for every 4 caster levels after 3rd; each deals 2d6 fire damage on a hit. Rays may target the same creature or different creatures.
