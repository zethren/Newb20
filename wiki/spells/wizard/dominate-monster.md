# Dominate Monster

| Spell detail | Rule |
| --- | --- |
| Level | 9 (Wizard) |
| School | Enchantment |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | 1 hour/CL |
| Attack | None |
| Saving Throw | Will negates; repeat hourly |
| Spell Resistance | Yes |

**Effect.** One creature makes a Will save or obeys your spoken commands for 1 hour/CL. It repeats the save hourly and when ordered to harm itself.
