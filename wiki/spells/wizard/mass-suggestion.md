# Mass Suggestion

| Spell detail | Rule |
| --- | --- |
| Level | 6 (Wizard) |
| School | Enchantment |
| Class | Wizard |
| Spell Lists | Cleric 5th, Wizard 6th |
| Casting Time | Standard Action |
| Range | 120 feet |
| Components | V, S |
| Duration | Up to 1 day |
| Attack | None |
| Saving Throw | Will negates |
| Spell Resistance | Yes |

**Effect.** Up to six creatures that hear and understand you make Will saves or follow the same brief, non-self-destructive course of action for up to 1 day.
