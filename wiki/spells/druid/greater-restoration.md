# Greater Restoration

| Spell detail | Value |
| --- | --- |
| Level | 7 |
| School | Conjuration |
| Class | Druid |
| Spell Lists | Cleric 7th, Druid 7th |
| Casting time | Standard Action |
| Range | Touch |
| Components | V, S, M (diamond dust worth 500 gp, consumed) |
| Duration | Instantaneous |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Touch one creature to restore temporary ability damage equal to a roll of 4d4 and permanent ability damage equal to a roll of 1d4. You may distribute the restored points among its ability scores.
