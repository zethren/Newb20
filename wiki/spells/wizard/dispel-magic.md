# Dispel Magic

| Spell detail | Rule |
| --- | --- |
| Level | 3 (Wizard) |
| School | Abjuration |
| Class | Wizard |
| Spell Lists | Cleric 3rd, Wizard 3rd |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | Instantaneous |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** Choose one spell effect on a creature or object. Roll 1d20 + caster level against DC 11 + the effect caster level; success ends that effect.
