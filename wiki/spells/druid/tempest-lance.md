# Tempest Lance

| Spell detail | Value |
| --- | --- |
| Level | 6 |
| School | Evocation |
| Class | Druid |
| Casting time | Standard Action |
| Range | 120 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | Instantaneous |
| Spell attack | Ranged spell attack (use your spell attack bonus) |
| Saving throw | None |
| Spell resistance | Yes |

## Effect

Make a ranged spell attack against one creature; on a hit it takes 1d6 electric damage per caster level and cannot take Reactions until its next turn.
