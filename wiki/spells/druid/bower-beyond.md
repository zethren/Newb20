# Bower Beyond

| Spell detail | Value |
| --- | --- |
| Level | 8 |
| School | Conjuration |
| Class | Druid |
| Casting time | Standard Action |
| Range | 300 feet |
| Components | V, S, M (a leaf or seed, not consumed) |

| Spell attack | None |
| Saving throw | None |

## Effect

Create a furnished, weatherproof extradimensional glade for up to twelve creatures; the entrance is a visible arch and the refuge lasts 8 hours.
