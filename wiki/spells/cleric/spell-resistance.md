# Spell Resistance

*5th-level Abjuration*

| Spell detail | Rule |
| --- | --- |
| **Level** | 5 |
| **School** | Abjuration |
| **Class** | Cleric |
| **Spell Lists** | Cleric 5th, Wizard 5th |
| **Casting Time** | Standard Action |
| **Range** | Touch |
| **Components** | V, S |
| **Duration** | 1 minute/CL |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

A willing creature you touch gains Spell Resistance 12 + your caster level for 1 minute/CL.
