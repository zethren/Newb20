# Greater Scrying

| Spell detail | Rule |
| --- | --- |
| Level | 7 (Wizard) |
| School | Divination |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | Self |
| Components | V, S |
| Duration | 10 minutes |
| Attack | None |
| Saving Throw | Will negates |
| Spell Resistance | Yes |

**Effect.** Scry on a creature you know on any plane. A failed Will save lets you see and hear it for 10 minutes; on success it senses the attempt and is immune for one day.
