# Cinderless Camp

| Spell detail | Rule |
| --- | --- |
| Level | 1st |
| School | Abjuration |
| Class | Ranger |
| Casting Time | 1 minute |
| Range | Touch |
| Components | V, S, a pinch of ash |
| Duration | 8 hours |
| Attack | None |
| Save | None |
| Spell Resistance | No |

## Effect

Choose a campsite no larger than a 15-foot-radius area. For the duration, the spell suppresses the camp's light, smoke, and ordinary cooking odors beyond its boundary and muffles routine conversation within it. It does not conceal tracks, movement, or the camp from direct observation.
