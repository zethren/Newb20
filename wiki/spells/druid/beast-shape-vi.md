# Beast Shape VI

| Spell detail | Value |
| --- | --- |
| Level | 9 |
| School | Transmutation (Polymorph) |
| Class | Druid |
| Casting time | Standard Action |
| Range | 30 feet |
| Components | V, S, M (a sample or tuft from each chosen creature) |
| Duration | 1 hour/CL |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

You and up to nine willing creatures within range each assume an animal or magical-beast form permitted by [Beast Shape IV](beast-shape-iv.md). Each target may choose a different eligible form and can change to another eligible form as a Standard Action while the spell lasts. Apply the chosen form's physical ability adjustments and Natural Armor bonus to Natural Armor AC, and adjust AC for its current Size. The [Transformation Rules](../../game-mechanics/transformations.md#polymorph-and-wild-shape) govern equipment and other form restrictions; use the shared [space and confinement rule](../../game-mechanics/transformations.md#space-and-confines-during-polymorph) if a new form cannot fit. Each target can end its own transformation as a Free Action.
