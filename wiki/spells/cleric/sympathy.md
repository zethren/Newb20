# Sympathy

*8th-level Enchantment*

| Spell detail | Rule |
| --- | --- |
| **Level** | 8 |
| **School** | Enchantment |
| **Class** | Cleric |
| **Casting Time** | Standard Action |
| **Range** | 60 feet |
| **Components** | V, S |
| **Duration** | 1 minute |
| **Attack** | None |
| **Saving Throw** | Will negates |
| **Spell Resistance** | Yes |

## Effect

Creatures you designate that see a chosen creature or object must pass a Will save or spend their next turn moving toward it by a safe route; damage ends the attraction.
