# Wall of Stone

| Spell detail | Rule |
| --- | --- |
| Level | 6 (Wizard) |
| School | Conjuration |
| Class | Wizard |
| Spell Lists | Cleric 5th, Wizard 6th |
| Casting Time | Standard Action |
| Range | 120 feet |
| Components | V, S |
| Duration | Permanent |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** Raise a 20-foot-long, 10-foot-high stone wall, 1 foot thick, on solid ground. It blocks movement and sight, has 100 HP, and remains until destroyed.
