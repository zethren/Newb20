# Banishment

*7th-level Abjuration*

| Spell detail | Rule |
| --- | --- |
| **Level** | 7 |
| **School** | Abjuration |
| **Class** | Cleric |
| **Spell Lists** | Cleric 7th, Wizard 4th |
| **Casting Time** | Standard Action |
| **Range** | 60 feet |
| **Components** | V, S |
| **Duration** | Instantaneous |
| **Attack** | None |
| **Saving Throw** | Will negates |
| **Spell Resistance** | Yes |

## Effect

One extraplanar creature must pass a Will save or return to its home plane; it cannot return to this location for 24 hours, and the spell does not affect a native creature.
