# Maze

| Spell detail | Rule |
| --- | --- |
| Level | 8 (Wizard) |
| School | Conjuration |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | Up to 1 minute |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | Yes |

**Effect.** One creature vanishes into an extradimensional maze for up to 1 minute. At the end of each turn it may make an Intelligence check against DC 20 to return; the spell also ends if you die.
