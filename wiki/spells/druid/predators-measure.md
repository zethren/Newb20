# Predator's Measure

| Spell detail | Value |
| --- | --- |
| Level | 5 |
| School | Divination |
| Class | Druid |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | Instantaneous |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Study one creature you can see; learn its current hit points relative to yours and one damage resistance or immunity, if any.
