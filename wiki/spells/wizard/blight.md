# Blight

| Spell detail | Rule |
| --- | --- |
| Level | 4 (Wizard) |
| School | Necromancy |
| Class | Wizard |
| Spell Lists | Cleric 4th, Wizard 4th |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | Instantaneous |
| Attack | None |
| Saving Throw | Fortitude partial |
| Spell Resistance | Yes |

**Effect.** One living creature makes a Fortitude save or takes 1d6 corrupt damage per caster level and becomes Sickened for 1 minute. Success halves damage and negates Sickened.
