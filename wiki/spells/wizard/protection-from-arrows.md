# Protection from Arrows

| Spell detail | Rule |
| --- | --- |
| Level | 2 (Wizard) |
| School | Abjuration |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | Touch |
| Components | V, S |
| Duration | 10 minutes/CL |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** One creature touched ignores the first 20 damage from nonmagical ranged weapon attacks each round for 10 minutes/CL.
