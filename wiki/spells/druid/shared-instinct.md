# Shared Instinct

| Spell detail | Value |
| --- | --- |
| Level | 4 |
| School | Enchantment |
| Class | Druid |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 1 hour |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Up to four willing creatures can exchange simple emotions and sensory impressions with one another for 1 hour while within 1 mile.
