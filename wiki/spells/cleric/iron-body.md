# Iron Body

*8th-level Transmutation*

| Spell detail | Rule |
| --- | --- |
| **Level** | 8 |
| **School** | Transmutation |
| **Class** | Cleric |
| **Spell Lists** | Cleric 8th, Wizard 8th |
| **Casting Time** | Standard Action |
| **Range** | Self |
| **Components** | V, S |
| **Duration** | 1 minute/CL |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

For 1 minute/CL, gain a +4 Enhancement bonus to Natural Armor AC and a +4 bonus on saves against poison; your movement speed is halved and you cannot swim.
