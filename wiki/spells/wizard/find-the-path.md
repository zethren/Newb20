# Find the Path

| Spell detail | Rule |
| --- | --- |
| Level | 6 (Wizard) |
| School | Divination |
| Class | Wizard |
| Spell Lists | Cleric 6th, Wizard 6th |
| Casting Time | Standard Action |
| Range | Self |
| Components | V, S |
| Duration | 1 hour/CL |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** Name a destination you have visited on this plane. For 1 hour/CL, know the shortest passable route and whether your next turn would lead into a dead end.
