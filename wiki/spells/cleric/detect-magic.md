# Detect Magic

*1st-level Divination*

| Spell detail | Rule |
| --- | --- |
| **Level** | 1 |
| **School** | Divination |
| **Class** | Cleric |
| **Spell Lists** | Cleric 1st, Paladin 1st, Wizard 1st |
| **Casting Time** | Standard Action |
| **Range** | Self |
| **Components** | V, S |
| **Duration** | 10 minutes |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

For 10 minutes, sense active spells within 30 feet and learn each aura’s location and school, but not its purpose or caster.
