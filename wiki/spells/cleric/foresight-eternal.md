# Foresight Eternal

*9th-level Divination*

| Spell detail | Rule |
| --- | --- |
| **Level** | 9 |
| **School** | Divination |
| **Class** | Cleric |
| **Casting Time** | Standard Action |
| **Range** | 60 feet |
| **Components** | V, S |
| **Duration** | 1 hour |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

Choose up to six willing creatures you see; for 1 hour they cannot be surprised and each gains +4 on its first Reflex save during the spell.
