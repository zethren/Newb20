# Move Earth

| Spell detail | Rule |
| --- | --- |
| Level | 6 (Wizard) |
| School | Transmutation |
| Class | Wizard |
| Spell Lists | Cleric 6th, Wizard 6th |
| Casting Time | Standard Action |
| Range | 300 feet |
| Components | V, S |
| Duration | Permanent |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** Shift a 40-foot-square area of loose earth up to 10 feet to form a trench, berm, or level surface. Creatures on it move with the ground and do not fall.
