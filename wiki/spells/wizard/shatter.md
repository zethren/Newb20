# Shatter

| Spell detail | Rule |
| --- | --- |
| Level | 2 (Wizard) |
| School | Evocation |
| Class | Wizard |
| Spell Lists | Cleric 5th, Wizard 2nd |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | Instantaneous |
| Attack | None |
| Saving Throw | Fortitude half |
| Spell Resistance | Yes |

**Effect.** Brittle nonmagical objects in a 10-foot burst break. Creatures there take 1d6 sonic damage per caster level, Fortitude half.
