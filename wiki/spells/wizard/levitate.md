# Levitate

| Spell detail | Rule |
| --- | --- |
| Level | 2 (Wizard) |
| School | Transmutation |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | 10 minutes/CL |
| Attack | None |
| Saving Throw | Fortitude negates if unwilling |
| Spell Resistance | Yes |

**Effect.** One creature or object weighing up to 500 pounds rises or descends vertically 20 feet per round for 10 minutes/CL; it cannot move horizontally without a surface to push against.
