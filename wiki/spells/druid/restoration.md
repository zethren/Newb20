# Restoration

| Spell detail | Value |
| --- | --- |
| Level | 4 |
| School | Conjuration |
| Class | Druid |
| Spell Lists | Cleric 4th, Druid 4th |
| Casting time | Standard Action |
| Range | Touch |
| Components | V, S |
| Duration | Instantaneous |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Touch one creature to restore temporary ability damage equal to a roll of 2d4 and 1 point of permanent ability damage. You may distribute the restored points among its ability scores.
