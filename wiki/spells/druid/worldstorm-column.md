# Worldstorm Column

| Spell detail | Value |
| --- | --- |
| Level | 8 |
| School | Evocation |
| Class | Druid |
| Casting time | Standard Action |
| Range | 300 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | Instantaneous |
| Spell attack | None |
| Saving throw | Dexterity half |
| Spell resistance | Yes |

## Effect

A 20-foot-radius, 40-foot-high column deals 1d8 electric damage per caster level; creatures inside make Dexterity saves for half.
