# Skills

## Skill Checks

For a check against a fixed Difficulty Class (DC), roll:

`d20 + skill ranks + relevant ability modifier + applicable bonuses`

The check succeeds if its total meets or exceeds the DC. For a contested check, both sides roll their check totals; the higher total wins, and the defender wins ties.

Characters may attempt checks without ranks unless a specific skill requires training. Maximum ranks in a skill equal character level, to a maximum of 20. Each class grants a base number of skill ranks per level plus the character's Intelligence modifier, to a minimum of 1 rank per level. There is no first-level multiplier. A skill designated as a class skill grants a **+3 Class Skill bonus** to checks with that skill. This bonus is separate from skill ranks and follows the stacking rules in [Attributes](attributes.md#bonus-types-and-stacking).

## Skill Synergies

A skill page may list a Synergy bonus to a related skill. Once a character has at least **5 ranks** in the source skill, they gain a **+2 Synergy bonus** to the named target skill check. The bonus is flat and does not increase with additional ranks. Synergy bonuses from different source skills stack.
