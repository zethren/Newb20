| Spell detail | Value |
| --- | --- |
| Level | 7 |
| School | Transmutation (Polymorph) |
| Class | Druid, Wizard |
| Spell Lists | Druid 7th, Wizard 7th |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a fragment of fossilized bone and powdered amber) |
| Duration | 1 minute/CL |
| Spell attack | None |
| Saving throw | Fortitude negates (harmless) |
| Spell resistance | No |

## Effect

One living creature gains a +1 Enhancement bonus to its Size category, increasing its actual size by one category, up to Colossal. The spell has no effect on a creature already Colossal and cannot affect an Undead, Outsider, or summoned creature. The target also gains Damage Reduction 10 against nonmagical physical damage. An unwilling target can make a Fortitude save to resist. Enhancement bonuses to the same value do not stack. Apply all relevant modifiers, space, reach, and weapon damage from the new Size in [Combat Scaling](../../game-mechanics/combat-scaling.md#size-modifiers); the spell grants no separate ability-score or AC adjustments. Worn and carried equipment enlarges with the creature and returns to normal size when separated from it or when the spell ends. Use the shared [space and confinement rule](../../game-mechanics/transformations.md#space-and-confines-during-polymorph).
