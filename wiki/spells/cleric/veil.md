# Veil

*7th-level Illusion*

| Spell detail | Rule |
| --- | --- |
| **Level** | 7 |
| **School** | Illusion |
| **Class** | Cleric |
| **Spell Lists** | Cleric 7th, Wizard 6th |
| **Casting Time** | Standard Action |
| **Range** | 60 feet |
| **Components** | V, S |
| **Duration** | 1 hour |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

Change the appearance of up to ten willing creatures for 1 hour; a creature that touches or closely examines a disguise may use Investigation against your spell DC to see through it.
