# Geas

*6th-level Enchantment*

| Spell detail | Rule |
| --- | --- |
| **Level** | 6 |
| **School** | Enchantment |
| **Class** | Cleric |
| **Spell Lists** | Cleric 6th, Wizard 6th |
| **Casting Time** | Standard Action |
| **Range** | 30 feet |
| **Components** | V, S |
| **Duration** | Up to 7 days |
| **Attack** | None |
| **Saving Throw** | Will negates |
| **Spell Resistance** | Yes |

## Effect

Set one clear, non-suicidal task for a creature that understands you; on a failed Will save it is compelled to pursue the task for up to 7 days, unless doing so is impossible or immediately fatal.
