# Meteor Swarm

| Spell detail | Rule |
| --- | --- |
| Level | 9 (Wizard) |
| School | Evocation |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | 1 mile |
| Components | V, S |
| Duration | Instantaneous |
| Attack | None |
| Saving Throw | Reflex half |
| Spell Resistance | Yes |

**Effect.** Choose four points within range; each bursts in a 20-foot radius for 6d6 fire plus 6d6 blunt damage, Reflex half. Overlapping bursts damage a creature only once.
