# Enervation

| Spell detail | Rule |
| --- | --- |
| Level | 4 (Wizard) |
| School | Necromancy |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | 1 minute |
| Attack | Ranged spell attack (spell attack bonus) |
| Saving Throw | None |
| Spell Resistance | Yes |
