# Life's Deep Current

| Spell detail | Value |
| --- | --- |
| Level | 9 |
| School | Necromancy |
| Class | Druid |
| Casting time | Standard Action |
| Range | 300 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | Instantaneous |
| Spell attack | None |
| Saving throw | Constitution half |
| Spell resistance | Yes |

## Effect

Up to ten creatures regain 1d8 per 2 caster levels (round up) hit points; undead make Constitution saves or take the same amount as corrupt damage, half on success.
