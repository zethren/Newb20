# Meteor Swarm

| Spell detail | Rule |
| --- | --- |
| Level | 9 (Wizard) |
| School | Evocation |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | 1 mile |
| Components | V, S |
| Duration | Instantaneous |
| Attack | None |
| Saving Throw | Reflex half |
| Spell Resistance | Yes |
