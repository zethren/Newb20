# Hold Person

*2nd-level Enchantment*

| Spell detail | Rule |
| --- | --- |
| **Level** | 2 |
| **School** | Enchantment |
| **Class** | Cleric |
| **Spell Lists** | Cleric 2nd, Paladin 2nd, Wizard 2nd |
| **Casting Time** | Standard Action |
| **Range** | 60 feet |
| **Components** | V, S |
| **Duration** | 1 round |
| **Attack** | None |
| **Saving Throw** | Will negates; repeat at end of turn |
| **Spell Resistance** | Yes |

## Effect

One humanoid that fails a Will save becomes Staggered for 1 round and repeats the save at the end of its turn, ending the effect on success.
