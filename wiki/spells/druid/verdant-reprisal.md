# Verdant Reprisal

| Spell detail | Value |
| --- | --- |
| Level | 5 |
| School | Abjuration |
| Class | Druid |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 1 minute/CL |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

The first time each round a warded creature is hit in melee, its attacker takes 2d8 piercing damage plus 1d8 per 8 caster levels; duration 1 minute/CL.
