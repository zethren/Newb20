# Gravebloom Beacon

| Spell detail | Value |
| --- | --- |
| Level | 4 |
| School | Necromancy |
| Class | Druid |
| Casting time | Standard Action |
| Range | Touch |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | Instantaneous |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

One creature you touch cannot be reduced below 1 hit point by nonmagical damage until the start of your next turn.
