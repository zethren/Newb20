# Raise Dead

*5th-level Conjuration*

| Spell detail | Rule |
| --- | --- |
| **Level** | 5 |
| **School** | Conjuration |
| **Class** | Cleric |
| **Casting Time** | Standard Action |
| **Range** | Touch |
| **Components** | V, S |
| **Duration** | Instantaneous |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

Touch the remains of a creature that died within a day; it returns at 1 HP, Unconscious and Dying, unless its head or heart is missing.
