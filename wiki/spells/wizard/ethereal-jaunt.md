# Ethereal Jaunt

| Spell detail | Rule |
| --- | --- |
| Level | 7 (Wizard) |
| School | Transmutation |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | Self |
| Components | V, S |
| Duration | 1 round/CL |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** You become intangible and pass through creatures and objects for 1 round/CL. You cannot attack, cast spells, or affect the material world; ending inside matter places you in the nearest open space.
