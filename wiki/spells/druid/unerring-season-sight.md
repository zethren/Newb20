# Unerring Season-Sight

| Spell detail | Value |
| --- | --- |
| Level | 9 |
| School | Divination |
| Class | Druid |
| Casting time | Standard Action |
| Range | 300 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | Instantaneous |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Ask up to three questions about creatures or events within 10 miles; the land answers each truthfully with a brief sensory image.
