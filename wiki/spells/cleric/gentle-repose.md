# Gentle Repose

*2nd-level Necromancy*

| Spell detail | Rule |
| --- | --- |
| **Level** | 2 |
| **School** | Necromancy |
| **Class** | Cleric |
| **Casting Time** | Standard Action |
| **Range** | Touch |
| **Components** | V, S |
| **Duration** | 10 days |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

Touch a corpse to prevent it from decaying, becoming undead, or being altered by effects on the dead for 10 days; this does not restore life or missing parts.
