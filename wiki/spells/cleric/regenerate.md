# Regenerate

*8th-level Conjuration*

| Spell detail | Rule |
| --- | --- |
| **Level** | 8 |
| **School** | Conjuration |
| **Class** | Cleric |
| **Casting Time** | Standard Action |
| **Range** | Touch |
| **Components** | V, S |
| **Duration** | 1 minute |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

One living creature you touch regains 4d8 HP, then 2 HP at the start of each of its turns for 1 minute; it cannot exceed maximum HP or return from death.
