| Spell detail | Rule |
| --- | --- |
| Level | 6 (Wizard) |
| School | Transmutation |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | Instantaneous |

| Saving Throw | None |
