# Leafshade

| Spell detail | Value |
| --- | --- |
| Level | 1 |
| School | Illusion |
| Class | Druid |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 10 minutes |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

One willing creature blends into natural surroundings, gaining advantage on Stealth checks while motionless for 10 minutes.
