# Incendiary Cloud

| Spell detail | Rule |
| --- | --- |
| Level | 8 (Wizard) |
| School | Evocation |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | 120 feet |
| Components | V, S |
| Duration | 1 round/CL |
| Attack | None |
| Saving Throw | Reflex half |
| Spell Resistance | Yes |

**Effect.** A 20-foot-radius spark cloud lasts 1 round/CL. Creatures that start their turn inside take 4d6 fire damage, Reflex half; strong wind disperses it.
