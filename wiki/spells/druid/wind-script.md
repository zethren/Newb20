# Wind-Script

| Spell detail | Value |
| --- | --- |
| Level | 4 |
| School | Divination |
| Class | Druid |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | Instantaneous |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Ask one question about weather or natural terrain within 1 mile; receive a truthful answer of no more than twelve words.
