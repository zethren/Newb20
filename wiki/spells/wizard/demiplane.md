# Demiplane

| Spell detail | Rule |
| --- | --- |
| Level | 8 (Wizard) |
| School | Conjuration |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | 30 feet |
| Components | V, S |
| Duration | 1 hour/CL |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** Create a 30-foot-cube room with air, floor, walls, and one doorway. It lasts 1 hour/CL and vanishes only when empty.
