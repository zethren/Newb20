# Scent of Rain

| Spell detail | Value |
| --- | --- |
| Level | 1 |
| School | Divination |
| Class | Druid |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | Instantaneous |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Learn whether natural water, poison, or a creature passed through a 20-foot area within the last hour; you learn direction but not identity.
