# Blur

*3rd-level Illusion*

| Spell detail | Rule |
| --- | --- |
| **Level** | 3 |
| **School** | Illusion |
| **Class** | Cleric |
| **Spell Lists** | Cleric 3rd, Wizard 3rd |
| **Casting Time** | Standard Action |
| **Range** | Self |
| **Components** | V, S |
| **Duration** | 1 minute/CL |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

Your outline shifts for 1 minute/CL, giving attacks against you a 20% miss chance; creatures that see through illusions ignore the effect.
