# Misty Step

| Spell detail | Rule |
| --- | --- |
| Level | 2 (Wizard) |
| School | Conjuration |
| Class | Wizard |
| Spell Lists | Cleric 2nd, Wizard 2nd |
| Casting Time | Standard Action |
| Range | Self |
| Components | V, S |
| Duration | Instantaneous |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** Teleport yourself to a visible, unoccupied space within 30 feet. This movement does not provoke Attacks of Opportunity or pass through solid barriers.
