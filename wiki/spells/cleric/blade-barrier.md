# Blade Barrier

*6th-level Evocation*

| Spell detail | Rule |
| --- | --- |
| **Level** | 6 |
| **School** | Evocation |
| **Class** | Cleric |
| **Casting Time** | Standard Action |
| **Range** | 90 feet |
| **Components** | V, S |
| **Duration** | 1 minute |
| **Attack** | None |
| **Saving Throw** | Reflex half |
| **Spell Resistance** | Yes |

## Effect

A 20-foot-long, 10-foot-high wall of blades lasts 1 minute; entering or starting a turn in it deals 1d6 slashing damage per caster level (Reflex half).
