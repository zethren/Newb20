# Greater Invisibility

*4th-level Illusion*

| Spell detail | Rule |
| --- | --- |
| **Level** | 4 |
| **School** | Illusion |
| **Class** | Cleric |
| **Casting Time** | Standard Action |
| **Range** | Touch |
| **Components** | V, S |
| **Duration** | 1 round/CL |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

A willing creature is visually undetectable for 1 round/CL even while attacking or casting, gaining Total Concealment against sight-reliant attackers.
