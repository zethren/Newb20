# Expeditious Retreat

| Spell detail | Rule |
| --- | --- |
| Level | 1 (Wizard) |
| School | Transmutation |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | Self |
| Components | V, S |
| Duration | 10 minutes/CL |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** Your movement speed increases by 10 feet for 10 minutes/CL. You gain no movement mode you do not already have.
