# Blight

*4th-level Necromancy*

| Spell detail | Rule |
| --- | --- |
| **Level** | 4 |
| **School** | Necromancy |
| **Class** | Cleric |
| **Spell Lists** | Cleric 4th, Wizard 4th |
| **Casting Time** | Standard Action |
| **Range** | 60 feet |
| **Components** | V, S |
| **Duration** | Instantaneous |
| **Attack** | None |
| **Saving Throw** | Fortitude half |
| **Spell Resistance** | Yes |

## Effect

One living creature takes 1d6 negative-energy damage per caster level (Fortitude half); plants take double damage, while undead instead regain hit points equal to the damage rolled.
