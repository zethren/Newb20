# Stone Shape

*3rd-level Transmutation*

| Spell detail | Rule |
| --- | --- |
| **Level** | 3 |
| **School** | Transmutation |
| **Class** | Cleric |
| **Spell Lists** | Cleric 3rd, Wizard 4th |
| **Casting Time** | Standard Action |
| **Range** | Touch |
| **Components** | V, S |
| **Duration** | Permanent |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

Reshape a contiguous stone object or section no larger than a 5-foot cube into a form you choose, including a doorway; cannot affect creatures or make moving parts.
