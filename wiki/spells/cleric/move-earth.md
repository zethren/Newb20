# Move Earth

*6th-level Transmutation*

| Spell detail | Rule |
| --- | --- |
| **Level** | 6 |
| **School** | Transmutation |
| **Class** | Cleric |
| **Spell Lists** | Cleric 6th, Wizard 6th |
| **Casting Time** | Standard Action |
| **Range** | 60 feet |
| **Components** | V, S |
| **Duration** | Permanent |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

Shift a 20-foot cube of loose earth along the ground to a new location within 60 feet; the gradual movement cannot instantly bury creatures and remains in place.
