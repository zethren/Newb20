# Sunburst

*8th-level Evocation*

| Spell detail | Rule |
| --- | --- |
| **Level** | 8 |
| **School** | Evocation |
| **Class** | Cleric |
| **Casting Time** | Standard Action |
| **Range** | 150 feet |
| **Components** | V, S |
| **Duration** | Instantaneous |
| **Attack** | None |
| **Saving Throw** | Fortitude half and negates Blinded |
| **Spell Resistance** | Yes |

## Effect

A 30-foot-radius flash deals 1d6 holy damage per caster level (Fortitude half); a creature that fails is also Blinded for 1 minute and saves again at each turn’s end.
