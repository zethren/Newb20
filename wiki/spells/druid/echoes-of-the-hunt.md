# Echoes of the Hunt

| Spell detail | Value |
| --- | --- |
| Level | 5 |
| School | Divination |
| Class | Druid |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | Instantaneous |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Reconstruct the last minute of visible movement in a 30-foot area as silent, translucent outlines.
