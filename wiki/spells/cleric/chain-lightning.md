# Chain Lightning

*7th-level Evocation*

| Spell detail | Rule |
| --- | --- |
| **Level** | 7 |
| **School** | Evocation |
| **Class** | Cleric |
| **Spell Lists** | Cleric 7th, Wizard 6th |
| **Casting Time** | Standard Action |
| **Range** | 120 feet |
| **Components** | V, S |
| **Duration** | Instantaneous |
| **Attack** | Ranged spell attack (first target) |
| **Saving Throw** | Reflex half on secondary targets |
| **Spell Resistance** | Yes |

## Effect

A ranged spell attack deals 1d6 electric damage per caster level on a hit; lightning jumps to four more creatures within 30 feet, each taking half the damage rolled by the primary target (Reflex half).
