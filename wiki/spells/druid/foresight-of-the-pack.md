# Foresight of the Pack

| Spell detail | Value |
| --- | --- |
| Level | 8 |
| School | Divination |
| Class | Druid |
| Casting time | Standard Action |
| Range | 300 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 1 round/CL |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Choose up to six allies; for 1 round/CL, each can add 1d4 to one attack roll or saving throw once per round.
