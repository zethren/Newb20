# Hunter's Phantasm

| Spell detail | Rule |
| --- | --- |
| Level | 4th |
| School | Illusion |
| Class | Ranger |
| Casting Time | Standard Action |
| Range | 120 feet |
| Components | V, S |
| Duration | Concentration, up to 1 minute |
| Attack | None |
| Save | Wisdom, negates |
| Spell Resistance | Yes |

## Effect

Create a lifelike image and sound of a small animal or other harmless lure at a point within range. One creature you can see that can perceive the illusion must make a Wisdom saving throw. On a failure, it believes the lure is real and is drawn to investigate by the safest available route, using its movement on its turns. The creature repeats the save if it takes damage or the lure acts in a physically impossible way. The illusion cannot deal damage or block movement.
