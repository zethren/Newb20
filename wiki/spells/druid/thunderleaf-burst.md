# Thunderleaf Burst

| Spell detail | Value |
| --- | --- |
| Level | 2 |
| School | Evocation |
| Class | Druid |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | Instantaneous |
| Spell attack | None |
| Saving throw | Dexterity half |
| Spell resistance | Yes |

## Effect

Creatures in a 10-foot-radius area must make Dexterity saves, taking 1d6 sonic damage per caster level on a failure or half on a success.
