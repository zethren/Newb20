# Mislead

*6th-level Illusion*

| Spell detail | Rule |
| --- | --- |
| **Level** | 6 |
| **School** | Illusion |
| **Class** | Cleric |
| **Spell Lists** | Cleric 6th, Wizard 6th |
| **Casting Time** | Standard Action |
| **Range** | 30 feet |
| **Components** | V, S |
| **Duration** | 1 minute |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

An illusory double appears within 30 feet as you turn invisible for 1 minute; direct it as a Move Action, but it cannot interact physically and your invisibility ends when you attack or cast.
