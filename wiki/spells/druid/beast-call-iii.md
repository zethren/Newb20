# Beast Call III

| Spell detail | Value |
| --- | --- |
| Level | 3 |
| School | Conjuration |
| Class | Druid |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a tuft of fur or other natural token) |
| Duration | 1 minute |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Summon one beast with CR 3, or roll `1d4` to summon that many beasts of one shared lower CR. Use the shared [Beast Call rules](../../spells.md#beast-call-i-ix) to select the creatures and resolve their actions.
