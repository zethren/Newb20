# Soul Cage

*9th-level Necromancy*

| Spell detail | Rule |
| --- | --- |
| **Level** | 9 |
| **School** | Necromancy |
| **Class** | Cleric |
| **Casting Time** | Standard Action |
| **Range** | 60 feet |
| **Components** | V, S |
| **Duration** | 24 hours |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

When a creature within 60 feet dies, trap its spirit in a visible crystal for 24 hours; ask it six questions, observe through its senses for 1 minute, or release it, but cannot compel answers.
