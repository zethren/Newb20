# Detect Thoughts

*2nd-level Divination*

| Spell detail | Rule |
| --- | --- |
| **Level** | 2 |
| **School** | Divination |
| **Class** | Cleric |
| **Casting Time** | Standard Action |
| **Range** | 30 feet |
| **Components** | V, S |
| **Duration** | 1 minute |
| **Attack** | None |
| **Saving Throw** | Will negates |
| **Spell Resistance** | Yes |

## Effect

One creature within 30 feet must pass a Will save or reveal its surface thoughts to you for 1 minute while it remains in range; success grants immunity to this casting.
