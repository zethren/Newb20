# Cinderfall

| Spell detail | Value |
| --- | --- |
| Level | 3 |
| School | Evocation |
| Class | Druid |
| Casting time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | Instantaneous |
| Spell attack | None |
| Saving throw | Dexterity half |
| Spell resistance | Yes |

## Effect

Creatures in a 15-foot-radius area take 1d6 fire damage per caster level, with a Dexterity save for half damage.
