# Hunter's Scent

| Spell detail | Rule |
| --- | --- |
| Level | 1st |
| School | Divination |
| Class | Ranger |
| Casting Time | Standard Action |
| Range | Self |
| Components | V, S |
| Duration | 1 hour |
| Attack | None |
| Save | None |
| Spell Resistance | No |

## Effect

Choose one creature whose tracks or scent you can detect within 30 feet. For the duration, you have advantage on Survival checks to follow that creature's trail. The spell does not reveal the creature's location or preserve a trail that has been destroyed.
