# Predator's Passage

| Spell detail | Rule |
| --- | --- |
| Level | 4th |
| School | Conjuration |
| Class | Ranger |
| Casting Time | Bonus Action |
| Range | Self |
| Components | V, S |
| Duration | Instantaneous |
| Attack | None |
| Save | None |
| Spell Resistance | No |

## Effect

Teleport from your space to an unoccupied space you can see within 60 feet that is in natural dim light, shadow, or foliage. You arrive with the same orientation and momentum, if any. You cannot pass through a magical barrier or arrive inside an object.
