# Primal Stillness

| Spell detail | Value |
| --- | --- |
| Level | 9 |
| School | Enchantment |
| Class | Druid |
| Casting time | Standard Action |
| Range | 300 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | Concentration, up to 1 minute |
| Spell attack | None |
| Saving throw | Wisdom negates |
| Spell resistance | Yes |

## Effect

Creatures of your choice in a 40-foot-radius area must succeed on Wisdom saves or be incapacitated for 1 minute; a creature repeats its save after taking damage.
