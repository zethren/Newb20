# Forcecage

| Spell detail | Rule |
| --- | --- |
| Level | 7 (Wizard) |
| School | Abjuration |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | 10 minutes/CL |
| Attack | None |
| Saving Throw | Reflex negates |
| Spell Resistance | Yes |

**Effect.** Enclose one Large or smaller creature in a 10-foot force cube; it may make a Reflex save to escape before closure. The cage lasts 10 minutes/CL and only Disintegrate ends it early.
