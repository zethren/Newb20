# Many-Path Mirage

| Spell detail | Value |
| --- | --- |
| Level | 7 |
| School | Illusion |
| Class | Druid |
| Casting time | Standard Action |
| Range | 120 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 1 minute |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Create illusory versions of up to six willing creatures, each appearing 10 feet away; attacks against a creature have a 50% chance to hit a duplicate and miss for 1 minute.
