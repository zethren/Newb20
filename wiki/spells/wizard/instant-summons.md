# Instant Summons

| Spell detail | Rule |
| --- | --- |
| Level | 6 (Wizard) |
| School | Conjuration |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | Touch |
| Components | V, S |
| Duration | 1 day/CL |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** Mark a book-sized object you own by touch. For 1 day/CL, use a Standard Action to call it into your empty hand from anywhere on the same plane.
