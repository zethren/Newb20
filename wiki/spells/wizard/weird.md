# Weird

| Spell detail | Rule |
| --- | --- |
| Level | 9 (Wizard) |
| School | Illusion |
| Class | Wizard |
| Spell Lists | Cleric 9th, Wizard 9th |
| Casting Time | Standard Action |
| Range | 120 feet |
| Components | V, S |
| Duration | 1 round |
| Attack | None |
| Saving Throw | Will partial |
| Spell Resistance | Yes |

**Effect.** Up to six creatures make Will saves. Failure Stuns a target for 1 round with a private vision; success leaves it Shaken for 1 round. The visions cause no physical harm.
