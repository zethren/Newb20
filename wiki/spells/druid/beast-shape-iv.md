# Beast Shape IV

| Spell detail | Value |
| --- | --- |
| Level | 6 |
| School | Transmutation (Polymorph) |
| Class | Druid |
| Casting time | Standard Action |
| Range | Self |
| Components | V, S, M (a sample from the chosen magical beast) |
| Duration | 1 minute/CL |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

This spell functions as [Beast Shape III](beast-shape-iii.md), and also allows Tiny or Large magical-beast forms.

| Form size | Physical ability adjustment | Natural Armor bonus to Natural Armor AC |
| --- | --- | ---: |
| Tiny magical beast | +8 Size bonus to Dexterity, -2 Size penalty to Strength | +3 |
| Large magical beast | +6 Size bonus to Strength, +2 Size bonus to Constitution, -2 Size penalty to Dexterity | +6 |

The form may grant burrow 60 feet, climb 90 feet, fly 120 feet (good maneuverability), swim 120 feet, blindsense 60 feet, tremorsense 60 feet, darkvision 90 feet, low-light vision, or scent if the chosen creature has that ability. It may also grant breath weapon, constrict, ferocity, grab, jet, poison, pounce, rake, rend, roar, spikes, trample, trip, or web when present in the chosen profile. If the creature has an elemental immunity or resistance, you gain resistance 20 to that type; you also gain any elemental vulnerability it has.
