# Passwall

*5th-level Transmutation*

| Spell detail | Rule |
| --- | --- |
| **Level** | 5 |
| **School** | Transmutation |
| **Class** | Cleric |
| **Spell Lists** | Cleric 5th, Wizard 5th |
| **Casting Time** | Standard Action |
| **Range** | 30 feet |
| **Components** | V, S |
| **Duration** | 1 hour |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

Open a 5-foot-square passage through up to 10 feet of nonmagical wood, stone, or earth; removed material rests beside it, and the passage closes after 1 hour.
