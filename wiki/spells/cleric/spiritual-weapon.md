# Spiritual Weapon

*2nd-level Evocation*

| Spell detail | Rule |
| --- | --- |
| **Level** | 2 |
| **School** | Evocation |
| **Class** | Cleric |
| **Casting Time** | Standard Action |
| **Range** | 60 feet |
| **Components** | V, S |
| **Duration** | 1 minute |
| **Attack** | Ranged spell attack (after casting) |
| **Saving Throw** | None |
| **Spell Resistance** | Yes |

## Effect

Create a floating weapon for 1 minute; on later turns, use a Standard Action to make a ranged spell attack against a creature within 30 feet, dealing 1d8 + Wisdom modifier + 1d8 for every 8 caster levels after 3rd magic damage on a hit.
