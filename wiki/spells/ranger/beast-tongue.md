# Beast Tongue

| Spell detail | Rule |
| --- | --- |
| Level | 1st |
| School | Enchantment |
| Class | Ranger |
| Casting Time | Standard Action |
| Range | Self |
| Components | V, S |
| Duration | 10 minutes |
| Attack | None |
| Save | None |
| Spell Resistance | No |

## Effect

You can convey simple concepts to beasts and understand their immediate needs, emotions, and observations. A beast is not compelled to cooperate, and its knowledge is limited by its senses and intelligence. The spell does not grant language, reveal lies, or change a beast's attitude.
