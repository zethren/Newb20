# Chill Touch

| Spell detail | Rule |
| --- | --- |
| Level | 1 (Wizard) |
| School | Necromancy |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | Instantaneous |
| Attack | Ranged spell attack (spell attack bonus) |
| Saving Throw | None |
| Spell Resistance | Yes |

**Effect.** A ranged spell attack hit deals 1d6 cold damage, plus 1d6 at caster level 5 and every 5 caster levels thereafter, and prevents the target from regaining HP until the start of your next turn.
