# Polymorph

*4th-level Transmutation*

| Spell detail | Rule |
| --- | --- |
| **Level** | 4 |
| **School** | Transmutation |
| **Class** | Cleric |
| **Casting Time** | Standard Action |
| **Range** | Touch |
| **Components** | V, S |
| **Duration** | 10 minutes |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

Transform one willing creature into a nonmagical beast of similar size for 10 minutes; it retains HP, mental scores, and speech but uses the form’s movement modes and natural attacks. If the new form cannot fit, use the shared [space and confinement rule](../../game-mechanics/transformations.md#space-and-confines-during-polymorph).
