# Power Word Stun

| Spell detail | Rule |
| --- | --- |
| Level | 9 (Wizard) |
| School | Enchantment |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | 1d4 rounds |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | Yes |

**Effect.** One creature with 150 HP or fewer becomes Stunned for 1d4 rounds; creatures above that limit are unaffected. No saving throw applies.
