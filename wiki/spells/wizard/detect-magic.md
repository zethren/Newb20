# Detect Magic

| Spell detail | Rule |
| --- | --- |
| Level | 1 (Wizard) |
| School | Divination |
| Class | Wizard |
| Spell Lists | Cleric 1st, Wizard 1st |
| Casting Time | Standard Action |
| Range | Self |
| Components | V, S |
| Duration | 10 minutes/CL |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** For 10 minutes/CL, sense active spells within 60 feet. A Standard Action reveals the school of one aura; stone walls block the sense.
