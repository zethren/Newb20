# Rebirth of the Green

| Spell detail | Value |
| --- | --- |
| Level | 9 |
| School | Necromancy |
| Class | Druid |
| Casting time | Standard Action |
| Range | 300 feet |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | Instantaneous |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Restore one creature dead for no more than 200 years to life with all hit points and end poison and disease; it can refuse to return.
