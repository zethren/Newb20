# Create Food and Water

*3rd-level Conjuration*

| Spell detail | Rule |
| --- | --- |
| **Level** | 3 |
| **School** | Conjuration |
| **Class** | Cleric |
| **Spell Lists** | Cleric 3rd, Paladin 3rd |
| **Casting Time** | Standard Action |
| **Range** | 30 feet |
| **Components** | V, S |
| **Duration** | Instantaneous |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

Create simple nourishing food and fresh water sufficient for six people for one day; it appears in containers or on a surface within range.
