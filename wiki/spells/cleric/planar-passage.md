# Planar Passage

*8th-level Conjuration*

| Spell detail | Rule |
| --- | --- |
| **Level** | 8 |
| **School** | Conjuration |
| **Class** | Cleric |
| **Casting Time** | Standard Action |
| **Range** | 30 feet |
| **Components** | V, S |
| **Duration** | 1 minute |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

Open a 10-foot doorway to a location on another plane you have visited; it remains for 1 minute or until eight willing creatures pass through.
