# Banishment

| Spell detail | Rule |
| --- | --- |
| Level | 4 (Wizard) |
| School | Abjuration |
| Class | Wizard |
| Spell Lists | Cleric 7th, Wizard 4th |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | Instantaneous |
| Attack | None |
| Saving Throw | Will negates |
| Spell Resistance | Yes |

**Effect.** One extraplanar creature makes a Will save or returns to its home plane, appearing in a safe unoccupied space there. A success makes it immune to this casting for 24 hours.
