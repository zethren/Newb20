# Remove Disease

*3rd-level Conjuration*

| Spell detail | Rule |
| --- | --- |
| **Level** | 3 |
| **School** | Conjuration |
| **Class** | Cleric |
| **Spell Lists** | Cleric 3rd, Paladin 3rd |
| **Casting Time** | Standard Action |
| **Range** | Touch |
| **Components** | V, S |
| **Duration** | Instantaneous |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

Touch a creature to end one disease; if the disease specifies a save DC, succeed on 1d20 + caster level against that DC or the disease remains.
