# Heat Metal

*2nd-level Transmutation*

| Spell detail | Rule |
| --- | --- |
| **Level** | 2 |
| **School** | Transmutation |
| **Class** | Cleric |
| **Casting Time** | Standard Action |
| **Range** | 60 feet |
| **Components** | V, S |
| **Duration** | 1 minute |
| **Attack** | None |
| **Saving Throw** | Fortitude half |
| **Spell Resistance** | Yes |

## Effect

Choose one metal item worn or held by a creature within range. For 1 minute, it takes 2d6 fire damage at the start of each of that creature’s turns; the creature can drop a held item, while a creature unable to remove a worn item can halve the damage with a Fortitude save.
