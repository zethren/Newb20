# Silent Image

*1st-level Illusion*

| Spell detail | Rule |
| --- | --- |
| **Level** | 1 |
| **School** | Illusion |
| **Class** | Cleric |
| **Spell Lists** | Cleric 1st, Wizard 1st |
| **Casting Time** | Standard Action |
| **Range** | 60 feet |
| **Components** | V, S |
| **Duration** | 1 minute |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

Create a visual image no larger than a 15-foot cube for 1 minute; it has no sound or substance, and close study with an Investigation check against your spell DC reveals it.
