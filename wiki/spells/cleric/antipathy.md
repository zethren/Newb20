# Antipathy

*8th-level Enchantment*

| Spell detail | Rule |
| --- | --- |
| **Level** | 8 |
| **School** | Enchantment |
| **Class** | Cleric |
| **Spell Lists** | Cleric 8th, Wizard 8th |
| **Casting Time** | Standard Action |
| **Range** | Self |
| **Components** | V, S |
| **Duration** | 1 hour/CL |
| **Attack** | None |
| **Saving Throw** | Will negates; repeat after leaving sight |
| **Spell Resistance** | Yes |

## Effect

Creatures of a type or a named individual you choose must pass a Will save or become Shaken and move away while they see you; they save again after leaving sight.
