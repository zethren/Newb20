# Primal Shifter

The Primal Shifter is a martial shapeshifter who gains stronger animal forms through six Shifting Talent tiers. Its documented forms are the Wolf (brawler/vanguard), Feline (striker/assassin), and Bear (guardian/tank).

## Class Statistics

| Statistic | Value |
| --- | --- |
| Hit Die | d8 |
| Base attack bonus | High progression, as shown below |
| Good saves | Fortitude, Reflex |
| Poor save | Will |
| Skill ranks per level | 4 + Intelligence modifier (minimum 1) |
| Class skills | [Acrobatics](../skills/acrobatics.md), [Athletics](../skills/athletics.md), [Escape Artist](../skills/escape-artist.md), [Fly](../skills/fly.md), [Handle Animal](../skills/handle-animal.md), [Lore (Nature)](../skills/lore-nature.md), [Perception](../skills/perception.md), [Ride](../skills/ride.md), [Stealth](../skills/stealth.md), [Survival](../skills/survival.md) |
| Spellcasting | Not specified |
