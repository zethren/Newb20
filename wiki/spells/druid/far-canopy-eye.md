# Far Canopy Eye

| Spell detail | Value |
| --- | --- |
| Level | 6 |
| School | Divination |
| Class | Druid |
| Casting time | Standard Action |
| Range | Self |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | 10 minutes |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

Create a sensor at a natural place you have seen within 1 mile; you can see and hear from it for 10 minutes, but not through solid barriers.
