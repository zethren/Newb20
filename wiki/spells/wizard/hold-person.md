# Hold Person

| Spell detail | Rule |
| --- | --- |
| Level | 2 (Wizard) |
| School | Enchantment |
| Class | Wizard |
| Spell Lists | Cleric 2nd, Wizard 2nd |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S |
| Duration | 1 round/CL |
| Attack | None |
| Saving Throw | Will negates; repeat each turn |
| Spell Resistance | Yes |

**Effect.** One humanoid makes a Will save or becomes Paralyzed for 1 round/CL. It repeats the save at the end of each turn to end the spell.
