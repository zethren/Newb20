# Mage Armor

| Spell detail | Rule |
| --- | --- |
| Level | 1 (Wizard) |
| School | Abjuration |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | Touch |
| Components | V, S |
| Duration | 1 hour/CL |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** You or one willing creature touched gains a +4 Armor bonus to Armor AC for 1 hour/CL. It does not stack with the Armor bonus from worn armor; use the higher Armor bonus.
