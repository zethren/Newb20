# Greater Command

*7th-level Enchantment*

| Spell detail | Rule |
| --- | --- |
| **Level** | 7 |
| **School** | Enchantment |
| **Class** | Cleric |
| **Casting Time** | Standard Action |
| **Range** | 60 feet |
| **Components** | V, S |
| **Duration** | 1 round |
| **Attack** | None |
| **Saving Throw** | Will negates |
| **Spell Resistance** | Yes |

## Effect

Speak a one-word order to up to four creatures that understand you; each that fails a Will save spends its next turn obeying if possible, without directly harming itself.
