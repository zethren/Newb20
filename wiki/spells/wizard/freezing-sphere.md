# Freezing Sphere

| Spell detail | Rule |
| --- | --- |
| Level | 6 (Wizard) |
| School | Evocation |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | 300 feet |
| Components | V, S |
| Duration | Instantaneous |
| Attack | None |
| Saving Throw | Reflex half |
| Spell Resistance | Yes |

**Effect.** A globe bursts at a point within range, dealing 1d6 cold damage per caster level in a 20-foot radius, Reflex half. It freezes a 10-foot patch of water solid for 1 hour.
