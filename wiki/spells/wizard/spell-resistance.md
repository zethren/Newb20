# Spell Resistance

| Spell detail | Rule |
| --- | --- |
| Level | 5 (Wizard) |
| School | Abjuration |
| Class | Wizard |
| Spell Lists | Cleric 5th, Wizard 5th |
| Casting Time | Standard Action |
| Range | Touch |
| Components | V, S |
| Duration | 10 minutes/CL |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | No |

**Effect.** One willing creature touched gains spell resistance 12 + your caster level for 10 minutes/CL, replacing any lower value.
