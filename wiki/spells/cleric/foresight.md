*7th-level Divination*

| Spell detail | Rule |
| --- | --- |
| **Level** | 7 |
| **School** | Divination |
| **Class** | Cleric |
| **Spell Lists** | Cleric 7th, Wizard 9th |

| **Components** | V, S |

| **Saving Throw** | None |
