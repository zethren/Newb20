# Canopy Leap

| Spell detail | Value |
| --- | --- |
| Level | 3 |
| School | Transmutation |
| Class | Druid |
| Casting time | Standard Action |
| Range | Self |
| Components | V, S, M (a leaf or seed, not consumed) |
| Duration | Instantaneous |
| Spell attack | None |
| Saving throw | None |
| Spell resistance | No |

## Effect

You or one willing creature can jump up to 60 feet horizontally or 30 feet vertically without taking falling damage until the end of your next turn.
