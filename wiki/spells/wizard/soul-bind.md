# Soul Bind

| Spell detail | Rule |
| --- | --- |
| Level | 9 (Wizard) |
| School | Necromancy |
| Class | Wizard |
| Casting Time | Standard Action |
| Range | 60 feet |
| Components | V, S, M (gem worth at least 1,000 gp) |
| Duration | Until dispelled |
| Attack | None |
| Saving Throw | None |
| Spell Resistance | Yes |

**Effect.** When a creature you see dies, trap its soul in a gem worth at least 1,000 gp. It cannot return to life while bound; dispelling this spell breaks the gem and frees it.
