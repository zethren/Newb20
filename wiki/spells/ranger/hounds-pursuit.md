# Hound's Pursuit

| Spell detail | Rule |
| --- | --- |
| Level | 2nd |
| School | Divination |
| Class | Ranger |
| Casting Time | Standard Action |
| Range | Self |
| Components | V, S |
| Duration | 1 hour |
| Attack | None |
| Save | None |
| Spell Resistance | No |

## Effect

Choose one creature whose trail you have found within the last hour. You can distinguish its trail from similar tracks and have advantage on Survival checks to follow it, even when it crosses other tracks or ordinary difficult terrain. The spell does not restore a trail erased by deliberate action or reveal the creature's current position.
