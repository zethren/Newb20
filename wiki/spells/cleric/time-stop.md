# Time Stop

*9th-level Transmutation*

| Spell detail | Rule |
| --- | --- |
| **Level** | 9 |
| **School** | Transmutation |
| **Class** | Cleric |
| **Spell Lists** | Cleric 9th, Wizard 9th |
| **Casting Time** | Standard Action |
| **Range** | Self |
| **Components** | V, S |
| **Duration** | 3 turns |
| **Attack** | None |
| **Saving Throw** | None |
| **Spell Resistance** | No |

## Effect

Take three consecutive turns during which other creatures cannot perceive or affect you and you cannot affect them or their possessions; effects on you continue normally.
